# 后端接口及异步入口清单

这是对 2026-11-06 工作区 URL 声明与 DRF `@action` 的静态提取，用于逐项溯源；**路由存在不代表已实现目标业务、当前角色有权调用或已经经过本轮测试**。处理器、权限、认证、数据和异常仍须沿代码及测试核对。路径参数和兼容入口保留源码写法。

主路由为 [`config/urls.py`](../../services/backend/config/urls.py)；老板／陪玩／后台的产品流程见[跨端主线](05-跨端订单资金售后.md)。此前文档若有单级提现、店内财务、星星或旧押金描述，以本套最新决定为准。

## 顶层与实时接口

- `api/health/`、`api/media/renew/`、`api/media/private/<ticket>/` 和 `media/<path>` 分别用于就绪检查、私有媒体续签／读取和公开媒体；权限及门店上下文仍须核验。
- WebSocket 由 [`config/asgi.py`](../../services/backend/config/asgi.py) 和 [`orders/routing.py`](../../services/backend/orders/routing.py) 接入；身份、令牌和店上下文分别核对，断开后重读持久数据。

## 订单及资金相关定时、异步任务

| 任务或配置 | 当前代码入口 | 业务关联 |
| --- | --- | --- |
| 待接单超时、兜底扫描 | [`orders/tasks.py`](../../services/backend/orders/tasks.py) | 已过期且仍待接订单取消／退款；与抢单、指派及不同支付渠道竞争时重校验。 |
| 预约过期 | `orders.tasks.expire_reservations` | 到期预约状态更新；预约不等于已支付订单。 |
| 陪玩收益释放 | [`wallet/tasks.py`](../../services/backend/wallet/tasks.py) | 已到期冻结收益按真实份额和规则释放；不把待结算份额冒充钱包余额。 |
| 订单实销确认和补贴重试 | [`engagement/tasks.py`](../../services/backend/engagement/tasks.py) | 按完成、报单、售后等条件处理，补贴失败可重试；不以任务启动等于成功。 |
| 会员周期券、生日、播报 | `engagement.tasks.grant_member_coupons`、`publish_birthdays`、`drain_broadcast_outbox` | 运营权益和通知有各自触发及幂等，不是支付本身。 |
| KOOK／企微派单 | `orders.tasks.send_kook_dispatch`、`send_wecom_dispatch` | 真实外部渠道和订单状态分开；每店配置与收件人隔离。 |
| 自动解封 | `console.tasks.lift_expired_bans_task` | 资格按账号和门店重新检查，不因任务恢复跨店身份。 |

周期配置见 [`config/settings.py`](../../services/backend/config/settings.py)，门店上下文和任务包装见 [`stores/tasks.py`](../../services/backend/stores/tasks.py)。计划执行频率是配置，不等于真实 worker 已启动或完成。

静态检查发现任务包装对部分无门店上下文的非周期任务会兼容回落声浪库；已登记的周期任务则分发各有效门店。新任务缺店时不能依赖该回落，历史兼容与实施验收见[差距 G22](07-差距待决与验收.md)。
