# XA 电竞平台三端业务 PRD 总纲

> **2026-11-11 前端产品化增补：** [SaaS 产品模块与三端前端闭环](34-SaaS产品模块与三端前端闭环.md) 明确固定模块、老板端 H5 独立购买/定制、角色入口、统一状态与待后端对接契约。本轮仅前端实现，新增接口和真实业务闭环须另行联调。

版本：2026-11-06　状态：**需求基线草案，待完成逐项复核与验收**

本文以老板、陪玩、后台三个使用方之间的订单和资金流转为主线，覆盖支撑该主线的门店、身份、服务、售后、积分、工资及运营能力。本文是产品目标和现状调查，不代表新增需求已经开发或测试通过。

> 金额口径已明确：服务原价 250 元、优惠后成交 200 元、积分抵扣后实付 170 元时，对外接单额／派单额／下单额及抢单排序按原价 250 元；按订单计提的岗位绩效、提成及适用福利按实付 170 元，固定底薪按薪资方案；陪玩分成与续单 188 元门槛仍按成交 200 元。部分退款退店币 42.5 元、积分 7.5 元等值时，原价汇总冲减 50 至 200，工资绩效、会员成长和经营报表的实付净额冲减 42.5 至 127.5；全额退款补齐冲销剩余原价。

> 人民币与店币按 **1 元＝10 店币**换算。服务项目标价必须是 10 店币的整数倍，预约按所选时长及单一折扣计算后有小数店币时向上取整；老板付款不使用小数店币。积分订单部分退款的店币向下取整、全退补齐；陪玩承担的分摊逐人逐笔向上取整，多出的真实金额归门店。所有比例折扣互斥，每单最多一张券，金额券可按规则叠加会员或门店活动折扣；积分只能按门店配置的完整兑换组使用。

> **2026-11-11 增补：** 平台按 SaaS 交付，各门店独立 License；三档和到期处理见 [SaaS 门店授权与 License](33-SaaS门店授权与License.md)。该能力尚未实现。

## 使用本套文档的规则

- 优先采用用户最新明确决定。现有工作区 [AGENTS.md](../../AGENTS.md) 给出的技术、隔离、部署与验收约定继续适用；其中与本轮用户最新决定冲突的店内财务、店币名称和押金标准，以本套文档标注的最新决定为准。
- **需求**描述要达到的行为；**现状**是源码或历史记录能证明的行为；**待开发**不等于已经实现；**待确认**不能由开发或测试自行替用户决定。每一项证据保留日期、代码路径或历史记录出处。
- 三端均为网页。老板端、陪玩端适配手机和桌面，后台以桌面和约 1366×1024 的 12.9 英寸 iPad Pro 横屏为最低目标。现阶段优先真实业务和异常闭环，沿用已有界面，不开展视觉重设计。
- 三端均支持账号密码；未绑 OTP 使用短信，已绑 OTP 默认手机验证器动态口令且可切短信；已绑定微信可扫码或快捷登录直接进入。老板可自行填写手机号并短信验证，陪玩正式接单前须绑定微信。真实渠道能力不得模拟成功；店员身份和平台身份的授权相互独立。
- 以 `fronted/` 为当前三端源码，`services/backend/` 为业务服务；`apps/` 和历史原生页面用于核对尚未迁移的能力，不把旧技术形态当作当前交付标准。
- 陪玩、老板、订单、钱包及其文件、缓存、实时消息、定时任务必须保留门店上下文。授权跨店汇总不等于跨店合并账户、钱包或转移订单。
