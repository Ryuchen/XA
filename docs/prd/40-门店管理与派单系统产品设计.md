# 门店管理与派单系统产品设计（专业 SaaS 视角）

版本：2026-11-17；状态：**产品设计基线**。范围：电竞门店管理域＋派单域的专业 SaaS 产品设计，落入 [39-审批单](39-SaaS缺口整改审批单.md) 已批复决策（SA01/02/05/06/07/08/11/12/13/14、PC01–PC09、C1）；不采纳/暂缓项（SA03 评分评级、SA04 平台排行反刷、SA09 结算票据流、SA10 提现窗口）不进入首版设计。业务规则以用户最新决定与 [PRD 总纲](README.md) 为准；本文是域级整合设计，细节规则引用对应编号 PRD，不重复抄录。

配套：[35-平台产品设计](35-企业级SaaS平台产品设计.md)（租户/商业化/生命周期）、[37-尊享卡](37-门店预存尊享卡.md)、[38-功能对照](38-入驻培训功能对照与SaaS化增补.md)、[dev/04-抢单预约与履约](../development/04-抢单预约与履约.md)、[dev/28-开发流程安排](../development/28-产品开发流程安排.md)。

## 1. 域边界与角色

| 域 | 职责 | 主要角色 |
| --- | --- | --- |
| 门店管理域 | 门店生命周期（入驻→配置→开业→营业→终止）、资质合规、组织与权限、经营分析、信任保障、增长运营 | 平台超管/平台财务、店内超管/客服/售后/运营 |
| 派单域 | 需求（订单/预约）→ 供给匹配（抢单/指派/试音/预约确认）→ 履约调度（转单/改派/房间）→ 完成与结算触发 | 老板、陪玩、客服（代派/调度）、系统调度器 |
| 交叉约束 | 两域共享：租户上下文、License 权益裁决、资金事实链、审计、通知恢复 | 全角色 |

设计原则（继承 [AGENTS.md 第一性原理](../../AGENTS.md)）：事实唯一、账实相符；派单每一次匹配与调度都产生可追溯事实（候选快照/排序依据/确认记录/资金版本），门店管理每一次配置变更都留版本与审计。

## 2. 门店管理域设计

### 2.1 入驻与开业（SA14 批准）

- **结构化开业自检清单**：阻断项（营业执照/证照、logo/背景、介绍、价目表、点单须知、核心资金配置、店币名称、客服名片绑定）与建议项（营销/增长配置）分级；阻断项未过不得 ACTIVE；清单状态进建立店七态的 CONFIGURING→READY 门禁。
- **证照管理**：上传（水印建议）、有效期提醒（到期前 30/7/1 天复用提醒中心）、过期阻断新增营业动作但保留存量业务（与 License 降级规则同构）。
- **合规校验（SA13 批准）**：平台规则库＋门店上传/改名校验留痕——禁极限词、图片禁价格/引流信息、价目表禁单方解释权条款（网络交易监督管理办法 21 条）、昵称管控词（接待/客服/售后仅授权角色）。
- **信任保障（SA02 批准）**：门店保证金（License 合同条款配置、缴纳/退还留痕）＋闭店公示 30 天余额返还＋老板端门店保障状态公示；资金监管账户二期。

### 2.2 配置与组织

- 系统字典/配置目录为唯一事实源（[prd/12](12-系统字典与门店初始化.md)/[18](18-门店初始化配置项详表.md)）；配置锁＋版本＋双侧审计；修改不追改已发生交易。
- 组织与权限：店内角色（超管/客服/售后/运营）权限点注册表；平台身份独立授权；员工任职与账号周期联动（离职结清、停职阻断）。
- 多租户中立：一切门店差异（店币/卡档/抽成/延迟/阈值）逐店配置，平台不硬编码（PC08 批准）。

### 2.3 经营分析与导出

- 经营面板四视图：总数据/日数据/趋势/排名（店内维度；平台排行 SA04 暂缓不做）；未知金额显式缺失不记 0。
- 订单导出（SA11 批准）：权限＋审计＋脱敏＋水印；平台跨店导出仅授权范围。
- 收支日志视图：礼物/订单/转移收入与免单/提现支出（门店维度，衔接平台总账）。

### 2.4 增长运营（SA12 批准全部入首版）

| 模块 | 设计要点 | 隔离/权益 |
| --- | --- | --- |
| 关注门店 | 老板关注/取关、关注列表快速入口、在线/关注数展示 | 逐店；不跨店合并 |
| 页面生成 | H5 制作工具生成价目表/须知/介绍链接；模板合规校验（SA13） | 门店素材版权承诺 |
| 喜报飘屏 | 触发场景/条件/对象/内容可配；走通知恢复框架 | 逐店；授权 CONTENT_OPERATIONS |
| 招聘中心 | 陪玩招聘发布/申请/考核联动（仅考核培训通过者可入） | 逐店 |
| 邀请好友 | 邀请关系链＋奖励配置（衔接现有推荐佣金口径：主单实付计佣、礼物不计） | 逐店；反作弊留痕 |
| 陪玩动态 | 动态发布＋打赏＋评价＋收藏；黑名单联动阻断 | 逐店；内容合规校验 |
| 用户群 | 门店用户群创建（权限开通制）、活动宣发 | 逐店；消息权限 |

### 2.5 卡式预存与平台费

- 尊享卡产品线按 [37](37-门店预存尊享卡.md) 已批复基线：按卡独立受限本金、卡档折扣互斥框架、卡面版权平台审核、逐卡转回开关、180 天权益窗口、高额审核门禁、退卡费逐卡可配。
- **平台服务费（SA01 修改批准）**：订阅制＋按每单金额 0.1% 平台服务费；账本来源 PLATFORM_SERVICE_FEE；计费基数建议实付金额、退款按比例冲回（PRD 修订定稿）；入平台总账与 ROI 成本；费率调整仅平台超管留审计；订单完成结算时同事务计提，失败进补偿队列。

## 3. 派单域设计

### 3.1 派单模式矩阵

| 模式 | 入口 | 匹配机制 | 关键事实 |
| --- | --- | --- | --- |
| 公开抢单 | 老板下单选公开 | 抢单池＋持久化时钟＋截止仲裁 | 入池时通行证可见快照、提交时间上下界、排序指标快照 |
| 客服指派 | 客服安排 | 客服在合格候选中指定（不能指定陪玩绕过资格） | 指派依据、资格复核 |
| 试音选人 | 付款后发布招募 | 报名（本人录音库/新录音）→ 老板试听选人 | 录音快照、报名周期、选人确认 |
| 预约 | 老板选陪玩/档期 | 单陪确认/双陪分别确认→付款转单 | 档期占档、确认截止、换人重选 |
| 老板指定 | 下单直选 | 资格校验后直接成单 | 资格快照 |
| 客服代派（SA05） | 派单工作台 | 频道内用户委托→跳单试听→客服选人付款 | 一组一单、默认试音、用户确认付款选择 |

### 3.2 调度引擎（正式化，M3 核心）

- **持久化时钟**：抢单窗口/总等待/预约截止/收益冻结全部数据库时钟；禁止内存时钟回落；时钟不可用时阻断新单扣款与即时分配（现有守卫保留）。
- **池与可见性**：入池时本人通行证状态＋门店延迟配置决定可见时间；公共组仅发刷新信号不含订单编号；个人消息按资格/归属。
- **仲裁排序**：等级/接单额/好评率/提交时间四级；近 30 天有效评价精确比率比较；完全同分延长重开窗口；证据不足先保存待恢复分类；人工核对入口（授权人员查看证据/申请恢复仲裁）。
- **双陪组队**：邀请/确认/超时替换/席位空缺补选；每席改派＋转单合计≤2 次（C1 批准维持）；转单技能/等级校验（借鉴东东）。
- **逐店隔离**：池/时钟/仲裁/扇出任务全部携带门店上下文；跨店同编号互不可见。

### 3.3 派单工作台（SA05 批准：KOOK 深化）

- 频道分组↔派单组映射；子房间管理（名称/公告/欢迎语/房锁/麦序/发言间隔）经 KOOK 能力映射，原生 WebRTC 二期。
- 客服代派：一组同时仅一单；默认试音；陪玩跳单入房→老板试听→告知客服→客服选中付款（划扣用户余额，可选尊享卡/通用本金，用户确认）；实名开关开启时未实名弹窗阻断（SA06）。
- 调度操作：送用户入客服房、麦序调整、进行中订单操作权限收敛（陪玩本人/老板为主，客服慎操作留审计）。
- 本地混响/背景音乐：KOOK 侧能力，平台仅配置开关与审计。

### 3.4 订单生命周期操作扩展

- **提前完成（SA08 批准）**：小时单实际时长＜45 分钟按半小时、≥45 按 1 小时（阈值逐店可配）；局单一次完成确认、部分完成退剩余；独立入口＋审计；与协商终止互斥不叠加。
- **免单（SA07 批准）**：售后期内门店主动减免；门店承担、陪玩按原应得结算；粒度 0.1 元可配；FREE_ORDER 来源走现有退款资金链；排行/流水口径扣减（店内维度）。
- **转单/改派**：资金版本＋逐段收益＋到账 RELEASE 沿用现有受控组合链路（开关分批开启）；技能/等级校验前置。
- **计价单位约束**：小时＝60 分钟整数倍；局单默认长周期（防跑单）可配。

### 3.5 通知与恢复

- 派单/抢单/预约/转单/结单事件同事务 outbox→逐店扇出投递→失败重试→账号周期变化跳过；站内＋KOOK＋企微渠道矩阵；真实短信/微信推送待 M6 渠道接入；通知失败不冒充业务失败。

### 3.6 权益与降级

- 派单能力按 License 档位与增值配置裁决（抢单/预约/试音/房间/代派键入权益矩阵）；控制库故障按签名快照降级：保留存量订单履约与资金闭环，暂停新增匹配入口；恢复重验。

## 4. 三端落点与状态设计

- 老板端：下单/预约/试音试听/我的卡/关注/动态/保障公示；加载/空/错误/有数据共用真实页面结构；未知金额不记 0。
- 陪玩端：抢单池/试音报名/档期/履约报单/收益/招聘申请/动态；服务状态开关决定派单可见。
- 后台：开业自检清单/配置字典/派单工作台/订单操作（提前完成/免单/转单）/导出/审核工作台/经营面板/增长配置。
- 平台：门店台账/保证金/费率/权益矩阵/合规规则库/跨店授权聚合。

## 5. 验收映射（编入 T 序列提案）

开业阻断项门禁；证照过期阻断与存量保留；合规校验留痕；保证金与闭店公示；0.1% 服务费计提与退款冲回对账；卡线全场景（37 §6）；抢单时钟故障阻断；仲裁同分/证据恢复；双陪席位替换；代派一组一单/默认试音/实名阻断；提前完成取整边界（44/45/46 分钟）；局单部分退；免单资金链与承担；导出权限审计；增长七模块逐店隔离；权益降级派单入口暂停与存量保留。
