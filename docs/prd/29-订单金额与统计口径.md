# 订单金额、退款与统计口径

状态：本页整理用户截至 2026-11-06 确认的目标；现有系统是否已记录所需金额和份额，须参照[差距与验收](07-差距待决与验收.md)及源码专项核查。页面展示、业务分成、福利、报表和真实资金分别使用不同事实，不能让一个 `amount` 字段承担全部含义。

## 1. 一笔订单的三个金额

假设一笔单陪服务按所选服务和购买数量计算，优惠前原价 **250 元等值**；按最新比例折扣互斥及用券规则处理后成交 **200 元等值**；老板使用积分抵扣 **30 元等值**，最终钱包实付 **170 元等值**。这里的人民币等值用于说明，店币支付不等于真实收取了 170 元现金。

| 事实 | 示例 | 用途与限制 |
| --- | ---: | --- |
| 优惠前原价 | 250 | 对外接单额、派单额、下单额、老板消费榜以及抢单排序接单额，按适用对象及本人份额使用；不是钱包实扣或现金实收。 |
| 优惠后、积分抵扣前成交额 | 200 | 按本单规则计算陪玩服务分成，判断已确认的续单奖励 188 元门槛；保留会员、活动及券的真实优惠明细。 |
| 积分抵扣 | 30 | 使用本店积分及付款时汇率、上限形成的抵扣等值；积分独立记账，不能写成店币付款或现金退款。 |
| 实际支付店币 | 170 | 用于与订单金额关联的岗位提成、绩效、适用福利及会员实销；可能由本金、赠送、赔付构成，并不天然等于现金实收。固定底薪仍按岗位薪资方案计算。 |

用户明确了两项重要例外：陪玩收益和续单奖励门槛按 **200 元成交额**，不因积分抵扣改按 170 元。若陪玩应得比例为 80%，本例应得 160 元等值；如该单符合续单其他条件，200 元严格大于 188 元，仍可获得约定奖励。客服派单提成、客服绩效和店长绩效按适用的 **170 元实付**计算；按原价显示的 250 元不作为这些岗位提成的付款基数。

普通订单抽成产生小数店币时，用户确认陪玩收益沿用现有最小记账单位，不强制取整到整数店币：成交 253 店币、门店抽成 20%，应得为 202.4 店币，即现有 2024 内部记账单位。老板支付、退款店币和陪玩承担退款分摊仍按各自已确认的整数店币规则，不能把这些规则无差别套到普通收益。

邀请人佣金按主服务订单实际支付店币乘推荐比例；加购不产生推荐佣金。本例推荐比例为 10% 时，基数 170、佣金 17 元等值。未发佣金按退款后的主单净实付计算；已发推荐佣金后续退款不追回。陪玩收益和不足时的门店补资独立核算。

## 2. 原价指标与实际退款

1. 老板消费榜包括礼物；服务订单和礼物的对外原价指标与本店实际支付、人民币实收分开。成就和会员标签仍按本店已确认实销的非礼物订单统计，不能因消费榜包含礼物而扩大成就范围。
2. 原价指标部分退款时，按**本次退回店币及退回积分的原单等值合计**冲减。以上订单若部分退款 50 元等值，其中退店币 42.5 元等值、退积分 7.5 元等值，原价统计净额为 `250 − 50 = 200` 元等值；店币退款和积分返还分别记账。
3. 最后一次全额退款时，**补齐冲销该单原价指标剩余部分，使原价统计净额为 0**。继续上例，后续退完其余实际支付构成后，原价指标再从 200 归零；这一步的统计补冲不代表额外向老板退了 200 元钱包，也不能制造不存在的现金或店币退款。
4. 多人履约时，抢单排序的接单额使用本人对应原价份额，扣本人分摊的退款等值；退款方案明确只影响某人时按真实归属冲减，未指定归属时按各人原价份额比例分摊。**涉及陪玩承担的分摊金额分别向上取整到整数店币，每笔退款独立取整，超出实际退款的差额归所属门店并形成真实资金流水。**例如双陪原价份额各 125 店币、需要由两人分摊并实际退给老板 51 店币，每人理论承担 25.5、取整后各承担 26；老板收到 51，门店取得多出的 1，个人接单额各为 99，整单原价净额为 199，二者相差的 1 是有据可查的门店取整差额，不是额外退给老板的钱。部分退款时若某人实际承担超过本人原价份额，个人接单额最低显示 0；全退后每人也为 0。每人的实际承担与门店逐笔取整收入保留，超出本人份额只作明细说明，不能作为另一笔门店收入重复记账。老板退款按整店币向下，预约报价按整店币向上，各自独立处理。订单总体、各人份额及差额应能核对，不能把整单原价重复计到每一位陪玩；历史真实份额不明时先核对。
5. 统计冲减、店币退款、退还抵扣积分、消费积分冲回、服务收益冲正及已发推荐佣金是否追回是独立事件。部分退款退老板店币向下取整至整数店币、积分按其最小单位向下取整，最后全退补足支付构成；店币按本金→赠送→赔付顺序退回，仍按[订单资金规则](05-跨端订单资金售后.md#21-积分抵扣示例)执行。

**与实付关联的工资绩效及 VIP 成长另按退回店币冲减。**上述示例原实付 170，退回店币 42.5、积分 7.5 元等值后，本单实付业绩净额为 `170 − 42.5 = 127.5`，不是 `170 − 50 = 120`。会员成长仍需满足实销确认及 VIP 状态等条件；已确认工资与跨月调整按薪资规则处理。原价指标则按 50 元等值冲减为 200，两者不可混用。已发消费积分只按本次实际退回的本金及对应发分规则冲回，退还的抵扣积分也要独立记账。

## 3. 排行、工资与经营报表

| 场景 | 归属及基数 |
| --- | --- |
| 抢单自动分发的接单额 | 陪玩开始实际履约后才纳入本店最近 30 天统计，按本人每次接入时间和对应原价份额分别归属；扣本人分摊退款等值，个人单笔净额不低于零，整单全退冲销剩余原价。已接但未开始履约不计入。 |
| 抢单自动分发的好评率 | 本店近 30 天有效评价中，综合评分 4–5 星的比例；无评价为 0%。不是综合评分平均值。 |
| 陪玩接单数量榜 | 每位实际履约者同单计一次，按本人最后履约结束或转出时间归属；即使全退仍保留该次真实履约记录。此榜单时间不等同抢单排序金额的接单时间。 |
| 客服及店长工资业绩 | 按实际支付的适用金额及实际工作归属，退款只冲减退回店币；退款和已确认工资按退款月、下一期调整及提成结转等规则分别处理。固定底薪按薪资方案独立计算。 |
| 老板会员成长与消费积分 | 满足实销及 VIP 状态规则；会员成长按实付减退回店币，礼物实付本金支付成功立即计成长，退款按实退本金冲回；消费积分只按实付中的本金及付款时适用倍率，赠送、赔付不赠分。 |
| 经营报表与 ROI | 原消费按付款月、退款按发生月；订单净消费、投产比分子和利润中的订单收入均按实付减退回店币，返还抵扣积分单独展示，不重复冲减收入。原价指标不代替实付或现金。赠送／赔付被消费时按已确认规则计成本一次，平台公共薪资单列。 |

例如订单实付 100 元等值，其中本金 80、赠送 20，陪玩成本 80，其他成本为零时，经营净消费展示 100，利润为 `100 − 20 − 80 = 0`。抵扣已经减少实付时不能再将同一抵扣额重复作为费用扣一次；实际线下收付款需以真实收付款记录单列。

**特殊玩法加购**：用户确认加购计入对外下单额、陪玩接单额、客服派单额、抢单排序接单额、老板 VIP 成长和员工工资业绩，各自仍执行上表原有口径。例如主服务原价及实付均 1,000 店币，服务中再按原价实付加购 350 店币，两者均符合相应确认条件且没有退款时，下单额合计 1,350 店币；VIP 成长及员工工资业绩分别核对 1,350 店币实际支付中的适用部分。加购原价归入对应陪玩及派单人员的指标份额；抢单排序仍按本店近 30 天、本人接入时间、开始实际履约和本人份额等条件处理，不按整单重复计给多人。消费积分只按实际使用本金、付款时倍率与开关等既定条件计算；工资归属按实际工作确认。售后对主服务及各项加购逐项确定退款，分别按各自退款记录冲减，不能把“主服务全退”等同为加购全退；需要保留每笔付款、原价与来源并避免重复汇总。

## 4. 保存与三端展示

- 老板端可同时查看原价、适用优惠、积分抵扣、实际支付、退款的店币与积分以及必要的余额来源；任何一项都不应被另一项覆盖。
- 陪玩端区分原价接单指标、按成交额计算的本人服务应得、待结算与可用余额；接单额不是钱包收入。双陪与转单保存每个实际参与者和每次履约的份额；历史已结算后转回也不能覆盖旧流水，新产生的转出份额不得在整单完成前结算。
- 后台展示订单原价、成交、实付、积分、退款、各人份额及工资／经营核算依据；平台汇总必须标明门店、币种、数据范围及缺失门店。
- 每笔支付和退款应保留服务价格、适用优惠、本人份额、积分汇率、支付来源、操作人和规则版本。后续改门店配置不应重写已完成交易或假造原价；旧数据缺乏可靠来源时标为待核对。
- 老板获得的推荐佣金归本金；抽奖和客服赠送归赠送；赠送、赔付消费不产生消费积分。礼物只用本金，不使用积分、赠送或赔付支付。

## 5. 待执行验收

| 场景 | 应核对结果 |
| --- | --- |
| 原价 250、成交 200、积分抵 30、实付 170；陪玩收益率 80%，本人已开始履约且原接单时间在近 30 天 | 原价指标及抢单排序显示／计算 250；陪玩初始应得 160；按订单计提的岗位提成、绩效及适用福利按 170，固定底薪按薪资方案，续单金额门槛按 200。 |
| 上例部分退款 50，其中店币 42.5、积分等值 7.5；再全退 | 原价指标先为 200，再归零；工资绩效、符合实销条件的 VIP 成长及经营报表订单收入先按实付净额 127.5 计算；真实店币及积分各按原构成退回，消费所得积分按退回本金冲回；统计补冲不产生虚假退款。 |
| 双陪原价各 125 元，部分退款 50 元等值；分别测试未指定归属及只影响其中一人 | 未指定时各冲减 25、净额各 100；明确仅影响某人时按真实归属冲减。抢单排序使用各自原价份额，汇总不重复整单，实际退款及份额可追溯。 |
| 双陪原价各 125 店币，分摊实际退老板的 51 店币 | 按 25.5 各向上取整为 26 店币，老板实际收到 51，门店取得 1 店币真实差额；个人指标各 99、整单原价净 199，取整差额独立可核对。 |
| 双陪原价共 10 店币、每人份额为 5 店币，分十次各退 1 店币，由两人等分承担并全额退款 | 每笔各人均由 0.5 向上取整为 1；十次合计老板收到 10、A 和 B 各承担 10、门店获得真实差额 10，不按累计退款撤销前次差额；全退后两人的原价接单额均显示 0，超额承担单列明细。 |
| 老板购买礼物及服务，分别查看 VIP、消费榜、成就、钱包及经营报表 | 礼物支付成功立即按本金实付计入 VIP 成长、退款按实退本金冲回；消费榜含礼物且按原价退款净额；成就排除礼物并按实销规则；钱包和经营报表不把原价当实付。 |
| 老板实际实付含赠送或赔付余额；随后发生退款 | 工资及会员实销按适用实付口径，积分仅按本金；经营成本与退款分别按真实来源、月份及既定规则核对。 |
| 一单在 11 月付款、12 月发生退款，员工 11 月工资已确认 | 经营原消费归付款月、退款归发生月；已确认工资不改写，提成与发生月绩效分别按已确认规则调整。 |

以上场景均待在隔离环境以真实业务接口与数据库执行；本次文档检查不代表资金链、统计报表或外部支付已经通过。
