## 2. 本轮已确认的目标口径

1. 会员累计按本店**已确认实销的实际支付**计算，部分退款只冲减退回的店币。礼物订单只用本金，用户已确认该实付本金在支付成功后立即计入 VIP 成长，后续按实际退款本金冲回；受 VIP 开关等已确认规则约束。当前代码的会员实销排除礼物，需增加真实确认及退款关联；成就仍排除礼物。扣除积分后的赠送和赔付店币仍属于实付，但不是现金充值。消费积分只由实际使用的本金产生，按付款时的本店 VIP 等级／普通会员倍率和适用生日规则快照计算。赠送、赔付及积分抵扣部分不产生消费积分，礼物本金的消费积分与其不能使用积分抵扣是不同问题。
2. 支持老板符合条件的陪玩服务订单及陪玩通行证用本店积分抵扣；体验套餐和礼物暂不支持。会员、门店活动、折扣券等所有比例折扣互斥；每单最多一张券，金额券可按资格叠加会员或门店活动折扣、不能同单折扣券。积分只按门店配置完整组使用，不得约分拆组；单笔抵扣比例必须低于 100%，实际店币支付不能为零。陪玩报酬和续单奖励门槛以抵扣前适用成交额为基数；工资绩效、会员成长、消费门槛按各自已确认的实付口径。
3. 付款构成分本金、赠送、赔付和抵扣积分；全退按原构成归还，部分退款先按店币／积分比例分配，再按本金→赠送→赔付退店币，最小单位向下取整，最后一次全退补齐。已发消费积分按实际退回本金冲回；抵扣积分返还是另一笔流水。
4. 每店可配置不同数量的 VIP 等级及门槛、折扣、积分倍率、券和权益。仍启用等级的券条款变化与取消等级、退款降级是不同事件：普通条款修改时，已发未用券按已确认规则更新；月券数量修改从下次发券生效；等级取消时该等级已发未用券保留取消前条款。
5. 退款导致 VIP 降级时，**已发未用月券、升级券、安全箱券及未交付权益全部保留**，之后新发权益按降级后的等级。本月已发未用月券保留降级前原条款；已使用券、已交付权益和订单历史保留。不能以“取消的 VIP 等级”规则、礼物退款规则或系统当前实现替代该决定。
6. 保留积分商城商品及老板抽奖，停止商城用积分直接兑换钱包余额；老板抽奖中的余额类奖品仍可保留。门店修改抽奖保底**次数**时个人未中奖计数从零开始，历史抽奖、中奖及积分事实保留。
7. 老板在月中升级时，本月不补发月券，已经发出的月券保留原条款；从下月按新等级发券。这与门店修改仍启用等级的券条款属于不同情形。
8. 同一门店允许多个积分抽奖同时开放，老板在可用活动中自行选择；各活动的奖池、积分消耗、次数和保底需独立对应。
9. 礼物订单退款后若不再达到赠礼活动门槛，已发礼物相关权益、标签及完整冠名有效期保留，不因退款撤销或缩短。
10. 停用 VIP 后已发有效券保留，等级折扣和消费积分发放停止，停用期间付款的消费不计日后成长；付款或实销其中任一时点 VIP 停用，该笔消费积分不发。
11. 积分发放、抵扣、商城、抽奖任一项停用时，积分使用整体暂停，已有积分和中奖权益保留；全部重新启用后自动恢复。只停用抽奖而发放仍启用时，符合条件的消费继续发分，VIP 停用等独立资格仍需同时满足。

## 4. 需要业务确认或进一步核实

以下是有明确源码依据、且与已确认规则不矛盾的边界；不能将待确认选项当作已实现或已承诺的业务行为。

1. **已解决的边界**：只更换保底目标奖品但次数不变时保留原计数；赠礼退款不缩短已取得的直接冠名期限；停用 VIP 后已发有效券保留但等级折扣及消费积分发放停止；全退返还的 VIP 券仍有效时保留原使用条款。
2. **开关实施核验**：积分四项能力任一停用暂停所有积分使用，已有积分和中奖权益保留；其他条件满足且发放开关仍开启时可继续发分，四项全部启用后自动恢复使用。退款返还与冲回不因暂停使用而丢失。

## 5. 补充场景验收清单

以下均为**待执行验收**，不表示本次已运行测试。

| 场景 | 应核对的结果 |
| --- | --- |
| 两店 VIP 等级数与倍率不同，老板分别下单、改变等级后完成订单 | 本店报价和付款时倍率快照正确；另一店数据不参与。消费积分只按本金，退款不重读当前倍率。 |
| 在同一月分别修改月券条款、减少数量、取消等级、退款降级 | 四类事件各走各自规则；降级后所有已发未用券与未交付权益保留，本月券保持原条款，发放数量和历史核销可核对。 |
| 同时持有可叠加的积分及不优于 VIP 折扣的折扣券 | 服务器返回实际优惠与所需付款；券未产生优惠时不误核销，积分只在合资格服务中按上限使用。 |
| 普通券和资格券分别全退；普通券发生协商终止部分退款；返券后原有效期已过 | 按核销快照显示对应结果；资格券与普通券不混同；已过期券不能作为有效券再使用，历史退款结论保持稳定。 |
| 积分商城直接请求余额商品；另以相同 `BALANCE` 类型作为真实奖品抽奖 | 前者被后台和直接接口阻断；后者真实中奖才发赠送余额，钱包及权益显示抽奖来源；重试同请求不重复发奖。 |
