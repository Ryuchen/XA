# 三端页面与功能追踪清单

2026-11-11 前端增量：新增后台 `workspace/modules` 与平台 `platform/overview/clubs/orders/modules/finance/accounts/security`，三端订单摘要复用统一状态模型。模块/购买/定制及新增接口见[产品模块与三端闭环](34-SaaS产品模块与三端前端闭环.md)，不改写下列历史验收统计。

日期：2026-11-06。用于发现遗漏和建立“页面动作 → 后端事实 → 其他角色”的追踪关系。**本清单不是本轮功能通过报告。**

## 核对方式与新旧差异

- 对照当前 [`老板端 App.tsx`](../../fronted/boss/src/App.tsx)、[`陪玩端 App.tsx`](../../fronted/provider/src/App.tsx)、[`后台 App.tsx`](../../fronted/admin/src/App.tsx) 和 [`后台导航`](../../fronted/admin/src/lib/navigation.ts)。当前可见 35 个老板正式路径、20 个陪玩业务路径；后台导航配置有 44 项，另有 `dictionaries` 业务路由未在该静态导航清单直接列出。兼容跳转、默认路由与通配路由不按新业务页面重复计数。
- 陪玩 `/auditions` 在当前路由中存在，但不在原 19 页矩阵中；其公开招募及样本提交显示待开放，不能当作新的订单招募试音已经实现。
- 下表沿用 [2026-11-05 原始逐页矩阵](../../fronted/verification-matrix.md) 的 R／W／E／F 业务动作定义，并补充 P20。**它是历史盘点，不是针对 2026-11-06 每个路由、按钮与权限的重新实测结果。**
- 原表中的切换门店、兴安旧币名、店内财务、单级提现审核、旧押金和旧薪资权限均已过期，以[平台与权限](01-平台门店与权限.md)、[跨端资金](05-跨端订单资金售后.md)及[积分薪资](06-积分薪资经营.md)为准。老板／陪玩页面不得出现切店；后台统一通过验证身份识别门店。
- 老板 B10–B15、P01–P05／P12、A06／A09／A18–A19／A50–A55 还须覆盖本轮门店前缀、微信头像、试音录音、积分抵扣、新押金、平台财务与薪资等新增目标；历史条目未列不表示无需实现。实际管理端登录方式及动态验证码以现行入口和最新约定核对，不以旧条目的 TOTP 或短信描述单独推断已完成。
- 历史积分商品中的直接兑换钱包余额已被用户取消；老板／陪玩仍保留其他积分商品及现有积分抽奖。表中旧兑换动作需按此新目标复核，历史记录保留。
- 积分抵扣用于符合条件的陪玩服务订单和陪玩通行证；礼物订单、体验套餐暂不支持。历史 B09／B16 等页面动作应按该范围和服务端校验同步复核。
- 原有共享客服会话池需增加领取、交还、转交及主管重分配；只有领取人和授权主管可查看聊天内容，普通未领取客服不得通过消息预览、接口、实时推送或图片查看。订单咨询新增正式关联与卡片，详见[咨询消息](15-咨询消息与通知.md)。
- 活动、VIP、预存、资格与抽成按[统一门店配置](12-系统字典与门店初始化.md)复核；历史矩阵提到的原字段和固定值不能代替新配置真实生效验证。
- R＝读取，W＝实际操作，E＝权限与异常，F＝资金及门店边界。页面和动作的实际完成、未覆盖项与问题按[差距及验收](07-差距待决与验收.md)逐项回填。
