# 仓库目录与工程边界

本仓库是单仓多工作区。目录名称和部署命令应与实际入口一致，变更时同时维护调用者、依赖锁文件及部署配置。

| 目录或文件 | 职责与入口 |
| --- | --- |
| `fronted/` | 三端 React 工作区、共享模块及微信授权桥接；由自身的 `package.json` 和 `package-lock.json` 管理 |
| `services/backend/` | Django 业务服务、管理命令、数据结构迁移和后端测试 |
| `packages/money/` | 根 pnpm 工作区使用的金额工具 |
| `docs/licenses/shadcn-vue/` | 已退役适配包保留的上游许可及说明 |
| `deploy/` | 本机开发、代理和部署配置；日常入口为 `deploy/dev.ps1`，Compose 编排集中在 `deploy/compose/` |
| `scripts/` | 仓库级检查、隔离联调和运维工具，见[脚本说明](../../scripts/README.md) |
| `docs/prd/`、`docs/development/` | 已确认产品规则、研发设计和进度 |
| `docs/architecture/` | 仓库结构说明，以及保留日期的架构、数据模型和流程参考 |
| `docs/ops/`、`docs/history/` | 运维说明、验证记录及历史快照 |
| `design-demos/` | 既有设计资料和原型，部分预览配置仍引用其中内容 |
| `.github/workflows/` | 持续集成与镜像发布工作流 |
| 根目录包管理和项目说明文件 | 被命令、脚本或工作流直接引用的工程入口 |

`.venv/`、`.tools/`、`node_modules/`、私有环境变量和运行时数据是本机资源，不属于应移动或提交的业务源码。具体忽略规则以根目录 `.gitignore` 为准。

仓库仍有被现有测试或文档引用的历史脚本和设计资料，部分脚本引用已移除的 `apps/`。已无调用者且依赖退役端的脚本，以及不适用于首版的腾讯云旧容器迁移脚本已删除；剩余项目需逐项核对调用关系后再处理。

当前三端源码和本机容器挂载使用 `fronted/` 这一既有路径。若将来调整该路径，须在协调并行开发后同时更新 npm 工作区、构建命令、容器挂载、测试、CI 和部署入口，并在隔离环境验证。
