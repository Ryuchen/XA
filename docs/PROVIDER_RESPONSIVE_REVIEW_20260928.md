# 陪玩端双端界面修订

## 设计依据与改造前检查

本轮以管理端的共享蓝色品牌、灰色页面背景、分层卡片、清晰边框与统一控件为依据，采用保留品牌的界面演进。设计变化度 4、动效 2、信息密度 5。继续使用 Taro / React 和现有共享设计系统，不另混入桌面专用 UI 库。

保留 13 个页面路由、五个主导航入口、原有字段顺序和订单 / 报单 / 提现 / 档期业务约束。营销页相关技能规则仅在适用的展示部分采用。

线上桌面及 390px 手机检查发现：钱包摘要被限制为 720px，下方账户与流水却铺满；原生按钮大小及背景不同；表单仍是手机布局；固定底部弹层缺少桌面居中和内部滚动；rpx 间距与固定字号混用，H5 图标也随屏宽放大。部分详情页还有硬编码白底，深色模式的层级不一致。

## 已完成的修订

- 建立陪玩端公共尺寸规范：主操作与输入框 44px，紧凑操作 36px，卡片圆角 16px，控件圆角 8px。陪玩端布局数值改为稳定像素，图标不再随桌面屏宽放大。
- 960px 以下采用单列内容和底部导航；960px 起采用侧栏与宽内容区，内容上限 1280px。窄桌面侧栏为 208px，普通桌面为 224px。资料页在宽桌面分为展示资料和每周档期两张并列卡片。
- 统一页面标题、说明、操作按钮、卡片边框与内容间距。修订登录、接单、报单、消息、钱包、个人中心、资料、技能、账户、评价、帮助、消息详情、试音共 13 个路由。
- 钱包摘要、收款账户、资金概览和流水使用一致内容边界；订单、技能和报单长文字可换行；上传区与表单字段分组，标签与控件在双列时保持对齐。
- 回复、拒单、提现和账户编辑共用弹层：桌面居中，手机底部展开，正文可滚动，操作栏保持可见。H5 支持初始聚焦、Tab 循环、Escape 关闭和关闭后恢复焦点。
- 筛选选择器和订单选择框在桌面居中，手机使用底部操作；内置确认框统一品牌色与深色模式。
- 修正 Taro `disabled="false"` 的网页表现和键盘语义。Taro 输入框会拦截原生按键，弹层改为捕获阶段处理焦点。修正深色文本域内部白底、主按钮文字对比度、二级页面导航选中状态及桌面返回主栏目行为。

沿用原有字段顺序、金额单位、接单资格、报单审核、提现报价与并发约束。预览中的示例订单、收款账户和余额仅用于本机 UI 检查；本机服务拒绝业务写入请求。线上验收使用既有零余额测试陪玩账号，只执行登录与页面读取。
