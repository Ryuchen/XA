# 资金请求成功回执与重试恢复

更新：2026-09-23。承接 [当前 PRD](PRD_CURRENT.md) 的资金防重要求，本轮修复客户端丢失成功响应后的恢复能力，不调整价格、抽成、提现和通行证商业规则。

## 问题与处理结果

原生端收到重复请求提示后一直保留交易编号，但服务端没有返回原订单；相同载荷再次提交仍只能得到重复提示。H5 则会清除收到重复提示的编号，无法区分“已取得原成功结果”与“仍需核对结果”。

现在下单、完成订单打赏、通行证购买、押金缴纳和提现申请都在资金事务内保存成功回执。客户端继续用原编号重试，后端先检查回执，再检查会随业务变化的余额、商品上架、报价和提现门槛。成功恢复后不再执行业务写入，也不重复投递业务通知。

| 场景 | 当前处理 |
| --- | --- |
| 同账号、同编号、同接口和载荷 | 返回原成功回执；新客户端恢复原操作结果，并结束本次请求 |
| 同编号改变接口、来源订单或参数 | `REQUEST_ID_CONFLICT`；不扣款、不返回不相干的成功结果 |
| 两个请求同时首次到达 | 唯一键和原业务行锁决定一次写入；竞争失败方再次读取已提交回执 |
| 另一账号使用同样编号 | 按账号隔离，不能读取其他账号回执 |
| 保存回执失败 | 与本次扣款、流水、业务记录和幂等键一起回滚 |
| 旧编号没有成功回执 | `FUND_RESULT_UNAVAILABLE`，继续保留编号并提示核对记录；不猜测历史订单、不生成新的扣款请求 |
| 已恢复后用户另行确认同样商品 | 新编号代表下一次购买，可正常下单 |

## 接口和客户端约定

新增迁移 `wallet.0026_idempotency_receipt` 为 `IdempotencyKey` 增加 `request_fingerprint` 和 `response`。指纹包含原接口路径及除 `client_request_id` 外的 JSON 载荷，忽略对象键顺序；回执保存原响应的 JSON 数据。历史数据不补造回执。

为兼容已有调用方，重复写入的响应仍为业务 `code:409`。可恢复的重复响应同时携带 `errorCode:FUND_ALREADY_PROCESSED` 和 `fundResult:{code:0,msg,data}`。原生 `core/api.fund` 与两份 H5 `fundRequest` 只接受这种明确的成功回执；普通 409、缺失/错误回执继续保留请求编号。H5 另拒绝将等待过程中切换账号后的旧响应交给当前页面。

回执是原操作的结果快照，不代表订单现在仍待接单、提现现在仍待审核或钱包余额未再变化；进入订单详情、钱包和通行证页面仍应读取当前业务状态。服务器升级须先执行迁移再启动新代码。测试和本地预览已迁移，本轮未部署正式服务器。

## 验证

- 新增后端 9 项场景测试，逐一覆盖五类资金操作、目录/规则改变后的恢复、参数/接口冲突、归属隔离、五类操作回执失败全部回滚，以及历史空回执。
- 新增 2 项真实 MySQL 行锁测试，其中一项覆盖五个入口同时首次提交，另一项验证第一次提现恰好耗尽余额时的第二个请求恢复。两个独立数据库连接均先读到“无回执”，再竞争提交。
- 原生页面控制器通过真实 Django HTTP 接口：首笔订单实际提交后，在测试传输层丢弃成功响应；再次点击提交取回同一订单；钱包只扣一次。退款后再购买能创建新订单。微信传输层适配为 Node HTTP，不等于微信真机测试。
- 隔离 MySQL 从空库执行真实迁移后，上述 9 + 2 + 1 共 **12 项全部通过**，日志 `.tools/fund-receipt-mysql.log`。测试库已销毁，仓库内临时 MySQL 实例已关闭。
- SQLite 完整回归 **934 项，923 通过、11 项行锁测试跳过**，日志 `.tools/fund-receipt-full.log`。该次完整回归后追加的两项并发测试及增强的 HTTP 场景另行验证：SQLite 专项 12 项中 10 通过、2 跳过；MySQL 如上全部通过，不能把 SQLite 跳过算作通过。
- 原生与两份 H5 资金请求脚本 **44 项通过**；两份 H5 TypeScript 检查通过，陪玩 H5 构建通过（保留两条既有资源体积提醒）。官方原生编译：40 个路由结构、41 个 WXML、42 个 WXSS 通过。迁移模型一致性与样式契约检查通过。

测试只使用本地隔离数据和模拟失去响应，不包含生产网络、真实转账、真实微信授权或外部派单投递。提现账户保存规则后续已确认并实现，见 [提现账户专项](WITHDRAWAL_ACCOUNTS_AUDIT_20260923.md)；参考小程序对标以及正式平台联合验收仍为未完成项。
