# KOOK 与微信客服开通指引

更新：2026-09-23。适用于当前 XA：KOOK 接收派单卡片；老板小程序打开微信客服，由工作人员在企业微信中接待。

## 先准备什么

| 项目 | 需要有权限的人 | 最终要交接的配置 |
| --- | --- | --- |
| KOOK | 俱乐部 KOOK 服务器管理员、机器人开发者账号负责人 | Bot Token、派单文字频道 ID；提醒角色 ID 可选 |
| 微信客服 | 企业微信管理员、小程序管理员、至少一名接待人员 | 企业 ID（CorpID）、官方客服链接；完成小程序企业绑定 |

平台注册、企业资料验证和管理员扫码由账号负责人完成。先在小程序后台确认是否允许绑定计划使用的企业：平台会校验主体类型、主体关系和验证状态。不要先购买第三方客服系统来解决本项目的入口配置。

本文已核对当前源码与 KOOK 官方公开文档。微信官方文档本次未能通过工具打开，因此下面的企微操作入口按功能名称给出，实际菜单、主体资格与验证要求以管理员登录后的提示为准，尚未替用户开通或验证账号。

## 一、开通 KOOK 派单机器人

1. 用俱乐部负责人的 KOOK 账号登录 [KOOK 开发者中心](https://developer.kookapp.cn/)，按平台要求完成开发者资料，创建机器人，可命名为“兴安电竞派单助手”。
2. 在机器人配置中取得 **Bot Token / 机器人 Token**。只把 Token 本身保存到私有配置，XA 会自动加上 HTTP 的 `Bot` 鉴权前缀。不要填 OAuth Client Secret 或 Verify Token。鉴权方式见 [官方 API 说明](https://developer.kookapp.cn/doc/reference)。
3. 通过机器人提供的邀请入口，将它加入俱乐部服务器。先建一个专门的“派单联调”**文字频道**，只让参与验收的人员和机器人可见；允许机器人查看频道、发送消息。
4. KOOK 客户端进入“用户设置 → 高级设置”，打开“开发者模式”；右键该文字频道，选择“复制 ID”。这就是 `KOOK_DISPATCH_CHANNEL_ID`，不是服务器 ID 或邀请链接。操作见 [KOOK 官方帮助](https://help.kookapp.cn/71dc/e7b6)。
5. 如需提醒陪玩身份组，在服务器的角色权限中复制角色 ID，检查该身份组能否被机器人提及；填入可选的 `KOOK_DISPATCH_MENTION_ROLE_IDS`，多个 ID 用英文逗号分隔。首次联调可留空。
6. 将配置交接给部署人员，确认测试频道后再启用并发送测试订单。发送接口见 [KOOK 频道消息文档](https://developer.kookapp.cn/doc/http/message)。

对应部署配置如下，尖括号内容需替换，不能原样使用：

```dotenv
KOOK_ENABLED=false
KOOK_BOT_TOKEN=<机器人 Token>
KOOK_DISPATCH_CHANNEL_ID=<测试文字频道 ID>
KOOK_DISPATCH_NEW_ORDERS=true
KOOK_DISPATCH_REJECTED_ORDERS=true
KOOK_DISPATCH_MENTION_ROLE_IDS=
KOOK_ADMIN_ORDER_URL=
KOOK_REQUEST_TIMEOUT=8
```

先保留 `KOOK_ENABLED=false`，目标频道与接收人确认后改为 `true`。正式环境填服务器 `.env.release`；可选后台链接在公网管理端部署后填实际 `/orders` 地址，不能向远程用户发送本机 `127.0.0.1` 链接。内置库模板见 [release.env.example](../deploy/release.env.example)，托管库模板见 [managed.env.example](../deploy/managed.env.example)。修改后需重新创建 Web、Worker、Beat 容器，使它们读取同一份配置。

**本机已有的容量测试和业务回归要求外部派单关闭。** 开通后另做受控的真实消息联调，不直接打开当前回归环境的自动广播开关再跑批量测试。若先在 Windows 保存，可放在 Git 忽略的 `.tools/external-integrations.local.env`，交接文件路径即可；这个新文件不会自动被部署脚本读取，接入环境仍需单独配置。

当前发送的是已支付、未过期、未指派的单陪待接订单及符合条件的拒单回池订单。已指派、双陪、礼物订单不会广播到抢单频道。陪玩收到通知后仍在陪玩 H5 抢单。KOOK 内按钮抢单、账号绑定和群指令尚未实现，因此本次无需填写公网事件回调地址、Verify Token 或 Encrypt Key。

## 二、开通微信客服并配置小程序入口

1. 进入 [企业微信官网](https://work.weixin.qq.com/) 或 [微信客服官网](https://kf.weixin.qq.com/)。已有俱乐部企业则让管理员登录；没有则先注册、完善企业资料并完成平台要求的验证。
2. 在企业微信管理后台找到“应用管理 → 微信客服”，或从微信客服管理入口开始使用。创建“兴安电竞客服”账号，设置名称和头像。
3. 邀请实际工作人员加入企业，给该客服账号配置接待人员、接待时间和分配规则。让接待人员在企业微信中确认能看到微信客服工作台。
4. 在“我的企业 / 企业信息”中复制**企业 ID（CorpID）**。在目标客服账号的接入配置中取得官方客服链接，形如 `https://work.weixin.qq.com/kfid/...`，使用平台复制的完整值。
5. 由小程序管理员登录 [微信公众平台](https://mp.weixin.qq.com/)，找到“客服 → 微信客服”接入项，按提示绑定上一步企业 ID。若后台不允许该主体绑定，先解决主体资格或企业验证问题，不能通过更换一个客服链接绕过。当前代码通过小程序接口打开已配置企业的客服。
6. 打开 [本地 XA 管理端](http://127.0.0.1:18081)，进入“运营管理 → 客服名片”，新增或编辑名片，按下表填写并启用。

| XA 字段 | 填写内容 |
| --- | --- |
| 名称、头像、公司 | 老板端展示的客服资料 |
| `wecom_corp_id` | 上一步企业 ID |
| `wecom_service_url` | 同一企业下目标客服账号的完整 `kfid` 链接 |
| 微信号、二维码、提示语 | 可选备用联系方式；二维码用可访问的图片地址 |
| 启用、排序 | 启用名片；没有指定负责客服时，按启用名片顺序选择 |

企业 ID 与客服链接必须同时填写。员工个人“添加企业微信好友”二维码可以作备用联系入口，但不是微信客服链接。当前后台显示“已接入”只表示字段已填写，**不代表平台权限和实际会话已验证**。

7. 用有体验权限的微信账号，在**真机**打开老板端，从客服页或订单详情点击联系客服。确认进入正确客服账号，接待人员能收到咨询并回复；检查订单咨询携带的业务上下文。单凭开发者工具或二维码能打开页面，不判定完整接待链路通过。

当前调用入口为 `wx.openCustomerServiceChat`，可从 [微信接口文档](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/service-chat/wx.openCustomerServiceChat.html) 和 [微信客服小程序接入文档](https://developer.work.weixin.qq.com/document/path/94739) 查看平台要求。这些是官方参考入口，本次未能在线读取其正文。

XA 目前不需要保存微信客服 Secret、回调 Token、EncodingAESKey。工作人员在企业微信接待；XA 的“消息与客服”是本系统的站内会话，不会自动同步企微聊天记录。需要在 XA 内直接收发微信客服消息时，须另行开发接口集成，配置项边界见 [凭证清单](INTEGRATION_CREDENTIALS.md)。

## 三、企业微信群派单是可选项

只有还希望在**企业微信群**里自动发派单消息时，才需要给目标群添加群机器人，保存完整 Webhook，并配置 `WECOM_DISPATCH_WEBHOOK` 和 `WECOM_DISPATCH_ENABLED`。微信客服名片不依赖此项，Webhook 不能填进 `wecom_service_url`。本项目相关规则见 [群派单说明](GROUP_DISPATCH.md)。

## 四、开通后怎样验收

| 操作 | 应看到的结果 |
| --- | --- |
| 指定测试频道，生成一笔符合广播条件的已支付订单 | KOOK 收到一张派单卡片；XA 发送记录显示成功 |
| 陪玩 H5 抢单、履约、报单 | 状态同步，KOOK 通知不代替服务端的抢单资格与并发校验 |
| 陪玩拒单回池 | 符合条件时通知新轮次，同一轮次不重复发送 |
| 打开已配置的微信客服入口 | 真机进入预定客服账号；指定接待人员能收发咨询 |
| 订单详情联系客服 | 客服收到正确订单上下文，不串到其他名片 |

先确认允许发送的测试频道，再执行真实消息验收。外部发送结果未知时先核查频道，不直接重复点击重试。

开通完成后交接四项即可：**KOOK 配置保存位置、测试频道 ID、企微 CorpID、客服链接**，并说明是否已完成小程序绑定和接待人员配置。密钥留在本机私有配置或服务器中，无需粘贴到聊天。
