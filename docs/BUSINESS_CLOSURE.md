# 业务闭环与验收记录

更新：2026-09-10。承接 [29 项菜单核对](ADMIN_FUNCTION_AUDIT.md)，本轮继续检查三端资金操作与运营配置的衔接。后台新增“通行证管理”，现为 30 项菜单。

## 本轮落实的修复

1. **打手人工充值入口**：钱包管理可切换老板/打手，以业务编号定位；充值复用实收人民币、赠币、图片凭证、全局收款流水去重和实际客服记录。拒绝向后台员工/系统账号充值；打手奖罚、退押金使用各自专用流程。
2. **打手联系客服**：钱包页新增客服充值/咨询入口，从后台启用名片读取联系方式，提供二维码、客服微信、企微链接和打手编号复制；充值后返回钱包刷新余额。
3. **通行证运营**：后台新增价格、可见延迟配置与购买记录，支持编号/昵称/账号/流水搜索。校验四档完整、金额有效、延迟顺序和权限。沿用 `escort:view` / `escort:edit`，只读客服不能保存规则。
4. **通行证资金闭环**：打手扣款、购买记录、有效期和平台 `PASS_INCOME` 入账在同一事务内完成，平台流水关联打手扣款流水号；失败全部回滚。每次购买 1 天，独立续费顺延，重复请求不续费、不扣款；价格变化需重新确认。
5. **两端资金请求防重**：老板下单/打赏、打手提现/押金/通行证携带 `client_request_id`。相同操作的并发点击共用请求，网络失败与页面重开后复用设备上保存的编号；明确业务响应后结束本次操作。设备存储失败时不发起无法追踪的扣款。
6. **超时退款保护**：扫描后在订单行锁内重新确认“仍待接单且当前期限已到”。已被接走、更新期限或没有超时点的订单不会被旧任务取消；未支付订单不会凭空返款。
7. **钱包完整记录**：打手累计订单收益由服务端汇总全部成功收益流水，不再只加最近 50 条；历史流水可继续加载，刷新与分页避免旧请求覆盖新结果。后台补齐押金、平台收入、退款、通行证、税费和调账筛选类型。
8. **成就金额一致**：接口返回指标类型，老板首页消费类进度展示兴安币、订单类展示单数，与后台单位一致。
9. **发布说明对齐**：纠正“通行证 30 天折扣”和 GHCR 的过时说明。实际工作流为 Docker Hub + SSH，凭证见 [INTEGRATION_CREDENTIALS.md](INTEGRATION_CREDENTIALS.md)。

新增迁移 `wallet.0025_pass_income_ledger`：增加通行证收入类型及约束。不改写历史订单或补记历史通行证收入；如正式库已有旧购买记录，须逐笔对账后另行补账，不能自动重复入账。

## 三端主流程

| 业务 | 发起与处理 | 完成后的结果 |
| --- | --- | --- |
| 开户与接单准备 | 后台开打手账号；老板微信登录；配置认证、等级、接单条件 | 对应端可登录，停用/封禁阻止受限操作 |
| 人工充值 | 客服名片 → 人工付款 → 后台核对实收、流水及凭证 | 钱包到账，TOPUP/GIFT、充值记录及客服身份可追踪 |
| 押金 | 打手用余额缴纳，平台同事务入账；后台退押金检查在途订单与原因 | 应缴/已缴/差额、余额与双边流水对应 |
| 通行证 | 后台配置 → 打手确认现价采购 → 同档续费 | 有效期与公共单池可见时间生效，购买历史与双边流水留存 |
| 余额下单 | 服务试算 → 活动/类型折扣/券校验 → 老板下单或客服代建 | 即时扣老板余额，成交价和抽成快照固定 |
| 派单与抢单 | 校验认证、押金、容量和可见延迟；支持单陪/双陪/转单 | 订单成员、状态日志、站内通知与实时更新 |
| 群派单 | 复制文案或使用 KOOK Bot / 企微群机器人 | 对外只显示打手实得，每轮发送状态可查；未知结果不当作明确失败自动重发 |
| 履约报单 | 开始/完成服务 → 补齐入队、结单、战绩凭证 → 提交审核 | 驳回可补充重提；必要成员全部通过后一次结算，老板不再扣款 |
| 取消退款 | 客户取消、后台售后或到期任务 → 状态机与行锁 | 只退实际已支付金额、按规则恢复券、保留退款流水；已结算订单禁止直接倒退 |
| 提现 | 打手申请 → 冻结 → 后台核对人民币和打款凭证 | 通过后出款/税额入账；驳回解冻，重复审核不重复处理 |
| 礼物奖罚 | 老板购买礼物/打赏；后台奖励扣罚 | 打手/平台分账或奖罚入钱包，明细与流水一致 |
| 运营奖励 | 券领取核销、消费成就、签到与补签 | 库存、有效期、进度及奖励入账可查；KOOK 全勤身份标签由客服人工发放 |
| 客服通知 | 老板原生企微会话在企微接待；站内消息在 XA 接待 | 以业务编号定位充值与订单；两种会话当前不自动同步 |

活动规则沿用用户确认口径：活动价 80 元、抽成 20% 时，打手得 64 元，俱乐部得 16 元。原价不进入对外派单文案。
