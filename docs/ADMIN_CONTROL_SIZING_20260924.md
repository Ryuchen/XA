# 管理端组件尺寸统一

尺寸集中在 `apps/admin-web/src/styles/tokens.scss` 和 `controls.scss`，沿用 Element Plus 组件。按后续要求，`App.vue` 通过 `el-config-provider size="small"` 全局启用小号，包括弹窗、登录页和手机端。

| 场景 | 高度 | 宽度规则 |
| --- | --- | --- |
| 全局按钮、输入、选择、日期、数字控件 | 32px | 按钮至少 72px；表单文本控件填满当前列 |
| 普通筛选框 | 32px | 180px，统一换行，不自动拉伸 |
| 日期范围 / 日期时间范围 | 32px | 280px / 360px |
| 表格内控件、分页、小号控件 | 32px | 按内容及列宽布局 |
| 登录页控件 | 32px | 沿用容器宽度 |
| 手机普通控件 | 32px | 筛选框占满当前行 |

- 统一圆角 6px、字号 13px、水平内边距与按钮间距；保留圆形图标按钮的形状。
- 多选框与文本域可根据内容增高，避免裁切。
- 数字步进按钮按输入框高度排列；原生文件上传按钮采用相同规格。
- 修复日期范围框被 flex 拉长、分页输入框 40px 与页码 32px 混排、小号按钮被强制拉高的问题。
- 业务数据、接口及权限没有变更。

## 验证

- 管理端 TypeScript / Vite 构建通过；只更新本地 `admin-web` 容器，入口 18081。
- 初版完成后按用户要求改为全局小号，取消原来的常规 40px、手机 44px 和登录大号覆盖。
- 分类设置表格检查了小号输入、开关和数字控件。
- 最终实测：老板信息页筛选输入与下拉均为 180×32px，查询按钮 72×32px；编辑弹窗输入、下拉及底部按钮均为 32px 高。
- 操作审计页日期范围框为 280×32px；390px 手机视口中筛选控件与按钮也均为 32px 高，无整页横向溢出。
