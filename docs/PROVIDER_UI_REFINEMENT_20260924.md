# 陪玩端界面优化

## 设计与范围

保留兴安电竞品牌、蓝色主色和原有五个主导航入口，以可读性和日常操作效率为主。设计取值：变化度 4、动效 2、密度 5。使用现有 Taro 组件及共享设计令牌，不引入新 UI 依赖。

初始浏览器检查发现：深色主题中通行证、订单和消息使用硬编码白底，浅色文字对比不足；字号偏小；订单列表与页面双重滚动；手机和桌面信息密度不一致。

## 实现

- 陪玩端独立字号映射：正文 14–15px，说明 12–13px，标题 26–30px；不修改其他端的字号。
- 统一深浅主题语义色。深色采用石墨色页面、分层卡片与清晰边界；保留品牌蓝及业务状态色。
- 接单工作台新增标题、技能入口和列表数量，梳理工作概览、通行证、筛选、订单信息层级；桌面双列订单，手机单列。
- 订单轮询和实时通知后台更新，不再每次切回加载骨架；请求失败显示重试入口，与空订单状态区分。
- 钱包、个人中心、消息、报单统一卡片、标题、按钮与空状态，移除主页面嵌套滚动；金额和业务操作沿用原有逻辑。
- 桌面侧栏支持现有系统主题，手机保留固定底部导航和安全区；减少动画并支持 reduced-motion。
