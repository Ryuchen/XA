# 资格券核销与退款规则修复 · 2026-10-06

用户本轮授权修复两个问题：不减价的资格券成功下单后也必须核销；已核销的体验超值券取消退款后不得恢复。体验单及优惠券录入仍等待明确指令，本轮不录入业务内容。

## 实现

- 新增套餐资格券类型 `QUALIFICATION`。必须绑定可直接购买的指定套餐，面额和门槛为0；每次购买一份，券本身不减价。
- 报价不占券；成功支付时在钱包与券行锁事务内核销，保存关联订单及使用时间。资格券核销不再取决于 `coupon_discount > 0`。失效、错档、错账户、重复使用及失败回滚在扣款前或同一事务中处理。
- `UserCoupon.restore_on_refund` 在核销时冻结：资格券为false，普通券为true。老板取消、后台取消、退款领域服务和超时自动退款统一读取该快照；资格券保留已使用状态、使用时间和关联订单。之后改变券模板类型不改变已核销资格的政策。
- 普通券未产生实际优惠时仍不消耗；普通券正常退款仍返还。不存在按券名称猜测类型或批量转换旧券的操作。
- 后台可选择套餐资格券并绑定套餐；老板端正确显示资格券，避免显示为金额抵扣券。新增增量迁移 `coupons.0009_qualification_coupon_policy`。
