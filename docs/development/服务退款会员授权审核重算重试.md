# 服务退款会员授权审核后的重算重试

服务订单会员成长授权 UNKNOWN 经平台审核 ALLOW 后，如审核已保存而会员等级重算仍待处理，可用同一请求编号、结论和原因重试。入口重新执行原审核支持的付款、实销结算和退款凭证核验，再锁定原老板钱包及账号；仅账号仍在原业务周期时调用既有会员重算。原审核、原实销和已发权益不重写，权益继续使用现有幂等及当前 License 门禁；无法重算时保留待处理。

对积分退款实销证据，该入口只在当前退款与原决定时退款一致时重试：原证据不当然证明后续新增退款。普通资金及转单分支仍受各自现有验证器支持范围限制；当前退款或原付款、结算、账号周期无法证明时继续待核对。后台定时任务保持原有行为，本次不扩展其资金证据核验。

本次未运行测试或迁移。最终需在隔离环境联调重复审核、授权恢复、多次退款、积分退款后新增退款、转单结算、退店重入和后台任务并发，核对跨库审计与锁顺序。
