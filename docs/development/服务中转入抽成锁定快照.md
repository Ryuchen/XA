# 服务中转入抽成的锁定快照

普通服务中转单会按原已购服务范围和转入陪玩解析当前门店规则，并将结果交给逐段资金记录。该路径原先锁住游戏及全局抽成配置，却在计算时用普通查询再次读取；MySQL 可重复读事务可能沿用锁前旧快照，把旧比例或旧固定额记到转入段。

转入计算现直接传入锁定读取的游戏配置及全局比例／固定额配置，继续使用既有抽成优先级、三角洲本人资格、瓦罗兰特和英雄联盟分类及固定额按成交份额分摊规则。既有计算器的 `global_rate` 参数也传给实际比例解析，避免调用方给出的锁定比例被忽略。原付款时价格与原履约段快照不改。

未运行测试或迁移。最终须在隔离 MySQL 联调门店配置修改并发转单、双陪不同资格、固定额及余数、多次转单和结算，以及两店隔离；未开放的退款及资金组合仍受现有门禁约束。
