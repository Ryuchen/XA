# 老板退店补签卡清空

退店预览的 `facts.unused_makeup_cards` 返回本月年份、月份和未使用数量；确认退店时将该数量和其余清空内容保存到原业务周期审计，并清空该月未使用补签卡。历史签到记录、已到账奖励和补签卡发放日期记录保留，不因退店删除。

签到页和签到提交与退店按本店钱包、老板账号、当月进度的顺序加锁；请求在等待期间遇到退店或重新入店时，不再用旧账号周期写入签到、钱包或补签卡。重新入店后，当日消费门槛只统计当前周期的服务、礼物和加购实付，按既有规则扣除退款；原周期消费不会再次产生补签卡。

本次没有新增结构迁移，未运行测试或执行迁移。最终需在隔离环境联调退店预览、确认与签到/补签并发、退店重入、跨午夜消费、已领签到奖励以及双店隔离。
