# 新店初始化商品选项

配置中的门店，首位管理员可以读取商品表单所需的游戏分类、服务分类、玩法、陪玩等级及资格选项，也可以读取活动商品、老板分级和 VIP 权益适用服务选项。接口分别为 `GET /api/admin/options/{game-categories|service-categories|gameplays|escort-levels|boss-types|service-items}/`、`GET /api/admin/qualification-options/` 和 `GET /api/admin/vip-tiers/service-options/`。

这些精确路径只开放读取；后台入口仍验证令牌所属门店、首位管理员身份及原接口权限，选项读取本店数据库。商品和权益的保存、授权及开业规则沿用原有流程。

初始化商品及玩法时，首位管理员还可调用 `POST /api/admin/catalog-image/` 上传商品图片；该接口继续要求 `service:edit`，使用既有图片类型、大小校验及展示图处理，不开放其他文件上传接口。

配置积分礼品与会员权益时，首位管理员可调用 `POST /api/admin/club-content-image/` 上传展示图片。该接口保留 `engagement:edit`、图片类型和大小校验；上传不代表奖品上架、授权启用或权益发放。

开发期未执行测试或迁移。最终联调须核对两家待配置门店的选项隔离、角色权限、商品表单和 VIP 权益配置，以及未营业时交易入口仍不可用。
