# 积分转单的加购经营成本

经营 ROI 对已经完成逐段结算、主服务没有退款的积分转单，按主单付款、每笔加购付款和退款、每次已确认加购交接各自的发生时间核算成本。多笔加购、多次加购退款及交接不再仅因数量超过一笔而直接落入待核对；主单仍按付款时的逐段收益快照计算，加购退款按真实承担冲减，交接按前后约定收益差额计入发生期。赠送和赔付按原付款来源及实际退回金额计算，加购不产生推荐佣金。

另支持已完成逐段结算的一类积分转单：一次主单协商退款及多笔加购，各笔加购可在主单退款前后发生多次实际退款和多次已生效换人，包括先退款再换人。主单退款后的加购事件须存在按事件顺序核对的补资释放版本，最终每笔加购来源、保留收益及退款编号须与逐段结算清单一致。主单付款、加购付款、主单退款及各笔加购退款各按自身发生期计算，赠送和赔付退回按原来源冲回；退款记录与钱包流水落在查询期间不同侧时保持待核对。每次换人后的收益变化按三方确认时间入账；换人前退款已经扣减的收益先从原收益中扣除，再计算换人差额，避免重复冲减。该分支不把陪玩已结算误认为推荐佣金已发，也不改写真实资金。

该有主单退款的新增范围须有最终逐段结算清单；未全部结算、缺少任一换人资金版本、事件顺序或逐段结算凭证的组合仍按其他已核实路径处理，否则保持待核对。`operating.verified_provider_settlement_evidence` 对本次查询中核实通过的订单，按实际钱包流水时间列示期间入账；结算状态及待结算金额为 `observed_at` 时点状态，不是历史期末余额，也不是全店汇总。整单已发推荐佣金后再发生合法退款的时序不属于此路径，具体规则分析见《积分转单已发佣金退款经营成本》。

仅在原订单逐段结算清单及有关支付、退款和交接凭证可核验时计算。凭证不完整、事件先后无法区分或现有积分转单资金能力不允许时，仍返回待核对；该变更不改变退款、分配、结算或门店授权规则。

本次按要求没有运行测试、检查或迁移。正式使用前须在隔离环境贯通多笔加购、主单退款前后多次加购退款、先退款再换人及换人再退款、部分与全额退款、不同抽成的跨月换人、三方确认、门店隔离，以及失败回滚与并发；不能将本次代码修改视作上述场景已经通过验收。
