# 门店企微群派单配置

新增 `GET/PUT /api/admin/config/wecom-dispatch/`，按既有 `dispatch_config:view` / `dispatch_config:edit` 权限管理本店机器人；PUT 接收 `revision`、`enabled`、`auto_new_orders`、`auto_rejected_orders`、可选 `webhook` 与 `clear_webhook`。返回是否已保存、解密异常、版本与开关，不返回地址。地址沿用 KOOK 的密钥加密，审计请求脱敏；开业前首位本店管理员可保存禁用草稿，启用及保存启用状态须 CONTENT_OPERATIONS 授权，授权失效仍可关闭。

常规预览、手动/自动入队、微信直付 outbox 和发送均读取本店数据库配置，不从其他门店或全局环境继承机器人。发送任务使用门店上下文，在发送前检查授权、订单、当前目标及入队时目标哈希；配置目标变化、停用或授权不可用则记录失败，由有权人员核对后重试，不改投新群。网络结果不明继续标 UNKNOWN，禁止自动重复发送。已检查且进入发送状态后使用该次已核对的目标，避免将改变后的地址传入当前请求。

仅支持现有单个群机器人及现有纯文本内容；多群路由、外部频道探测和前端尚未接入。新增 console 0038 结构迁移文件，未执行迁移、测试或建库；上线前须在空库完成结构迁移并联调跨店异步任务、授权失效、配置竞争、队列恢复、目标变更及真实企微通道。
