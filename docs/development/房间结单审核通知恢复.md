# 房间结单审核通知恢复

客服通过实际房间结单审核接口核实或驳回时，开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 和默认关闭的 `ROOM_REVIEW_NOTICE_RECOVERY_ENABLED` 后，在审核及审计事务内保存逐人通知意图。原申请提交人收到核实或驳回消息和客服说明；仅核实通过时另通知订单老板，保持原收件范围。客服重复提交相同请求沿用原审核结果，不重复创建通知。

提交后独立投递，失败由逐店任务恢复；每条申请对每个收件账号最多创建一条消息。投递核对审核人、审核结果、原订单及收件周期；核实通过的待确认消息仅在该确认仍有效时发送，异议暂停期间保留待重试，确认结束、转单失效、账号重入或来源不明时记录跳过。审核说明直接读取原申请，不另存一份私密文本。消息发送失败不回滚已提交审核；消息创建不代表客户端已收到。关闭开关沿用原周期保护的即时通知。

启用前须在各店应用 `site_messages/0025_roomreviewnotice` 及依赖，运行逐店 worker/beat。最终联调须覆盖通过和驳回、老板与原申请人、单双陪及转单、异议暂停/恢复、确认结束竞争、同请求重放、单人失败及并发恢复、双店同号、账号停用与重入、审核事务回滚。转单或协商终止自动使申请失效的路径原本不发送客服审核通知，未在本次冒充客服审核；其他实时通知仍有缺口，正式注销保持关闭。本轮未运行检查、测试或迁移。
