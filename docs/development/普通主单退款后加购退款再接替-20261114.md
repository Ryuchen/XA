# 普通主单退款后加购退款再接替

普通双陪首次正数主单退款后，已完成独立加购退款，再首次创建该付款的三方接替方案时，不再要求对尚不存在的方案提供失效记录。原退款必须早于新方案，仍须有真实退款资金版本、对应摘要和既有逐人承担；已存在的旧接替方案重提仍经原有版本链与失效凭证核对。

该核对由真实接替确认、补资资金版本和后续加购退款回放共用；实际到账 RELEASE 和最终结算继续使用既有事务入口、逐段责任和补资检查，不额外写入或伪造流水。本次不扩大服务转单后的接替能力，也不覆盖原有能力域之外的已结算、主单多轮退款或其他资金时序。

未运行测试或迁移。最终需联调首次正数主单退款、部分加购退款、三方接替确认、正数及零 RELEASE、后续逐人退款和结算，覆盖重复请求、不同门店及方案失效重提。
