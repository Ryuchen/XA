# KOOK 签到积分配置

本店管理员通过 `GET/PUT /api/admin/config/kook-points/` 读取和保存 `daily_checkin_points`（整数积分，允许零），沿用原角色、revision 与启用授权规则；未提交该字段时保留当前配置。首版默认 5 积分。每次变化记录生效时刻、版本和操作者，实际 KOOK 签到事件在配置锁内按当时配置入积分流水；同账号同日已有自动或人工流水时返回原结果，不按后来的金额再发。前后台规则展示读取本店值。

后台人工登记接口保留原日期与来源字段，新增可选 `observed_at` 表示实际签到时间。当该日期中有不同规则且未提供时间时提示补充；提供时间后按对应历史版本计算并保留时间和版本依据，不能凭当前值猜旧金额。只有签到积分变化时不改变监听连接版本，不重启语音连接、不重置在线余量；服务器、频道或启停变化仍按原配置版本安全切换。

新增 engagement/0045 结构迁移文件，未运行测试或迁移。最终须联调真实 KOOK 事件、改额与签到并发、同日人工/自动竞争、日切和授权变化、实际签到时间核对、双店隔离；语音 2 小时 1 积分及其人工在线规则本次未配置化。
