# 会员加购实销与退款联调范围

主单与每笔已付款加购分别保留实销、付款时 VIP／积分倍率和实销时授权决定。加购确认核对该笔实际付款、退款与资金来源；重复确认检查既有实销的归属及累计退款，不重新发放成长或积分。消费积分只按该加购保留本金计算；退款按该笔累计实际退回本金冲回已发积分，重复退款请求不得重复冲回。

普通逐段订单以现有最终结算和加购历史凭据为准。积分正式资金目前仍限制加购付款数量，不能因会员代码支持逐笔处理就认为多笔积分加购已开放。用户业务周期、VIP 和 License 在付款、实销时的规则及 UNKNOWN 人工核对继续分别适用。

本次未运行测试或迁移。最终联调需覆盖多笔加购先后付款、主单和不同加购退款交错、本金／赠送／赔付混合来源、全退、跨期授权变化、人工核对、重试、回滚、双店隔离和 MySQL 并发；底层未支持的资金组合继续受其门禁限制。
