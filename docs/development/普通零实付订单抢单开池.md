# 普通零实付订单抢单开池

普通非积分、非体验服务订单被优惠抵扣至零时，在付款事务内先核销优惠，再凭零额成功付款流水、订单优惠快照及实际核销券保存开池意向。提交后沿用本店数据库时钟开池、单双陪原有仲裁及恢复任务，不修改排序和时限。零额安全箱继续使用原补贴凭证校验；积分和体验订单不纳入本次范围。

到期或老板取消沿现有退款事务登记零额退款，并按券原退款规则处理权益，不虚构退款到账。正常履约结算沿已有零收益路径，不产生虚构收益流水。实际流程依赖 `GRAB_COMMITTED_OPENING_ENABLED`、对应正式时钟与单双陪仲裁配置及 MySQL 门店环境；开关仍沿原默认值。未执行测试或迁移，上线前须在隔离环境联调优惠、开池、取消、返券和结算。
