# 充值收款请求结果恢复

后台确认线下收款的充值成功时，在本金、标准赠送或待审批记录及资金来源同一门店事务中，给原操作编号保存请求摘要和充值记录关联。摘要覆盖老板标识、金额、赠送申请、收款流水、备注、档位版本及收款图片内容。相同请求重试时读取并核验原本金流水和赠送审批／到账事实，返回当前充值及审批状态，不重复增加本金或赠送；不同请求内容使用同一编号返回冲突。

并发重试在既有档位锁后再次读取回执，避免先前提交成功但余额或档位已变化时误报为新充值。回读只展示当前钱包状态及原记录，不把回执中当时余额冒充当前余额。既有不含回执的请求不按金额猜测恢复；老板身份、线下凭证、档位组合和赠送审批的原有权限及规则保持不变。

本次没有新增结构迁移，也未运行测试或迁移。最终须隔离联调线下凭证图片、标准赠送和通过／驳回审批、不同请求内容复用编号、并发重试与失败回滚、审批后回读和双店隔离；真实线下收款仍由客服独立核实。
