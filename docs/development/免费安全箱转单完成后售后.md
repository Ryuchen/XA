# 免费安全箱转单完成后售后

免费安全箱券保持单陪主套餐适用范围。同一陪玩转出再转回后，订单自然完成且尚未结算时，售后期内登记的协商可继续进入实际预览、老板和当前陪玩确认、执行及安全箱逐段结算；原有在服务中立案且期限内仍可处理的案件也沿相同路径。预览按已完成订单核验真实完成时点、原券、补贴、转单及本人分段，不把已完成履约段当作未开始段；只核定当前段，先前保留段和已确认原报酬不变。执行沿用已有同事务凭证与审计，不改写自然完成时间；整单售后等待期、本人报单审核及冻结期仍分别按既有规则计算，整单补贴余额不足仍等待。过期后新建售后、已支付补贴及未接通的其他路径仍保留现有门禁。

本次修改安全箱专属转单预览和结算计划入口，无新增迁移；未运行测试或迁移。须最终在隔离环境联调 A→B→A、服务中及完成后立案、有效期边界、双方拒绝/确认/重试、实际平台补贴、先前段报单及等待期、补贴不足、并发回滚及门店隔离。
