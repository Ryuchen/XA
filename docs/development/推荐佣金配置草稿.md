# 门店推荐佣金配置草稿

店内有字典查看或编辑权限的人员可通过 `GET /api/admin/config/referral-draft/` 读取门店草稿；具有字典编辑权限的人员可通过 `PUT` 提交整数百分比 `rate`（0–100）和读回的 `expected_version`。首次未配置返回 `rate: null`、`version: 0`；写入使用本店数据库事务、版本检查和审计。待配置门店的首位管理员也可使用该接口。

响应固定返回 `state: DRAFT` 与 `applies_to_orders: false`。草稿不会改变账号当前单独设置的推荐比例或实际订单；店级比例和个人设置的优先关系尚待用户确认，确认后仍需接入实际订单、付款快照及初始化字典。本次未运行测试或迁移；双店隔离、并发冲突、权限和实际订单接线待最终联调。
