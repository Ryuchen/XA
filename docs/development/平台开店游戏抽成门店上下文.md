# 平台开店游戏抽成门店上下文

平台超级管理员通过门店初始化接口保存游戏抽成时，三角洲规则所引用的玩法现在在目标门店上下文和事务中核验，并写入该店实际用于新订单计价的游戏抽成配置；平台身份和操作编号继续分别写入平台及本店审计。版本冲突保留原有校验，多个游戏类目并发争用同一游戏标识时返回配置冲突，不再将唯一约束冲突报告为结果不明。

当前初始化已有预存档位、VIP、游戏抽成、预约期限、积分使用与抵扣、提现规则的实际配置入口；开业核验仍按实际启用状态和已保存配置检查，部分能力受独立功能开关与外部接入约束。此次只修复平台抽成写入的门店上下文和冲突反馈，不代表所有初始化步骤或跨库并发已验收。

未运行测试或迁移。最终在隔离环境验证两店玩法编号相同但内容不同、无效玩法、平台身份与门店审计、并发保存、版本冲突、开业核验及实际订单计价快照。
