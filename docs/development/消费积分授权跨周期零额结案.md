# 消费积分授权跨周期零额结案

原消费积分授权判断为 UNKNOWN 后，平台审核确认原时点允许发放，而老板已经退店并进入新业务周期时，可在原审核入口以零积分结案，避免将旧周期权益发给新周期。仅平台既有独立授权的审核人员可操作，沿用原请求幂等和平台审计。

结案须核对原订单、消费积分授权决定、原业务周期、原付款流水及决定时已有的退款本金快照。若 UNKNOWN 来自会员成长授权，还须有该笔订单对应的会员成长授权 ALLOW 审核。锁定原钱包和账号后，确认当前周期确实大于订单周期，并存在该老板原周期的退店审计；资料不足时继续待核对。结案记录为原授权 ALLOW、零积分、`CYCLE_CLOSED`，退款本金字段保存原决定时的历史基线，不代表已经核实后来发生的退款，也不改动订单、退款或既有积分。

账号仍处于原周期时，发放仍须通过既有实际付款、当前有效退款、实销金额等完整来源检查；不能据此分支绕过资金凭证。明确 DENY 沿用既有零额结案，无法证明原授权或原始付款等事实的情形不猜测。订单逐段结算、加购及其他未被原入口支持的场景不因此扩展支持。

本轮未运行测试或数据库迁移。最终联调需在隔离环境核对多次退款、退店重入与平台审核并发、跨库审计失败重试、同请求幂等及钱包与账号锁顺序，并确认真实付款和退款凭证与各业务分支一致。
