# 积分转单已发佣金后的退款

积分转单订单的推荐佣金当前在逐段收益全部结算、整单结算时才发放。现有积分转单退款资金范围对首笔主单退款要求整单尚未结算；逐段退款前个人结算凭证只证明陪玩收益已经发放，不能代替推荐佣金已发凭证。加购退款的现有生产范围也不能据此证明整单已结算后仍可退款。

按当前首版售后规则，这个交集本身不可达：服务完成后，逐段结算须等待订单售后期限结束且本人报单冻结到期；整单最终结算和佣金入账还要求没有任何进行中的售后。期限结束后，只能继续处理期限内已经建立且仍为 OPEN 的售后，而该 OPEN 售后又阻止整单最终结算。因此未发现“合法售后仍可退款、整单已结算且佣金已发”的状态；不能绕开售后及结算边界制造该状态。不同门店的时限快照可以分别配置，不影响上述先后关系。

`orders/points_referral_refund_policy.py` 中的已发推荐佣金退款核对只覆盖无转单、无加购的积分订单，并明确排除已经发生退款的订单；当前没有发现可供报表复用的积分转单加购、佣金已发后又退款的完整资金写入及补资核对链。因此该组合继续显示待核对，不能把尚未发放的佣金当成已发，也不能假设门店补资到账或退款成功。

后续若业务实际允许此时序，须先明确其与售后期及整单结算条件的关系，再建立可验证的佣金原入账、已发佣金不追回、实际退款及其本金／赠送／赔付原路来源、陪玩个人收益和门店承担资金凭证。报表才能把付款及各笔退款分别归属发生期；查询时的待结算余额不能当作历史期间末余额。

本次按要求未修改资金执行、前端或站内消息，也未运行测试、检查或迁移。后续联调应覆盖已发佣金金额、退款前后期次、实际来源分配、陪玩及门店承担、佣金流水无冲正、到账用途、并发重试和两店隔离。
