# 双陪预约另一席拒绝通知恢复

双陪预约的受邀陪玩本人拒绝时，在预约锁定事务内保存拒绝事件、其原邀请事件以及另一在席陪玩的账号、席位、原业务周期和关联用户。提交后创建站内消息；失败由逐店任务恢复，按拒绝事件幂等。已有老板状态提醒和重选邀请沿用既有链路，不在这里重复发送。

恢复时核验本人拒绝及原邀请、预约仍待处理、拒绝席位仍空缺、另一席仍由原周期账号占用。预约结束、空席已重选、另一席变化或账号退出重入时跳过过时通知；内容只提示另一人拒绝，不称预约已付款、成单或接单。若另一席也失效导致预约过期，既有预约过期通知负责该结果。

`RESERVATION_TEAM_DECLINED_NOTICE_RECOVERY_ENABLED` 默认关闭，依赖 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED`，关闭期间的事件不会追补。上线前需应用 `site_messages/0038_reservationteamdeclinednotice` 并隔离联调拒绝、重选、同时超时、账号周期变化与失败恢复。本轮未运行测试或迁移。
