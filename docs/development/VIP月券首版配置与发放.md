# VIP 月券首版配置与发放

本店月券发放统一按当前等级保存的数量、折扣和其他条款执行，并以老板、本店业务周期及月份保存唯一发放决定，数量为零也有事实记录。已有决定或实际券记录优先，不因刷新、定时任务、升级或重试补发；月中升级的旧券保留原条款，下一月份按当时等级发券。已锁定的券在降级、等级停用和 VIP 关闭时保留原条款。安全箱折扣读取本店等级字段，已锁定的券继续使用锁定条款。

已经登记月券规则的门店可直接执行该发放路径，不再依赖旧的月券实验开关。新店空库初始化时登记规则；已有真实发放决定或券记录不覆盖。当前期间缺少决定时执行当前期间的正常发放，不根据规则登记时刻猜测过去已发零张。自定义等级沿用等级顺序、权益引用、角色权限、持锁重算和 License 检查，不再因为旧实验开关被拒绝。VIP 关闭或 License 不允许新增权益时不新增发券，已获有效券按原规则使用。

首版不执行历史数据接管。本轮未运行测试或迁移；需在隔离库联调同月重复领取、月中升级、配置修改、降级、切换/初始化并发、License 宽限及数据库故障回滚。
