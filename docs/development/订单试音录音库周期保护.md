# 订单试音录音库账号周期保护

订单招募试音已有本人多段录音上传、选择已上传录音、双陪队友本人确认并提交本人录音、老板试听与选人链路。上传创建独立对象，报名引用原录音，个人库删除仅软删除，不会删除已提交音频；上传成功不代表报名成功。文件、报名和授权沿用当前门店数据库及私有媒体边界。

开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 时，录音库列表、上传结果查询、上传和软删除均在本店事务锁定陪玩账号，并核对原请求账号类型、在店状态及业务周期；旧请求遇到注销或重新入驻后返回 409，须重新登录。上传前的音频解析不写业务数据；解析后再次持锁核验，避免等待期间身份变化后写入。软删除仍不影响报名引用及既有私有播放授权规则，未更改已提交录音。

本次不改变双陪业务和录音存储，也未新增结构迁移。生命周期集成关闭时不提供该周期并发保障；音频格式、失败恢复、双陪各自确认、老板试听权限及双店同号仍需在隔离环境联调。按要求未运行测试或迁移。
