# 新店会员基础配置初始化

新门店完成结构初始化时，幂等建立本店 `ClubOperationConfig` 单例，使用现有会员服务相同的模型默认值。此前只有两项月券能力同时启用时才会间接创建，默认关闭时平台会员初始化无法保存，首次开业检查也会因基础配置缺失阻断。

此步骤不自动确认积分倍率、VIP 等级或其他开业规则，不改变 License 激活要求；平台或门店仍须按现有入口完成实际配置和确认。初始化重试遇到已保存单例时原值保留，不覆盖门店填写内容，也不复制其他门店的会员或资金数据。

本次只修改初始化代码，未执行数据库迁移或测试。最终需在隔离新库联调默认开关、初始化中断重试、单例已存在、平台配置与确认、License 激活及首次营业；线上建库和部署仍须由授权的部署流程执行。
