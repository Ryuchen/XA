# 工资加购付款归期

加购工资绩效和迟核补发以 `OrderAddonPayment.paid_at` 对应本店月份，而非同事务稍后写入的扣款流水创建时间。跨月时只计入付款月，后续实际退款仍按退款发生月计算；已确认工资快照不重写，迟到事实依既有下一期补发链处理。金额仍使用实付店币及既有人民币分换算，未改变对外原价指标或资金执行。

保留付款流水、钱包、金额、余额、冲正及退款凭据核验；若付款时间与其扣款流水分别位于已确认工资确认时刻两侧，无法证明当时快照是否包含该付款，明确返回待核对，避免误发或重复补发。核算截止前付款流水尚不可证实时也要求核对。发生月净绩效为负时按既有规则取零、不结转负绩效；已确认提成退款扣回与余额不足的结转沿用现有链路和开关。

本次无新增迁移，未修改加购资金执行；按要求未运行测试或迁移。需要隔离联调跨月午夜付款、工资确认竞争、单笔/多笔加购退款、积分主单、迟登记补发、负绩效及双店隔离；无法证明的资金组合继续受既有门禁限制。
