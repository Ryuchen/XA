# 积分无转单跨加购退款

无转单积分订单在首次主单部分退款后，现有加购售后方案与双方确认入口可按原付款构成退款；执行器按实际确认人的待结加购收益、该人其他加购待结收益、主单待结收益、钱包及押金顺序计算承担，并在退款事务内记录资金释放。后续补资与逐人结算读取现有真实付款、退款和资金版本。

本次补充实际退款 RELEASE 的到账回放：没有负责人接替的另一笔加购被占用时，逐笔核验其真实付款、同店订单、同一陪玩和履约段、退款前历史扣减、实际剩余收益及退款时尚未结算。之后才结算的收益不会反向改变退款时点；付款或扣减与退款同时发生、无法证明先后时继续拒绝核对。原有接替组合继续使用各自的接替凭证校验。

代码沿用已有接口、权限和功能开关；未运行测试或迁移。最终须隔离联调主单部分退款前后多笔加购、跨付款和主单收益承担、原构成退款、钱包／押金不足、实际与零 RELEASE、共享到账、补资不足与补足、逐人结算、幂等重试和并发回滚。本次补充是实际来源核验，不代表整条资金链已验收。
