# KOOK 语音积分规则配置待接入

当前真实监听及人工在线登记仍按每 7200 秒 1 积分，语音不足一组的余量累计。此功能尚未开放按门店更改，不能将签到积分配置误认为语音规则已配置化。

规则切换需要保留旧规则下的已发积分、未发完整组和不足一组余量，并按真实在线区间确定切换时点；不能仅修改累计总时长的除数。尤其 `kook_license_review.resolve_locked` 对授权 UNKNOWN 的补核会把旧毫秒合并进当前累计，若规则期间改变，需要真实区间和规则版本的逐段凭证及按顺序重放，否则会将旧时段按新规则计算或重复消费余量。

后续应在门店配置中记录规则版本和实际生效时刻；在业务周期内为每个绑定持久化按规则分段的原始区间、余量与已发／待核对事实；自动监听、人工登记及平台审核共用该凭证和幂等流水。真实来源不足的审核继续待核对。实现及空库结构迁移、跨规则 UNKNOWN 审核、两店隔离和监听连接竞争均尚未完成；本轮未改语音发放逻辑，未运行测试或迁移。
