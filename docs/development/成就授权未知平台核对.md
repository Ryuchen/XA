# 成就授权未知平台核对

平台超级管理员可通过 `GET /api/admin/platform/store-management/<门店ID>/license-achievement-review` 查看 UNKNOWN 事件，`kind` 为 `PENDING` 或 `REVIEWED`；使用同路径 `/<事件ID>/resolve` 提交 `request_id`、`outcome`（ALLOW 或 DENY）和原因。沿用平台独立权限、门店隔离、原请求幂等及跨库审计；门店提交成功而平台审计失败时，原请求重试可补齐审计，不重新发放。

DENY 在核验原事件归属、原付款及 UNKNOWN 依据后零发放结案。ALLOW 只支持原周期首笔、无退款、无加购、无转单及非积分支付的普通服务订单；须验证原支付和完整来源、真实结算、当前无其他实销、原累计金额和数量及成就规则快照一致，且账号仍在原周期。逐项 `get_or_create`，不重复解锁。若规则已变、发生其他实销或退款、跨周期、来源不足或属于其他场景，则保留待核对，不按当前统计猜测历史事实。

老板已解锁消费成就后，退款导致有效实销低于门槛仍保持解锁；消费统计按实际退款冲减。本次新增审核模型和首版结构迁移文件，没有执行迁移或测试；还须在隔离环境联调权限、跨库失败重试、授权恢复、重复请求、资金和账号并发、退款及锁顺序。未保存原事件的来源仍缺扫描及核对入口。
