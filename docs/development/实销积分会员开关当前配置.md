# 实销时的会员和积分开关

服务实销事务已锁定本店会员配置并根据付款快照、实销时开关及 License 保存决策，但随后发放消费积分和计算会员等级时又普通读取配置。MySQL 可重复读事务如果先建立了旧快照、再等待配置启用提交，可能已经标记实销完成，却因旧开关漏发积分或跳过升级。

普通服务及已有的退款、转单退款实销入口现将已锁定的本店配置传给消费积分发放和会员重算；重算等级行也按当前锁定读获取。积分倍率和生日倍率仍取付款时快照，实销时开关与 License 决策仍保持原规则，已发积分和既有实销事实不改写。礼物等未传锁定配置的独立入口不因本次改动扩大支持范围。

未运行测试或迁移。最终须在隔离 MySQL 环境联调配置启停与普通、退款和转单退款实销并发，核对本金、赠送、赔付、付款时倍率、License 及幂等；其他实销路径及会员权益发放仍需统一联调。
