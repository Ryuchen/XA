# 已分配积分订单服务前取消预览

客服可在既有 `GET /api/admin/orders/{id}/refund-preview/` 核对已分配、尚未开工、非预约积分订单的全额取消构成。新增返回字段与预约积分退款预览一致：`refund_equivalent_units` 为原成交等值，`refund_coin_units` 为退回店币内部单位，`refund_points_hundredths` 为退回积分百分之一单位，`prepaid_units`、`gift_units`、`compensation_units` 为店币来源，`released_funding_units` 为预计释放的原门店补资内部单位，`full_refund` 和 `test_only` 表示范围及环境。返回值是当时核对结果，并非已经退款或释放补资；前端需对接这些字段。

预览与实际客服退款共用锁内状态、权限、订单付款、未开工与补资来源核验，额外按原积分凭据和钱包来源计算完整退回；实际提交仍在原退款事务重新核验并完成店币及积分退回、适用券返还和到账释放。已确认预约仍走自己的退款预览；隔离预约测试开关不会将非预约单误送入预约预览。

现有开关与能力门禁不变：仅覆盖已经支持的无售后、无加购、无服务中转单的全额取消；预约使用原预约链，部分退款和其他组合不因此开放。无新增迁移；按要求未运行测试或迁移，须隔离联调单双陪、服务前改派、多到账共享、钱包/积分/券与失败回滚、权限、并发和双店隔离。
