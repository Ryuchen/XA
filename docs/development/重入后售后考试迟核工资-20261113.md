# 重入后售后与考试迟核的工资来源（2026-11-13）

已确认工资月份内再次入职后，售后结案和人工核实考试沿用现有薪资业绩登记 API。登记时按实际业务时间选取已生效的重入薪资方案快照，将相应售后单价或考官费用及逐次扣成写入下一未确认工资期；同一业务凭证不得重复归属。原工资快照不改。

工资预览及确认前再次核对原售后结案周期或考试核实凭证、重入身份、当时最后生效的方案及补发金额；来源变化或无法核验时提示待核对并停止确认。售后处理人仍按既有人工核实规则归属，不因结案操作人自动改派业绩。

后续已按用户确认接入同月重入后的多方案绩效：各方案使用其生效期间的实际业绩及对应目标、绩效金额，已确认的原工资不变；主单、加购及门店业绩的处理范围和待联调事项见[同月重入多版本绩效](同月重入多版本绩效-20261113.md)。本记录最初对该部分尚未接通的描述已被后续实现取代，不代表已完成最终验收。

本次未测试或执行迁移；最终联调须覆盖多方案切换前后、真实售后重开与结案、考试幂等及撤销、工资确认重试、重入与账号状态竞争和双店隔离。
