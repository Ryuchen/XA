# 普通混合付款协商退款后的审核触发结算

无转单、无加购的普通服务订单发生一次已确认协商退款后，陪玩报单审核通过时，若双陪整单已经完成，可以立即尝试既有逐人结算，不再先用整单完成时间阻挡受影响陪玩。已终止陪玩的售后等待仍从协商确认时起算；另一陪玩仍按其适用的整单完成时钟和本人报单冻结时间处理。

结算器仍须在本店订单和资金锁下核对本金、赠送及赔付的原付款和实际退款、线下到账与整单补资；补资未足额时不释放任何陪玩收益。各陪玩已入账凭证、退款承担及钱包流水按既有规则逐人核对，只有全部收益及最终去向核实后才完成整单。整单尚未完成时审核入口仍拒绝结算；未覆盖的转单、加购及追加协商组合保持原门禁。

本次未运行检查、测试或迁移。最终联调须覆盖一人提前终止且整单未完成、整单完成前后不同售后与报单时钟、混合资金及补资不足后补足、逐人重复审核与重试、双店隔离和并发回滚。
