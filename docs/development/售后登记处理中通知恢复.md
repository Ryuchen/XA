# 售后登记与处理中通知恢复

老板提交售后或客服代登记售后时，开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 和默认关闭的 `AFTERSALE_OPEN_NOTICE_RECOVERY_ENABLED` 后，在登记事务中按实际收件名单保存通知意图：客服代登记通知老板，按售后范围通知相关陪玩；老板本人提交不额外通知本人。每个意图固定订单原收件周期、该次登记时间及历史事件摘要，不复制售后私密说明。

提交后独立投递，失败由逐店任务恢复，每个登记事件和收件账号最多创建一条消息。投递核对原历史事件、当前仍是同一次处理中售后、原订单账号周期及在店状态；结案、重开、账号重入或来源不明时记录跳过。开启此功能时结案事务也把同次已创建的处理中消息更新为已处理，避免继续提示处理中。消息发送失败不回滚登记，创建站内消息不代表客户端收到实时刷新；关闭开关沿用原周期保护的即时通知。

启用前须各店应用 `site_messages/0021_aftersaleopennotice` 及依赖并运行逐店 worker/beat。最终联调覆盖老板与客服登记、单双陪及指定范围、留存收益的转单人员、重复提交、登记与结案竞争、同单重开、部分通知失败与并发恢复、双店同号、账号停用和重入、事务回滚。低星评价触发的通知续接情况见《低星评价售后通知恢复》；其他实时事件也未覆盖，正式注销继续关闭。本轮未运行检查、测试或迁移。
