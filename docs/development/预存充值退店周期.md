# 预存充值与退店周期

充值使用本店当前档位从高到低重复组合；修改赠送时先记本金并保存标准组合，审批通过发申请金额、驳回发原标准金额。发现退店老板的账号可能仍是启用状态，充值入口原先未核验在店身份：本金会进入已结束的会员周期，赠送审批又无法正常办理。

充值原事务现按既有钱包、老板账户顺序加锁并核对当前在店状态，退店后须重新入店才能发起新充值；重新入店后使用锁内读到的当前业务周期。已经成功的同一充值请求仍先回读原事实，不受后续退店影响。该变更解决错误周期收款与待审批赠送，未改变档位试算或原审批记账。

充值成功的站内提示使用本次充值保存的业务周期，只向仍属于该周期的老板发送；提示的币种使用本店名称，例如声浪的浪花和兴安的星辉。账号已退店或重入时不会把旧充值提示发给新周期；充值本金、赠送及审批结果不受通知结果影响。此通知仍是提交后尽力投递，不代表客户端或外部渠道已收到。

未运行测试或迁移。最终须在隔离环境联调充值与退店并发、退店后原请求重试、重新入店的新充值，以及不同档位组合和批准／驳回的真实资金来源。
