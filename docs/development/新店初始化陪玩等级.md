# 新店初始化陪玩等级

新店空库不预设陪玩等级；现有陪玩入驻审核需要选择本店启用的等级，部分服务配置也可关联等级。平台超级管理员现可通过既有目录初始化接口 `/api/admin/platform/store-management/<门店ID>/setup/catalog/escort-level` 读取并保存等级，使用原目录 `version`、`id` 和 `configuration` 协议及本店后台相同的等级字段校验。等级被纳入目录版本，平台保存仍只允许首次开业配置中的门店，并保留平台和门店审计。

首次配置阶段，符合现有门店身份和 `escort_level` 权限的首位管理员也可访问已有 `/api/admin/escort-levels` 及单项维护、删除影响查看接口。门店等级写入与平台目录初始化共用目录锁，防止并发保存绕过版本检查；角色权限不因开放入口而扩大。

本次不预设等级、抽成或营业前必须创建等级，也不改变已有陪玩资格和订单。未执行测试、迁移或建库；最终需在隔离新库联调角色权限、并发目录编辑、等级关联服务、陪玩注册审核及首次营业。
