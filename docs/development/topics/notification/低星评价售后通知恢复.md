# 低星评价售后通知恢复

低星评价在门店配置的售后有效期内实际创建、重开或关联处理中售后时，沿用原处理范围：只有此前未被覆盖的陪玩收到处理中通知。开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 和 `AFTERSALE_OPEN_NOTICE_RECOVERY_ENABLED` 后，通知意图与评价和售后历史同事务保存；投递核对真实 LOW_RATING 历史、对应评价、售后仍为同次处理中以及原订单陪玩业务周期。结案、重开、账号重入或来源不明时跳过，发送失败由逐店任务重试。

低星评价本身的陪玩提醒也在评价事务中保存意图，按原订单周期核验后投递或重试；无法证明来源、评价已作废或账号重入时跳过。售后期限仍使用现有 `aftersale_deadline` 和门店配置，默认 72 小时；超期仍只记录超期状态并发送评价提醒，不因此创建或修改售后。没有变更低星范围、结案及退款规则；普通非低星评价提醒另见《普通服务评价通知恢复》。

须在各店应用 `site_messages/0022_lowratingnotice` 与依赖、启用上述开关并运行逐店 worker/beat。最终联调须覆盖期限前、截止边界、超期、已有售后附加、多人评价与转单、已结案范围、重复与并发、评价作废、消息故障恢复、结案及重开竞争、账号重入、双店同号与业务事务回滚。站内消息创建不代表客户端收到实时刷新；其他通知仍有缺口，正式注销保持关闭。本轮未运行检查、测试或迁移。
