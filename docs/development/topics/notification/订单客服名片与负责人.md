# 订单客服名片与负责人

老板通过 `GET /api/support/contact-card/?order_id=...` 查询本店本人订单的联系名片时，返回的名片须启用且绑定仍可登录、门店后台身份有效的员工，与下单时可选择的名片口径一致。原名片或其员工不可用时使用当前可用的默认名片；没有可用名片则返回空，不因此更换订单负责人。未关联订单的通用联系入口沿用原规则。

接口补充 `order_contact_name`（订单保存的原名片名称）、`contact_fallback`（原名片不可用而改用其他名片）、`contact_is_order_responsible`（当前展示名片所绑定员工是否仍是订单负责人）。原名片删除后，订单外键会置空，但仍可根据订单保留的原名片名称标识兜底；从未选择名片的订单不标记为兜底。名片后来改绑员工时，该判断按订单已保存的负责人，而不是当前名片名称推断。在线咨询仍按共享池领取，不因展示名片或负责人而自动领取。

本次只增加后端响应字段，无结构迁移；未运行测试或联调。最终需在隔离门店验证原名片停用、改绑、无原名片、跨店及咨询领取场景。
