# 赠礼到账站内通知周期恢复

老板赠礼成功时，在赠礼订单、老板扣款和陪玩收益入账的同一门店事务中保存通知意图，固定收件陪玩账号、赠礼原业务周期、两笔真实流水及当时通知文案。提交后尝试发送，失败由本店任务重试；每张赠礼订单最多一条站内消息。

恢复时锁定收件账号与订单，核验订单为已付款完成的真实赠礼、原收件周期、老板扣款和陪玩收益流水及余额变化；周期或付款收益来源缺失、冲突会保留 `REVIEW` 待核对，不假定到账。账号退店或注销重入后跳过旧待发送意图，已发送消息继续保留并由现有接口标明旧周期。

`GIFT_RECEIPT_NOTICE_RECOVERY_ENABLED` 默认关闭，依赖 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED`。开启生命周期集成而关闭本恢复开关时，即时发送仍按赠礼原周期核验，缺来源记录告警但不能自动恢复；两项开关均关闭时沿用旧即时行为。启用恢复前需应用 `site_messages/0041_giftreceiptnotice` 及依赖迁移并配置逐店任务。`REVIEW` 目前没有专门的后台核对页面；其他尚未接入周期与可靠恢复的旧通知路径仍需逐项处理。本轮未运行测试或迁移，需隔离联调付款、冲正、重入、失败重试和双店隔离。
