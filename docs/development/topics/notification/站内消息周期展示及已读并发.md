# 站内消息周期展示及已读并发

站内消息列表和详情保留同账号历史消息，根据保存的真实收件周期返回 `CURRENT`、`PREVIOUS` 或 `UNKNOWN`；缺失、无效或无法确认的周期不会推测成当前周期。消息列表总数、未读数、详情已读及全部已读继续覆盖该账号可见历史消息，未擅自清除或重置旧周期消息；历史链接能否访问原业务对象仍由对应业务接口授权决定。

开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 后，列表、详情、未读数、全部已读和派单声音游标在本店事务中先锁定账号并核对认证请求的账号类型、业务周期及在店状态。退店或注销重入与这些请求竞争时，已变化的旧请求返回 409 并提示重新登录，不读取新周期或把新周期消息标记已读。已读刷新事件仍使用该次请求原周期；派单声音游标只统计当前周期，旧周期和未知来源不会触发新派单声音。关闭生命周期集成时保留原处理规则。

本次没有新结构迁移，不代表所有通知发送源已具备原周期或可靠恢复。最终须在隔离环境联调老板退店重入、陪玩注销重入、旧请求与单条/全部已读并发、分页及未知周期、未读数、派单声音游标、实时刷新和双店同号；正式注销保持关闭。本轮未运行检查、测试或迁移，前端旧周期标识展示仍由前端对接。
