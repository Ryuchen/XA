# 经营 ROI 退款流水期间统一

普通订单的单次协商、追加协商、转单和已发推荐佣金退款，以及积分订单的单次和追加协商成本，按关联老板钱包的真实退币时间归期；仅退积分时按真实积分账本事件归期。加购退款继续按关联钱包入账时间归期，礼物退款按其直接关联的实际钱包流水核对。记录时间仍用于验证业务版本、接替与退款先后，不因记录和入账跨期就拒绝已证明的成本。

期间收入按实退店币冲减，返还积分按独立积分账本期间单列；已发推荐佣金及续单奖励继续沿用已核验的独立流水，不将退款、补资或收益流转重复计为收入。分批结算证据与待付金额保留现有资金版本和报单等待核验。

仅支持真实关联或原有规则可唯一证明的钱包流水；没有可靠来源、历史事件矛盾、未覆盖的资金版本或未完成结算证据仍显示待核对。本轮未运行测试或迁移；最终须隔离联调多个同额退款、退币和积分跨月、追加协商、加购接替、已付后退款、分批结算、推荐佣金和续单奖励、共享到账与门店隔离。
