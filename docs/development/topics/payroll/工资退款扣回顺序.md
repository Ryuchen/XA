# 工资退款绩效与提成扣回顺序

退款发生月的工资已经确认时，保留原工资快照，按既有真实退款凭证在下一期计算绩效调整；本期绩效扣减至应发工资为零，未扣部分不结转。已经确认工资的退款提成也从适用工资扣回，本期不够扣的余额继续结转；员工完成离职工资结清后，按既有离职核销规则不再追扣。

当不可结转绩效与可结转提成同时争用本期应发工资时，先处理绩效调整，再按退款发生顺序处理提成。同一类别内部仍按真实退款发生时间及来源稳定排序，保留退款、原工资、员工和实际扣减关联。例如应发 100 分、绩效调整 80 分、提成扣回 80 分，本期扣绩效 80 分和提成 20 分，提成余额 60 分结转；不会因先扣可结转提成而提前放弃可在本期处理的绩效。

本次只调整核算顺序，不修改历史已确认工资或资金流水；需启用既有 `PAYROLL_REFUND_ACCOUNTING_ENABLED` 链路才生效。未新增迁移，按要求未运行测试或迁移；最终需在隔离环境联调多笔退款顺序、工资为零、部分结转、绩效修订、离职结清、重试与双店隔离。
