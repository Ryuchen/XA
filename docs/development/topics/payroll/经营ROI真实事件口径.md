# 经营 ROI 的真实订单事件

当前开发将实际支付及退款分别归入付款发生月和退款发生月。礼物付款使用真实负向 GIFT 流水；普通服务使用真实 PAY 流水；加购独立核对付款、退款与资金来源。退回积分不计入退回店币，平台到账补资也不计入营业收入。

收入查询支持按任意日期区间核验主单和加购退款：退款记录及对应老板钱包入账在查询区间的金额与来源必须一致；退款或流水落在区间两侧时标记待核对。主单同额退款在可核对的相同来源下按笔数和金额汇总比对，不虚构逐笔关联；加购使用直接关联钱包流水。积分退款另核对积分账本所在区间，不能将跨期积分返还当作零。主单累计核验只读取查询期结束前的退款与钱包入账，未来退款不会提前纳入累计核对；但付款或退款后发生冲正时，当前仍按待核对处理，尚不提供重建历史冲正前状态的能力。

免费安全箱正式协商按逐人份额核验：双方确认、客服执行审计、各份额及资金凭证可核实时，若服务已完成后才协商，在服务完成期计入各人的原补贴，并在协商执行期计入各自保留补贴与原补贴的差额；若服务中协商终止，按双方确认的保留补贴在完成期计入。转单场景额外复用正式协商的分段和转单证据校验，只在对应生产能力或隔离联调开关开放、当前业务确实能产生正式执行记录时适用；该扩展不打开业务开关。已结算份额还需核对补贴资金流水；未结算份额按正式协商快照作为应计成本，不称作已打款。缺少凭证、现行执行流程不支持的多人情形及已付资金冲正，保留待核对。旧安全箱协商直接执行入口当前被业务门禁禁用，不能据其内部代码声称冲正业务可达。

普通完成和正式协商的安全箱补贴共用资金核对：已结算时，平台支出须来自平台钱包，陪玩收入须属于该订单的对应陪玩，双方金额、流水状态及前后余额须相符，且须存在陪玩结算时间；零收益已结算不强行要求金额流水。尚未结算时，如果已出现收入／支出流水或结算时间则提示待核对，不将其当成可证明的待结算成本。存在陪玩收入冲正时暂不推算补贴净额。

可核验的普通店币退款按实际原收益流水和每笔退款冲正计算陪玩成本；已发推荐佣金保留为成本，门店为该佣金退款的真实到账不再重复记作成本。礼物仅在本金来源、付款、各方入账及退款凭据完整时给出成本。普通转单在逐段清单、首轮协商（包括零退款）、逐轮追加、实际退款、加购和资金来源完整时，按原分段成本与各次实际事件计算。退款后继续转单时，须额外通过最终清单与最新版本链核验，以最新正式分段扣减前收益归付款期；清单或版本不完整仍须核对。

积分单笔协商退款复用真实积分退款和参与人凭据；双陪两笔退款仅在两笔 posting、后续终止、实际资金来源和推荐收益均可核实时计算。积分转单的一笔退款、无加购场景可用已验证的历史资金版本重建逐段原始收益；退款后再转单须另验证最终清单。推荐佣金在全部退款后才发放时，按各次退款的净实付变化归属；已发之后再次退款、积分转单多次退款或加购，以及不能确认金额或来源的组合仍显示待核对。普通转单的首轮及追加轮次均可核验无现金退款情形。跨月只在相关付款或退款所在期间记入对应变化，避免将平台补资和原订单收入重复统计。

本次实现未运行开发期测试，也未执行迁移。最终联调需覆盖两家门店、正常付款及跨月多次退款、礼物本金来源、积分返回、加购退款扣主单收益、转单、同一人兼任陪玩和推荐人、已发推荐佣金、到账释放、并发及失败回滚；还须覆盖主单、加购和积分流水与退款记录跨日／跨月、相同来源的多笔同额退款，以及未来退款不影响历史累计核验。安全箱须覆盖完成后跨月确认及服务中确认、结算前后、转出再转回、各方确认和审计或分段证据缺失时待核对，并验证事务及门店隔离。现有未覆盖组合不得以 0 替代未知成本或宣称 ROI 完整。
