# 工资确认与退款核算开关

已确认工资后的退款绩效和提成沿原工资确认事务分别处理：绩效在下一可处理工资期先扣，最多扣至应发为零，未扣部分登记放弃；提成未扣完的余额继续结转。零工资的绩效也记录处理事实，迟核业绩引起的更正另留修订，不改原工资快照。

本次修复店内工资确认及离职结清入口：与平台工资入口一致，只有退款工资核算和本店工资事件屏障都启用时才能确认或结清。此前店内入口在退款核算关闭时仍可用旧净额口径确认工资，后续退款不会进入上述处理。工资预览在任一能力未启用时明确提示不可确认；保存确认和关联退款处理仍使用原事务及门店隔离。

本次不修改退款或钱包写入，也不表示所有资金入口的屏障并发已验收。未运行测试或迁移；最终须在隔离环境联调实际付款退款与工资确认竞争、零工资、绩效放弃和提成结转、迟核修订、离职结清、重试及双店隔离。
