# 工资退款绩效一次性处理

已确认工资后的退款绩效，在可处理的下一期工资中按本期应发扣减，最多扣至零。每笔调整记录实际扣除额和未扣放弃额；即使工资为零也保存处理事实，未扣部分不进入后续工资。退款提成是独立欠扣，仍按原规则结转。

迟核业绩引起的绩效差额另存逐笔修订，保留原工资和原退款调整。补正只退回此前实际扣除、且超过新应扣额的部分；未扣部分不会被当作已扣工资补发。新增扣款只在本期可用工资内执行，剩余放弃。修订及处理记录在工资确认事务中保存，重试以工资期和来源唯一约束核对。

新增 `console/0034` 结构迁移尚未执行。本次未运行测试；最终联调须覆盖零工资、部分扣款、同月多笔退款、正负修订、此前未扣部分、提成同时结转、跨期重试、双店隔离及 MySQL 竞争和回滚。

离职结清检查以逐笔绩效处理事实中的实际扣款与放弃额为依据；已处理且放弃的部分不再冒充未结余额。若后来发现的迟核业绩使应扣额发生变化，须先完成相应补正后才能结清；退款提成仍按离职结清规则单独处理。
