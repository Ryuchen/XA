# 工资退款真实流水核对

工资月度派单业绩及已确认工资之后的派单提成扣回，按实际退回老板的店币计算。主单积分退款只计退回的店币，不把退还积分当作店币；加购退款按其独立付款及退款凭证计算。确认过的工资仍保留原记录，后续退款按现有下一期扣回与绩效调整流程处理。

本次在这两处计算接入退款凭证校验：优先核对积分退款或协商执行记录关联的老板钱包流水；普通退款没有直接关联时，仅在相同订单、退款金额及操作人能唯一匹配一笔退款记录和一笔老板钱包入账时采用。加购退款核对其直接关联的钱包入账与原付款。退款和钱包流水必须处于相同自然月，且不能跨过该月工资确认时点；原付款、钱包归属、金额、状态和流水前后余额需一致，已冲销流水不计入。证据不足或无法确定发生期时返回待核对，不将未知金额当成零。

迟登记派单和迟确认加购的补发也使用同一凭证口径：已确认工资保持原快照，补发提成按原方案计算；在补发核算截止前实际到账的店币退款冲减补发提成基数。原月绩效补发继续采用已确认月的有效业绩，后续退款在其发生月另行处理。若退款金额超过该来源付款或补发基数，提示核对，不将超额部分截为零。前一笔迟登记派单会影响当前笔取整基数，也须核验其退款。

派单提成的日成本按真实付款和退款事件日计算，主单及各项加购统一按付款对应的日夜班比例逐笔累计并计算取整差额。例如上月派单、本月付款的提成归入本月付款日；同月后续退款在退款日冲减。该变更只影响尚未确认工资预览的新快照，月工资仍按原有累计比例计算，已确认快照不回写。前月付款、本月退款产生的已确认工资扣回，继续由既有跨期扣回流程处理，不重复计为本月原付款的日提成。

跨期工资的退款提成、原确认月的绩效调整和迟确认门店绩效按核算截止时点及核算期结束时点读取主单、加购付款退款事件；截止之后的记录不参与本期的金额或凭证核验。若退款记录在截止前，但关联钱包实际入账在截止后，提示待核对，不能提前记为已退款。没有指定截止时间的离职结清等全量核对仍检查全部现有记录。

老板预存充值的客服提成依据本金钱包到账时间归月：工资来源列表、未归属提醒和业绩登记使用相同时间，按已核实的本金流水金额计算，不计赠送店币。若工资已确认，之后才核实归属，继续使用原月薪资规则在下一未确认工资期补发。缺少本金流水的记录仍按记录创建月提醒待核对；已有流水但证据不合格的记录按流水月份提醒，不作为有效充值业绩。

本次不改变退款、钱包、确认工资或资金记账。相同订单同金额同操作人的普通退款无法可靠区分时仍须人工核对；零店币的纯积分退款不形成工资退款额。其他工资计算路径及实际生产资金尚未由本次变更证明。

最终联调应使用隔离门店数据库，覆盖普通与积分协商退款、加购退款、跨月退款、工资确认前后事件及多笔同额退款；验证老板钱包原始流水、已确认工资快照和下一期调整一致。另需覆盖多笔迟登记派单及加购的先后补发、取整基数、补发前后退款及核算截止边界；验证主单跨月派单付款、主单和多笔加购同月分日退款及跨期扣回时，日成本汇总与月提成一致；验证截止后退款不影响截止前的工资，特别是截止前退款记录与截止后到账流水分属两侧的情况。充值须覆盖记录与本金流水跨月、未到账、重复流水及确认工资后归属补发。真实付款退款事件口径仍受既有工资事件屏障开关限制，尚未完成生产启用验证。本轮按开发安排未执行测试或迁移，不能据此判定端到端已验收。
