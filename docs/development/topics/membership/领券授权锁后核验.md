# 公开领券的授权时点

公开领券在本店钱包及优惠券锁后、创建新券前核验 PROMOTIONS License，避免等待锁期间授权到期或降档后继续发券；UNKNOWN 不作为允许。相同账号、业务周期、券和领取周期已有记录时直接返回原结果，重试不受后续授权变化阻断，也不增加库存消耗或再发券；响应增加领取记录 ID、实际可用状态和重试标识，不将已使用或过期券描述为可用；不同资格券的共享限制仍按原规则处理。账号业务周期变化则要求重新登录。已领取券的使用和退款返券路径未修改。

未运行测试或迁移。最终须联调到期与锁等待、优惠券库存及相同请求竞争、日切、退店重入、控制库断开和双店隔离；跨数据库授权变更与门店提交并非分布式原子事务，锁后判断是发放前最后一次核验，不声称具备跨库线性化。
