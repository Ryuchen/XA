# 会员升级时安全箱券条款

老板的已确认实销升级和门店修改等级门槛引起的升级，均通过同一升级前入口处理。事务在原等级仍有效、钱包和本店会员配置锁已取得时，先固化本周期尚未使用且有效的安全箱券当前条款，再锁定该券，升级后报价和付款继续使用原券条款。来源和周期必须可核对，不创建新券；不更改本月月券数量、不重发或撤回既有权益。多人共用的专属券无法证明归属时回滚并提示核对。

仅等级变化触发此固化；门店修改仍在使用等级的规则继续沿用既定动态条款。VIP 停用时沿用已有券保存的条款。License 到期或降档不影响已获得券的读取和使用；新增 VIP 权益仍由原授权检查控制。未运行测试或执行迁移，需在最终隔离环境联调升级、跨级、配置重算、不同周期及结账并发。
