# VIP 停用时已发券条款

本店后台关闭 VIP 时，现有会员配置事务先锁定门店配置，并按等级、券的既有顺序固化当前有效未用月券和安全箱券的真实生效条款，再保存 VIP 停用及停用前等级基线；即使可选的券保护开关尚未开启，也不会将仍在使用等级的动态条款回退为过时券面。本次不创建、补发或撤回券，也不更改本月已发数量。已有身份和私有券来源异常沿用核对及事务回滚。

停用后，等级折扣继续按原下单规则停止，消费积分继续按原 VIP 与积分开关判断；已取得的有效券仍按固化条款使用。重新启用仍受原有重算和人工核对条件约束。平台首次开业前的独立配置入口也允许已有老板的门店关闭 VIP：沿用先锁老板钱包及门店配置的顺序，先固化实际已发券条款并记录停用基线。可选开关默认关闭不再单独阻断停用；已经发生规则切换且必要保护不可用时仍须核对。启用 VIP 仍按原重算条件执行。未运行测试或迁移；最终需在隔离库联调停用与支付、同等级修改和授权状态变化的并发。
