# 陪玩展示名称接口契约

老板端陪玩目录、选人及详情使用的 `GET /api/users/escorts/`、`GET /api/users/escorts/{provider_id}/` 响应中，每个陪玩对象提供：

- `nickname`：陪玩原始昵称，保持原接口语义，不写入或修改门店前缀。
- `store_prefix`：请求所属门店配置的英文陪玩展示简称，如 `SL`、`XA`；配置尚未完成时可为空。
- `display_name`：按当前门店简称生成的展示名，如 `SL-小星`；同一简称的重复前缀会在展示值中去重，原始昵称不变。未配置有效简称时返回原始昵称。
- `avatar`：当前账号已保存的头像地址；是否已获得微信头像及可否接单由既有资格规则核验，本字段不表示微信授权凭据。

字段按请求域名绑定的门店生成，查询参数不能切换门店；更改简称影响后续展示，不改写陪玩资料。其他订单、预约、评价等接口未因本契约自动获得新字段。客户端选择已有 `nickname` 自行排版或直接使用 `display_name`，不应对展示名再次无条件拼接前缀。
