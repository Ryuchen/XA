# 游戏资料规则的下单与预约当前读

平台及门店可分别配置游戏和服务的资料必填项，服务级配置优先；服务级选择继承时使用游戏级规则。规则保存已在统一互斥锁后对版本行做当前锁定读，但下单及预约原先取得同一锁后仍用普通快照读取规则。MySQL 可重复读事务若已建立旧快照，等待规则更新提交后可能仍按旧必填项放行。

实际下单、单陪和双陪预约及预约付款的共用 `lock_and_validate` 现于取得规则锁后，对服务配置和所需的游戏配置使用当前锁定读，再按原服务优先规则校验。只读展示仍使用普通读取，已保存订单和预约资料不改写；平台与门店保存接口无需变更。
