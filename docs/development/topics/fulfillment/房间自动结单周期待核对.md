# 房间自动结单周期待核对

门店配置的房间确认截止到达后，自动结单仍先核验陪玩原业务周期、房间、参与人、截图及售后。开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 时，若陪玩身份或原周期无法核实，任务现在将仍在运行且已到期的确认记录标为待核对，进入现有客服待核对队列并沿用首次提醒；不会将订单标记完成。订单、房间和确认记录按现有顺序加锁后再次检查，异议暂停、转单失效、已确认及未到期记录不被覆盖。

该标记保留原截止时间和自动重试：事实恢复并通过完整结单前置校验后仍可执行，无法核实时由有权限客服处理。此改动未调整门店确认时限、老板异议暂停与恢复或转单重提规则，也不为旧数据增加处理。未修改前端、未执行测试或迁移；自动任务、生命周期并发及跨店队列仍需最终联调。
