# 普通双陪完成后本人追加售后

普通双陪一人经正退款协商终止、另一人继续完成订单后，本店客服可在订单原售后期限内，为当前唯一未释放且未结算的陪玩登记本人追加协商售后。登记须通过既有普通追加协商生产能力、前次协商终止凭证及当前席位核验；已终止的陪玩不能借此重新打开。后续沿用已有方案预览、老板与受影响陪玩确认、实际付款来源退款、资金释放和逐人结算服务，不在本入口另造资金流水。原售后记录及范围保留在历史中。

该能力适用既有生产服务支持的未转单普通双陪，允许没有已付款加购；有加购仍须符合既有逐笔凭证及资金条件。老板对继续履约陪玩的低星评价在原售后期内仍走现有自动建单或关联逻辑，并复用同一追加协商服务。首次零退款、积分、转单、直付、安全箱及其他既有门禁未在此扩展；生产能力及资金配置均沿原开关，尚未开启开关不等于已上线。

本次未修改前端、未运行测试或迁移。真实 MySQL 下的首次退款、低星自动建单、双方确认、退款来源、补资不足与补足、A 先结算或未结算、B 逐人结算、双店隔离与并发回滚仍需最终联调。
