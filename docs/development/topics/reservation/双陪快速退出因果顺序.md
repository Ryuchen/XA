# 双陪快速退出的因果顺序

正式 MySQL 双陪抢单中，队伍邀请、队友确认和本人退出均在同一订单锁下持久化；确认读取原队伍邀请后才能创建。若真实收件、成员、轮次、资格及截止均已核实，且锁内持久化顺序能证明邀请／确认先于退出，快速操作的观察区间即使重叠也可执行原退出事务，释放该队伍席位。只有邀请尚未确认时，亦须证明原邀请先于退出。

撤回与排名共用[原邀请和确认的因果核对](双陪邀请确认因果顺序.md)。撤回还要核对本人的原请求、同轮截止和相对先后。缺少正式流程的证据时，只有各观察区间能证明先后才可释放席位。

顺序无法证明时仍待核对，首轮结束后仍有效的留池邀请保留席位。隔离 MySQL 已验证快速退出、原号回读、确认竞争和双店同号席位。无新增迁移，正式双店物理切换待联调。[回归记录](../../16-开发进度.md#2026-11-23-抢单库存与重开回归恢复)
