# 预约积分订单服务前取消幂等与分流

已付款并分配、尚未开始服务的预约积分订单，客服仍通过既有全额退款入口处理；受限范围内按原付款构成退店币与积分，返还满足原条款的券，并按实际到账分配和历史释放凭据释放剩余补资。双陪沿用预约人数和原支付、履约证据核验，不因为取消开放已开始服务、存在售后或加购等其他组合。

预约取消现在必须提供 1 至 64 字符的 `client_request_id`，与非预约积分取消一致；该编号随退款事实同事务保存，响应丢失后可用相同编号和相同退款意图核验原结果，不能重复退币、退积分或释放补资。客服预览若指定退款金额，必须等于原店币实付；不接受部分金额后展示全退。预约取消测试开关只对真实已转单预约生效，不再将普通已分配积分订单误送到预约链路。

本次不修改金额计算、优惠券条款或补资释放算法，不新增结构迁移。前端须在预约取消提交时传入稳定的 `client_request_id` 并在重试时复用。按要求未运行测试或迁移；需隔离联调单双陪、已退券、补资多到账共享、重复请求与响应丢失、事务回滚和双店隔离；正式能力与其他不支持组合继续受既有开关和门禁限制。
