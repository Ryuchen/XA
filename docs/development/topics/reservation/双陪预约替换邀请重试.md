# 双陪预约替换邀请重试

老板替换双陪空席时可选传入 `client_request_id`（非空、最多 64 字符）。有编号时，在本店事务内将操作者、预约、席位、目标陪玩及双方业务周期与真实 `INVITED` 事件绑定到现有幂等回执；同编号重试只返回仍属于该事件的有效邀请或已确认结果，原邀请超时、被拒绝或被替换后不会重新生成。请求编号用于不同操作会报错。

不传编号时，同席位同周期且仍有效的待确认邀请返回原结果；邀请已失效后，老板可主动再次选择同一陪玩，创建新的真实邀请与截止。重试不改原截止、不重复发确认邀请；另一席位在等待时超时仍按原事务释放及通知。保留已确认陪玩的档期，付款时限仍由双方确认及本店配置决定。复用现有回执表，无新迁移；未运行测试或迁移，需最终隔离联调丢包重试、同人再次邀请、超时／确认竞争、通知和多店隔离。
