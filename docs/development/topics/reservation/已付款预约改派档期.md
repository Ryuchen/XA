# 已付款预约改派档期

客服在服务开始前改派已付款的单陪或双陪预约订单时，持原订单、派单及陪玩资料锁，按原预约起止时段检查接替陪玩已设置的周循环接单档期；跨午夜和连续相邻时段可共同覆盖完整区间，未设置班次沿原规则视为不限。该预约改派不再要求接替陪玩在操作当刻处于普通接单班次，也不把接替陪玩冒充原预约本人确认。

原时段的待确认、已确认及已付款预约冲突复用预约写入路径的锁定当前读，排除本次自身预约；冲突或后续任一步失败时事务回滚，原陪玩和另一位陪玩的占档均保留。成功后原席位释放，新席位按原预约时段占档；其他资格、退款押金缺口及并发规则未放宽。

未新增迁移，也未运行测试或迁移。最终须隔离 MySQL 联调单／双陪、跨午夜班次、未设置班次、同一新陪玩并发预约、改派失败回滚及跨店。
