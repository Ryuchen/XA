# 积分转单追加退款的多名已付人员

已转单积分订单在首次主单协商退款后，另一实际履约范围可通过现有售后预览、客服方案、老板和受影响陪玩确认及授权退款执行入口发起追加退款。执行时按本人仍待结收益、本人钱包余额、本人可用押金的顺序承担；实际退款、钱包／押金流水、整单补资版本、真实 RELEASE 和售后结案保持原事务。后续仍须补资足额并按实际报单及履约分段逐人结算。

原预览将先前已结算的其他陪玩固定为一名，即使同单多名人员的结算清单和流水都可核对也无法继续。本次移除此人数门槛，保留已有结算清单、逐人报单与钱包／押金流水核验、已付加购核验、补资守恒以及受影响人员不得已结算的要求；已发收入不重新入账。

既有授权、门店隔离、本人资金不足时拒绝退款及实际资金凭证校验不变。未运行测试或迁移；须在隔离 MySQL 联调多名已付人员与一名未付受影响人、钱包和押金混合承担、首次／后续退款、补资不足与补足、零及非零 RELEASE、逐段结算、重试和并发回滚。不能据代码接线视为完整资金验收通过。
