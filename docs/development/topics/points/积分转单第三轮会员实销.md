# 积分转单第三轮退款后的会员实销

积分转单在正式第三轮退款结算能力及同一订单的结算上下文可用时，会员确认读取真实最终逐段清单，并复用财务第三轮清单和补资核验；逐笔核对三次退款与原支付构成，按实际退回店币计算会员净消费、按实际退回本金计算消费积分。原付款倍率、确认时 VIP 与 License 决定、原账号周期及已有幂等凭证继续适用。成就仍由同一实际实销事件按独立授权处理。

首轮及已有后续积分协商全退在原事务中保存逐券退回结果，供老板订单退款详情读取；资格券等不应退回的券标为未退回。记录与原退款及返券一起提交，不因之后重新使用券而改变。三轮全退的完整资金与返券流程仍以实际接入范围为准，未执行测试或迁移。

当前严格继承财务第三轮结算的受控范围：无加购、无预先已付人员、第三次后无新增到账，且本人待结收益、可用钱包与可扣押金按顺序合计足额，门店补资仍须在当前受控路径内足额。已有真实到账分配时，可核验第三次正数 RELEASE 或真实零释放见证；本单从未分配到账且三轮后整单无需补资时，结算复用订单本地退款和资金版本核验，不创建虚假到账或用途事件。该无到账路径已接代码，仍须最终接口和账务联调。其他情况不得依据此分支推断可办理。License UNKNOWN 仍需平台按原决定和真实凭证核对；成就 ALLOW 审核进入同单结算上下文并核验实际最终清单，DENY 沿用原结案规则，已发权益不重写。

未运行测试或迁移。正式结算触发、平台授权审核、三笔退款的原来源及补资、不同账号周期、幂等和事务锁序须最终联调。

三轮全部退回的会员侧口径已核对：若财务按 `COMPLETED`、`REFUNDED` 写入真实最终结算及完整退款构成，既有逐笔核验得到零净实付和零本金，不创建成长或消费积分；全退主单不计成就金额与订单数。退券由退款终止事务按原券事实处理，不由会员确认伪造。财务全退预览及结算回放仍在开发，当前不代表该场景可办理。
