# 消费积分付款时间快照

老板普通下单、预约转单和客服代单使用资金来源账本时，在钱包扣款及真实支付流水创建后，同一事务按流水 `created_at` 保存 VIP、基础积分倍率及生日倍率快照，再继续积分付款凭证和开池等处理。此前用订单创建时间判断生日；跨北京时间零点时，两者可能属于不同日期。

本次调整不改变赠送及赔付不发消费积分的规则、实销确认条件或支付金额。关联测试夹具改为先建立支付流水再保存快照，本轮未执行测试或迁移。最终须联调北京时间生日零点前后、真实流水与快照一致性、普通及预约和客服代单、积分付款、失败回滚和双店隔离。

服务加购也以实际钱包扣款流水的 `created_at` 同时保存付款时间和会员积分快照；扣款、快照及加购付款凭证仍在同一事务。这样跨午夜时，生日倍率和工资、经营报表的付款日期使用同一事件。未运行测试或迁移，最终联调还须覆盖跨午夜加购、付款失败回滚及跨月统计。
