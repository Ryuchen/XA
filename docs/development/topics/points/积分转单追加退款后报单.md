# 积分转单追加退款后的履约证据

在既有正式积分转单范围内，服务订单含加购且经过两次主单协商退款后，继续履约的陪玩可通过原双陪结单截图入口提交本人证据；逐段报单提交及后台审核不再仅因内部测试开关关闭而拒绝该类订单。

正式报单作用域仍先按原流程锁定订单和资金，核验两次真实退款、终止及加购资金版本。报单入口进一步核验最新结案及可能已有的结算凭证；上传者仍须是当前未释放的本单陪玩，且有本人已开始、未终止的履约段。未完成核验不得提交，其他退款及转单组合不因此开放。

本次未运行测试或迁移，正式开关保持原值。最终须在隔离 MySQL 联调有／无加购退款、双次退款影响历史段及当前段、继续履约、结单截图、逐段报单与审核、等待期、补资不足和补足、原账号周期、重复操作及并发回滚。
