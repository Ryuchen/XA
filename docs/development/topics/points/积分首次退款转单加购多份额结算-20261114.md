# 积分首次退款转单加购多份额结算

积分服务订单首次主单退款后的转单逐段结算，仍按真实付款、退款、接替责任、补资版本和本人报单核对，但不再把单笔付款的实际责任份额限制为最多三份。多次已确认接替可能让同一付款、同一陪玩、同一履约段保留多份收益；结算计划现在只在这三个身份完全一致时合并金额，生成该付款和履约段的一条真实结算记录。不同付款、陪玩或履约段不会合并。

原付款来源、已发生退款扣减、整单资金守恒、受影响段完成确认、整单完成、本人报单及已付流水检查均保持原规则。此修改不扩大其他积分能力域，若接替或资金版本在上游仍不支持，仍不能办理。

未运行测试或迁移。最终联调需覆盖多次接替导致同段多份收益、跨付款/多人退款、来源扣减与零收益、共享到账、逐人报单冻结、已付重试以及最终实销。
