# 积分退款后接替的跨到账补资

积分服务订单首次主单退款后发生服务转单及已确认加购接替时，接替资金快照只记录当时真实存在的订单补资到账。若当时已有到账 A，后来平台再将到账 B 分配到同一订单补足资金，回放接替凭证时 B 可作为已锁定的本单当前到账见证；B 不写入旧快照，旧事件仍按当时 A 的分配、退款及释放重建。

该修正接入既有平台财务补资和到账用途回放；仍须验证原付款、转单资金版本、接替双方及老板确认、每笔历史分配和 RELEASE、当前到账归属，并由原订单结算路径按本人报单和等待期核验。没有本单真实到账见证或历史凭证不完整时继续拒绝，不生成资金流水。已付加购的后续主单退款另见 [已付加购到账回放](积分转单追加退款已付加购到账回放.md)。

未运行测试或迁移，正式开关保持原值。最终须隔离 MySQL 联调先分配 A、退款后再次转单并接替、加购退款及追加协商、之后分配 B、已付与未付陪玩、足额及不足、真实和空 RELEASE、跨库恢复、幂等、共享到账和并发锁顺序。其余未接通时序保持原有门禁。
