# 退款主单 VIP 成长授权待核对接口

仅独立平台超级管理员可以操作；路径中的门店确定业务库，不接受请求中的其他门店标识。

- `GET /api/admin/platform/store-management/{store_id}/license-vip-review?kind=PENDING` 查询授权未知记录；`kind=REVIEWED` 查询已核对记录及平台审计状态。返回订单、老板、付款与退款金额、付款/确认时 VIP 开关、原授权决定时间及可核对状态。
- `POST /api/admin/platform/store-management/{store_id}/license-vip-review/{decision_id}/resolve` 提交 `{"request_id":"UUID","outcome":"ALLOW 或 DENY","reason":"原时点证据及核对依据"}`。仅原决定为 UNKNOWN 可处理；不根据当前续期状态自动推断原时点授权。相同请求、结论和原因可由授权管理员重试，保留原操作人；请求冲突返回 409。
- 本店核对已提交而平台审计尚未提交时，列表显示 `AUDIT_PENDING`；重试补记原操作人的平台审计，不重复处理业务。跨库结果不确定返回 503，使用原请求编号核对重试。`vip_recalculation_pending` 是可变化的后续重算状态，审计保留不可变的原决定，不以该字段变化判断篡改。

本接口与会员代理开发的决定及实销流程一起使用，不影响已有订单结算；是否实际补算及发放以本店已保存事实和对应业务闭环为准。本轮未执行测试或迁移，平台审计恢复、历史事实、订单/退店周期、重复处理和双店隔离待最终联调。
