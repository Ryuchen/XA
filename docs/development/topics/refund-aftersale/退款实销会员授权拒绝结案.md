# 退款实销会员授权拒绝结案

主单已完成实销，原会员授权为 UNKNOWN，实销之后又发生退款时，平台超级管理员仍可按真实原时点授权证据在已有会员核对接口提交 DENY。服务端锁定原订单和决定，核验账号及业务周期、原 UNKNOWN 依据、付款流水、原实销时间、实销前退款基线和付款时 VIP 开关；已有退款实销或转单实销证据时，同时核验原证据摘要及归属。若已经存在会员成长确认或原事实不一致，继续待核对。拒绝结果不创建会员成长或积分，不改已获权益。

DENY 不再依赖后续退款的资金作用域或当前逐段结算能否重新构建，也不推断当前退款金额。ALLOW 仍按原有范围严格核验实际付款、逐段结算和当前所有退款来源；不扩大任何订单、退款或转单能力。平台原权限、审计和同一请求幂等保持不变；已记录的消费积分 UNKNOWN 仍由其独立接口核对。

参考 [Formance Ledger 的拒绝结果及幂等重放](https://github.com/formancehq/ledger/blob/main/docs/technical/architecture/subsystems/admission/idempotency.md) 区分拒绝结案和账本变更；本项目原交易、授权及退款证据以自身业务为准。
