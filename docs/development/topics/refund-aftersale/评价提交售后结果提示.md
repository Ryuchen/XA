# 评价提交售后结果提示

老板提交评价时，接口继续要求综合、技术、态度、沟通四项分别填写。接口响应的 `data.low_rating_aftersale_state` 返回本次评价实际记录的售后状态：`OPENED` 已创建、`ATTACHED` 已关联处理中售后、`CLOSED` 未新建或重开、`EXPIRED` 售后期已结束、`INELIGIBLE` 不符合建立条件，空字符串表示非低星。响应消息分别说明真实结果；过期低星只记录评价和提醒，不创建或扩展售后。字段只表示本次评价结果，双陪不返回另一陪玩的评价或售后信息。

现有提交事务按评价目标创建或关联售后，后台作废保留评价、原因和已有关联售后。前端展示、双陪双方隔离、门店配置的售后时限、作废后售后继续处理和并发行为仍需最终联调。本次未改前端，未运行测试或数据库迁移。
