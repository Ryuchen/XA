# 开业前签到配置

初始化中的门店，首位本店超级管理员可按原 `checkin:view`／`checkin:edit` 权限，通过 `GET/PUT /api/admin/config/checkin` 及 `checkin-gifts` 配置接口设置本店签到门槛、补签及每日签到礼。沿用现有字段校验、锁和本店数据库隔离。

配置不开放客户签到、补签或奖励发放，也不新增强制开业项目。现有授权规则允许首位管理员在配置期先录入；正式营业后的规则修改继续按 CHECKIN License 判断，实际签到及发放继续执行其各自的 License 检查。

未运行测试、建库或迁移。最终须联调开业前后授权变化、角色权限、配置并发、双店隔离和客户签到/补签边界。
