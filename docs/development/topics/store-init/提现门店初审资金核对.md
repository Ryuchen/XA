# 提现门店初审资金事实核对

门店客服初审通过前，锁定本人提现申请和所属钱包，核验该申请独立的待处理提现流水、申请金额和余额变动、申请时扣费及预计实付快照，并确认钱包冻结总额足以覆盖本次申请。冻结总额允许包含其他提现或收益冻结，不要求与本笔金额相等。流水缺失、冲正、重复关联、钱包归属或金额不一致时返回 409 待核对，不推进平台队列。

初审本身不扣款、不解冻、不创建成功提现流水；最终付款仍须平台财务按原规则完成终审、核对实际金额并登记线下凭据。客服重复提交已成功初审的同一领取事实沿用原幂等返回，不重复记账。

本次未新增结构迁移，未运行测试或迁移；最终需隔离联调多笔提现共用冻结、收益冻结共存、初审与本人取消并发、异常流水、平台驳回和打款、双店同编号及权限隔离。
