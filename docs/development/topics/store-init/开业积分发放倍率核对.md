# 开业前积分发放倍率核对

积分发放启用时，开业核验要求有权限人员确认普通会员积分倍率，并在 VIP 启用时同时核对所有生效等级的倍率；倍率 0 至 1000 为现有模型允许范围，零不被当成缺项。积分发放停用时不要求确认；VIP 停用时不要求配置或确认 VIP 等级。确认只记录配置快照，不发放积分、不改变已有权益；倍率、VIP 开关或有效等级变化会使快照重新待确认。

平台超级管理员可通过 `GET /api/admin/platform/store-management/{id}/setup` 读取 `points_award_rates` 快照，再向 `POST /api/admin/platform/store-management/{id}/setup/confirm/points_award_rates` 提交其 `fingerprint`。本店首位管理员可按已有 `dictionary:edit` 和 `engagement:edit` 权限通过 `GET/POST /api/admin/dictionaries/setup-confirmation/points_award_rates` 核对。普通会员倍率、VIP 开关及等级沿用原平台初始化和门店会员配置接口；营业后继续使用原配置与读取接口。确认记录保存在本店业务库，开业检查读取同一份记录，不跨店共用。

参考 [Shopify 会员计划配置](https://github.com/Shopify/app-intent-types/blob/main/types/application-loyalty-program.md) 对积分获取规则与等级的分离；具体开关、倍率范围与发放规则均以本项目 PRD 和现有模型为准。

按开发期约束未运行测试或迁移，仅完成 Python 语法解析。隔离环境仍需验证保存与确认、停用和重启、跨店权限、并发更改及历史订单积分快照；此项不代表开业或积分全链路已经验收。
