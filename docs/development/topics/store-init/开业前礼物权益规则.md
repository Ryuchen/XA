# 开业前礼物权益规则

初始化中的门店，首位本店超级管理员可按原 `engagement:view`／`engagement:edit` 权限，通过 `GET/POST /api/admin/gift-benefits/` 和对应明细接口维护本店礼物消费回馈规则。礼物分类、奖励类型、门槛、日期与累计规则继续使用既有校验。

门店未取得有效 `GIFTS` 授权时可保存停用草稿；创建启用规则或将规则保持启用并修改时仍须通过原 License 判断，停用已启用规则不需要新增授权。编辑先锁定规则，再判断当前启用状态与授权；该入口只保存配置，不开放客户赠礼、支付或权益发放，也不作为强制开业项。

未运行测试、建库或迁移。最终需联调双店隔离、角色权限、未授权草稿、授权启用及授权变更竞争，并验证开业前客户业务仍不可用。
