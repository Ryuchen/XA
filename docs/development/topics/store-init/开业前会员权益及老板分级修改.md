# 开业前已有老板的会员权益和分级配置

平台开业初始化现可在已有老板时修改老板分级的名称、折扣和其他普通属性；停用仍须先按现有规则处理关联的启用中 VIP 等级。VIP 等级的月券折扣、安全箱折扣与适用服务、权益设置及积分倍率等非结构性配置也可保存；门槛、顺序和启停仍走已有重算事务。

对仍处于该等级、当期有效且未使用的会员月券及安全箱券，等级条款变更后复用支付侧的有效条款计算，在配置事务内保存到对应私有券，使券列表与支付一致。已用券、退款返还并锁定的券、降级或取消等级锁定券及月中升级保留的原月券不被改写；月券数量变化不撤回或补发本月已有数量。VIP 停用时既有券沿用已保存条款。

操作使用目标门店数据库、配置版本及真实平台主体审计；多领取人等无法证明归属的券继续待核对。未运行测试或迁移，最终须在隔离环境联调月券数量增减、已用券全退、升降级和取消等级、VIP 停用重启、两店隔离及并发使用。
