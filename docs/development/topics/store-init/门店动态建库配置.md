# 门店动态建库配置

平台按门店独立业务数据库创建和初始化门店。部署设置 `XA_DYNAMIC_STORE_DATABASE_TEMPLATE_ALIAS` 指向 `XA_STORE_DATABASES` 中已配置的非 `default` MySQL 连接模板后，动态建库能力默认启用；也可显式设置 `XA_DYNAMIC_STORE_DATABASE_ENABLED=false` 关闭。未配置模板时默认关闭，接口不接受用户提供的数据库账号、密码或任意库名。

门店数据库别名及库名根据合法门店标识生成。首次建库、结构迁移、门店初始化和首位管理员均按既有平台权限及初始化流程执行；仅注册连接不会创建数据库。部署方须为模板配置合适的建库及业务访问权限，并在空库环境完成初始化。

恢复连接时使用平台控制库的原归属凭证，核对部署模板 `HOST`、`PORT` 和生成的库名。已有归属凭证的门店如果目标变化，先由平台运维检查配置，再重试。已初始化门店缺少凭证时须先核对归属。模板通过顶层连接字段设置目标，可继续配置 TLS、超时及隔离级别。会改变目标或在建连时执行命令的 MySQL `OPTIONS` 会被拒绝，包括库名和地址覆盖、socket 参数、客户端默认配置文件及 `init_command`。

控制库暂时无法读取时，允许降级的入口仍需核对已签名的本店路由快照。Mac 已登记的 MySQL 控制库验证了原归属指纹匹配、端口变化拒绝及事务回滚。动态物理建库、跨进程业务读写和双店隔离需最终联调。[开发记录](../../16-开发进度.md#2026-11-20-动态门店重连核对数据库归属)
