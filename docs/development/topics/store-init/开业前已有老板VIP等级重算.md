# 开业前已有老板的 VIP 等级调整

平台开业初始化的 VIP 等级配置现支持门店已有老板时新增启用等级、单独修改消费门槛或等级顺序、重新启用等级，以及修改消费积分倍率。启用等级及结构性调整复用门店现有会员重算：按原锁序锁钱包和会员配置，在同一门店事务核对真实老板及等级事实，固化适用的已发券条款，依据新等级更新会员并按现有规则发放升级权益。VIP 停用时沿用既有延迟重算规则。

平台操作在门店审计中保留真实平台账号和平台操作编号，不冒充店内管理员；原门店操作的审计身份保持不变。开店状态、配置版本、会员重算及权益保护开关、License 权益约束均沿用现有要求。

本次只处理单项调整；多等级批量调整、等级停用、VIP 开关以及已有老板时其他等级权益修改仍须接通各自真实流程，不能把当前边界当作最终产品范围。未运行测试或迁移；最终隔离联调须覆盖新增／升降级、既有券及升级权益、VIP 停用后重启、双店身份隔离、并发付款和失败回滚。
