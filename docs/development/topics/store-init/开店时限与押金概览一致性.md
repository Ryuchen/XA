# 开店时限与押金概览

新服务订单付款时已经从本店 `settlement_clock_rules` 保存售后等待和收益冻结快照；两者分别从整单完成及本人有效报单提交时起算、并行等待。平台开店押金配置、陪玩注册及押金概览此前通过旧规则固定返回 0 或 72 小时，即使门店已配置其他冻结时间，接口仍显示旧值。

上述押金规则和概览现读取同一门店时限配置，分别返回收益冻结 `hold_hours`、售后等待 `aftersale_hours` 和配置版本。该数据描述新服务订单的当前配置，已付款订单仍使用各自付款快照；旧独立报单的处理没有改动。
