# 提现收款方式业务周期

陪玩保存的提现收款方式绑定创建时的本店业务周期；本人查询、修改和解绑仅操作当前周期，按账号、周期和方式各保留一条。注销后重新入驻需重新维护收款方式；旧绑定不会出现在新周期，也不能凭旧 ID 和版本用于新提现。提现提交在钱包锁内再次核验被选择的收款方式属于本周期，失败发生在占幂等键和冻结余额之前。

已提交提现继续使用申请自身保存的收款人、方式和账号快照；本项不改写历史申请、账本或打款状态。提现列表的历史展示语义未在本项调整。

新增 wallet/0062 依赖 0061，按首版空库结构部署，不推断旧记录所属周期；本轮未执行迁移或测试。需最终隔离联调双店、注销重入、旧 ID 重放、并发修改／提现、回滚和实际付款核对。
