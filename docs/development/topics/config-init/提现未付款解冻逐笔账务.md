# 提现未付款解冻逐笔账务

陪玩初审前取消、门店客服驳回，以及平台财务确认未付款后驳回或取消，现统一使用本店钱包解冻服务。持有提现和钱包锁时，同一事务将本申请金额从冻结退回可用余额、将原待处理提现流水标记失败，并保存独立的逐笔解冻记录：关联申请、原流水、钱包、金额、前后余额和冻结额、真实操作主体及原因。平台事件同时保存解冻记录编号；陪玩查询申请可读取解冻金额、原因及时间。未付款解冻不会创建成功提现支出。

已登记付款仍沿用平台终审后实际线下凭据和金额核验、消费原冻结并记提现及业务扣除的原路径；`PAYMENT_UNKNOWN` 只能在有权人员明确核实未付款后解冻。一次申请及其原流水各最多关联一笔解冻事实，现有请求重试继续使用原幂等记录。本店业务和平台审计分库，平台事件审计恢复沿用原机制。

新增结构迁移 `wallet/0057_withdrawalrelease`，依赖 `0056_recharge_account_business_cycle`，本轮未执行迁移或测试，也不回填旧申请。上线前需迁移空库，并在隔离环境联调本人取消与初审竞争、客服和平台驳回、待核实后取消、已付款拒绝解冻、多笔共享冻结、重复请求、事务回滚、账号周期与双店隔离；真实线下打款仍须财务独立核实。
