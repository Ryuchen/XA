# 平台门店域名配置（待最终联调）

平台独立超级管理员使用 `/api/admin/platform/store-management/{store_id}/domains`；GET 返回本店域名、状态、版本和共享索引目录是否配置。PUT 请求 `{"hostname":"shop.example.com","active":true,"revision":0}` 新建；修改时填写 GET 返回的版本。域名必须小写、完整、非 IP，且在部署 `ALLOWED_HOSTS` 中。部署保留的声浪、兴安及统一后台域名不由此接口更改。域名一旦分配，撤销后仍保留原门店归属，不支持跨店转移。

部署需设置 `STORE_DOMAIN_INDEX_DIR` 为所有应用实例共享、可靠持久且支持原子替换和跨实例文件锁的既有目录，并限制写权限；未配置或不可写时域名变更不可用。操作先写签名拒绝状态，再提交控制库，随后发布本店签名路由快照和启用索引；提交或发布不确定时离线路由拒绝，接口返回待核对，管理员重新读取后处理。目录数据库故障时，只有签名索引、目标门店数据库身份和最新门店快照一致才允许离线定位。控制库恢复后重新读取真实绑定。

域名归属不替代 TLS、DNS、反向代理和 `ALLOWED_HOSTS`；这些仍由部署负责。HTTP 和 WebSocket 均先检查允许的 Host，再检查门店绑定；请求的 `store` 参数或头不能选择其他门店。当前代码未执行测试或迁移，不代表可正式上线；须联调多实例共享索引锁、进程崩溃／提交不确定、撤销与恢复、控制库和店库故障、动态建库重启发现、HTTP／WebSocket 及真实反代和证书。

- 配置期允许保存尚未绑定的入口地址；平台 setup 显示原始配置供授权人员核对，公开门店资料只返回已确认属于本店的链接，否则返回空。已绑定的动态域名可作为本店规范入口；目录及可信索引均不可用时不伪造地址。首次 Host 路由遇目录异常返回 503。未执行测试或迁移。
