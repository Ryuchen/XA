# 平台授权档案分页

平台按店查询授权码记录仍使用 `GET /api/admin/platform/store-management/{store_id}/licenses`，默认每页最多 100 条；响应 `data.results` 沿用原记录格式，新增 `data.next_cursor`。有下一页时将该值作为 `cursor` 查询参数提交；为 null 表示已读完。游标签名绑定门店，按创建时间及唯一记录 ID 倒序定位，翻页期间新增记录不会挤走后续历史。

列表仅返回签发、合同和状态信息，不返回授权码明文或摘要；平台独立身份和 `stores:manage` 权限不变。无数据库结构变更。未运行测试或迁移，需联调同一创建时间记录、翻页期间新签发、跨店游标与权限撤销。

平台列表同时返回 `backdate_reason`、`created_by`、`voided_by` 和 `activated_by_account_id`：无追溯原因、未作废或未激活分别为 null；重发显示新码签发人并保留原合同和原追溯原因。本店激活响应不增加平台操作者身份。
