# 平台初始化老板分级

新店空库没有默认老板分级，而 VIP 等级需要关联老板分级。平台初始化总览的 `membership` 现返回 `boss_types`，并将其纳入原 `version`；平台超级管理员可调用既有 `PUT /api/admin/platform/store-management/<门店ID>/setup/membership/boss-type`，提供 `version`、`id`（新增为 null）和 `configuration`，使用本店后台同一分级字段与校验创建或修改。随后可用返回的新版本配置关联的 VIP 等级。

该入口只允许首次开业配置中且尚无老板账号的门店，使用本店 VIP 配置锁和版本校验并记录平台及门店审计；门店后台分级创建也使用同一配置锁。关联启用中 VIP 等级的分级不能直接停用。不会自动创建等级、改变现有会员、确认开业条件或激活 License。

未运行测试或迁移。最终需在隔离新店联调平台及门店权限、并发创建/编辑、分级与 VIP 等级关联、初始化配置确认、License 激活和首次开业；涉及已有老板账号的分级或会员变更仍须使用原门店业务流程。
