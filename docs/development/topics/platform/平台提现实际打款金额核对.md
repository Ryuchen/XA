# 平台提现线下打款金额核对

陪玩申请仍先冻结，门店客服初审不记打款；平台终审通过后，财务实际线下付款并登记凭据、时间和实际人民币金额。平台 `paid` 接口新增必填 `paid_amount_fen`，必须为正整数，单位人民币分；须与提现申请已固化的 `actual_amount`（同为人民币分）一致。成功登记时在本店平台提现事件及可恢复的平台审计中记录该实际金额，随后按既有逻辑一次消费冻结、标记提现流水成功并记费用。

若申报金额与申请快照不一致，原处于平台终审通过的申请转 `PAYMENT_UNKNOWN`，在本店事件中记录申报金额、预期金额、申报凭据及申报时间，保留冻结和待处理提现流水，不认定已打款；操作可用同一请求编号幂等恢复。已处于待核对的申请如再次提交不一致金额，保持待核对并返回冲突，不重复写事件。核实后只能依据真实凭据按既有待核对流程处理，不得重复打款或盲目解冻。

此接口新增必填字段需要前端对接；本次未修改前端。复用既有事件 JSON，无新增结构迁移。本轮未运行测试或迁移；启用前需隔离联调金额一致与不一致、待核对恢复、重复请求、跨店授权、付款登记失败及冻结/驳回并发。外部线下打款本身不由系统执行，系统不能独立证明渠道付款事实。
