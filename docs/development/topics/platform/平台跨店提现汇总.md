# 平台跨店提现汇总（待最终联调）

平台超级管理员在具备 `dashboard:view` 权限时，可从已初始化的各门店独立数据库读取已登记打款的提现笔数及扣税后实付，停用门店的历史数据也纳入。各门店金额与币种单独返回，并按现有人民币换算返回以分为单位的跨店部分合计；不将不同店币直接相加。

门店库不可访问时返回 `UNAVAILABLE`。打款结果待核实、打款事实或钱包归属不完整时，该店提现指标返回 `REVIEW`，笔数及金额为 `null`。人民币合计只包含可核验的门店，任一门店失败或需核对时汇总标记为不完整。若无可核验门店，人民币合计为 `null`。

每店用一条查询读取候选申请、原扣款流水和实际打款事件，核验后按申请累计。已付申请必须有唯一的门店打款事件，事件与申请的实付、凭证号、打款时点和登记人一致。钱包扣款成功、账户归属、余额变动和申请金额须一致。历史事件缺原登记实付时需人工核对。

隔离 SQLite 和双店 MySQL 已验终审未打款、结果待核对及确认未付后恢复。经实际登记接口补验了非零实付、原事件异常和健康店继续纳入部分合计。真实线下打款、页面分项提示及大历史量待联调。[验证记录](../../16-开发进度.md#2026-11-24-平台总览核对提现打款事件)
