# 平台跨店提现汇总（待最终联调）

平台超级管理员在具备 `dashboard:view` 权限时，可从已初始化的各门店独立数据库读取已登记打款的提现笔数及扣税后实付，停用门店的历史数据也纳入。各门店金额与币种单独返回，并按现有人民币换算返回以分为单位的跨店部分合计；不将不同店币直接相加。

门店库不可访问时返回 `UNAVAILABLE`；打款事实或钱包归属不完整时返回 `REVIEW`，对应金额为 `null`。人民币合计只包含可核验的门店，任一门店失败或需核对时汇总标记为不完整；没有任何可核验门店时不返回伪造的零值。

本轮未执行检查、测试或数据库迁移；权限隔离、真实已打款流水、跨店故障和数据完整性须在最终联调中验证。
