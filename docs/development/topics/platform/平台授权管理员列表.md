# 平台门店授权管理员列表

`GET /api/admin/platform/store-management/{store_id}/license-activators` 供独立平台超级管理员查看指定门店的显式 License 激活授权，沿用 `stores:manage` 和统一后台域名限制。返回本店所有授权与撤销记录，包括账号编号、授权状态和登记时间；授权变更仍使用原有 PUT/DELETE 接口。

身份只从指定门店库核验：`identity_status` 为 `MATCH`、`MISSING`、`MISMATCH` 或 `UNKNOWN`，仅匹配时返回昵称；`account_eligible` 反映该身份当前是否是可登录后台账号。门店库不可用或尚未初始化时 `identity_available=false`，身份及资格未知，控制库内真实授权状态仍可查看，不把离线当撤销。

无需新增数据库结构。未执行测试或迁移；需在隔离环境联调平台角色撤销、门店库离线、账号身份不匹配及跨店隔离。
