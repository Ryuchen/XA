# 已结算服务实销的授权决定

服务订单在真实结算后确认会员成长时，即使其转单、退款或加购组合不属于已有专项核验分支，也会在本店确认事务内记录当时的 `VIP_GROWTH` 授权结果及实际订单、账号周期和退款净额。授权允许时沿用原会员确认；明确拒绝不计成长；暂不可核验时保留真实待核对决定，不能在恢复后自动当作已授权。成就仍按原独立实销规则处理。

消费积分独立按实际本金、付款快照和积分开关记录待核对；若普通支付来源暂无法核验，保留实际付款快照标识及待核对状态，不猜金额、不制造积分流水。混合付款的积分退款基线按真实已退本金而非退款总额保存。复杂组合能否补发仍由现有平台审核对真实付款、退款、逐段结算及原账号周期的能力决定；未支持或证据不足的情况继续待核对，不代表已完成自动恢复。

本次不改变已支付、已结算或已发权益；未运行测试或迁移，最终需在隔离库联调授权在确认时的变化、混合付款及多笔退款的人工核对。

### 普通混合来源服务的 UNKNOWN 核对
平台原会员授权审核入口现在可核对未转单、无已付款加购且未退款的普通服务：使用原付款来源、售后等待及本人报单、逐人收益和门店/推荐流水证明已结算，并继续按原授权决定和业务周期执行既有成长重算、消费积分审核。已有一笔协商退款的路径仍走原协商结算核验；本次新增路径不推断实销后退款，多次退款、转单及加购仍受各自证据路径限制。旧已发权益不追回。未运行测试或迁移；真实数据库并发、退款与授权故障恢复需最终联调。

### 普通服务多笔加购的 UNKNOWN 核对
普通混合资金服务订单关联多笔实际加购时，平台主单授权审核逐笔读取付款和退款，并复用加购真实收付款、双方确认和承担凭证的核验；逐笔实销须与原账号周期、实销金额和本金退款一致，主单及各陪玩结算继续由既有结算核验器确认。移除一笔加购和每笔一次退款的数量限制；主单退款与未接通结算组合仍沿用既有范围。此处只核对主单，既有加购授权和积分独立审核、幂等流水及已发权益不变。未运行测试或迁移，需最终联调实际多笔退款和结算证据。

### 转单清单中的全退加购
普通转单最终结算清单中，全额退款的加购可能没有待付分段；平台主单 UNKNOWN 审核会从清单内真实加购退款 ID 关联对应付款，核对该付款全部退款合计等于实付，再按原流程逐笔核验付款、退款、实销及账号周期。未全退或清单无法证明的付款仍待核对；主单成长与加购权益仍各自核对、独立幂等。实际转单、退款和授权故障恢复尚未联调，未执行测试或迁移。

### 积分转单二次退款的多承担人
积分订单转单后再次主单退款，实际写入允许多名陪玩分别承担；会员实销核验现逐人对照方案、待结收益/钱包/押金承担并合计实际追回，核对已付款人员不在再次承担范围。平台 UNKNOWN 审核对已最终结算的同一真实转单使用结算作用域及只读退款核验，继续复用逐段结算、真实原付款、退款本金和补资版本；各笔加购仍按独立实销及授权决定核对。资金版本与结算核验器不支持的组合继续待核对；未测试或执行迁移，需最终联调多承担人及跨库审计。

### 同一积分转单的主单和加购授权恢复
平台分别确认同一服务订单主单及一笔或多笔加购的 UNKNOWN 授权后，自动任务可在同一订单事务中按原审核人员与请求逐项复核，主单沿已结算转单作用域校验退款、逐段收益和补资，加购校验各自付款、退款和实销。全部记录及原账号周期一致后统一重算，避免单笔重算遗漏其他待处理成长；任何证据未通过均保留待处理，跨订单或礼物混合仍不放行。此变更不重发消费积分，不改原审核与已付收益。未运行测试或迁移，跨库审计及并发锁序需最终联调。

### 普通服务带加购的追加退款核对
普通混合资金服务有加购且先后发生两笔主单协商退款时，会员实销及平台 UNKNOWN 审核改用实际追加协商的最终结算核验：两笔退款须分别关联前后真实执行，核对已确认承担、整单补资和各人实际收入，再逐笔核对加购付款退款与原账号周期。主单消费积分仍按自身原付款本金及累计本金退款核算；加购权益各自记录和幂等。其他退款数量、结算凭证缺失或后续资金时序不在本次范围，保留待核对。未测试或执行迁移，真实结算与平台跨库审核需最终联调。


### 加购成就授权 UNKNOWN 平台核对
加购真实实销产生的成就 UNKNOWN 事件现可按本店原付款、结算、加购实销及账号周期核对：平台可依据原授权事实独立记录拒绝；首笔加购构成原汇总、无退款且逐段或逐人结算及原规则均可证明时，可幂等补记当时已达标成就。VIP 是否启用或获授权不参与该判断。原事件未保存逐项历史汇总，其他已有实销、多笔加购及退款后的原汇总暂留待核对，不凭当前净额倒推历史；已解锁成就和当前退款净统计规则不变。未运行测试或迁移，真实结算核验与平台跨库审计需最终联调。

### 成就 UNKNOWN 的逐笔原时点快照
成就授权 UNKNOWN 事件现随真实实销写入本账号周期的主单、加购及各自已发生退款 ID/金额和当时启用的成就规则，并保存摘要；原统计与逐笔合计不一致时不伪造快照。平台审核 ALLOW 以该快照逐笔对照本店真实付款、退款、原实销时点、账号周期及规则后，按事件时达标规则幂等补记；之后的退款不改写原快照，当前净实销仍由实际退款冲减，已解锁成就保留。VIP 授权不作为成就条件。证据缺失、原账号周期变化、规则被删除或流水无法核验时保留待核对，原平台权限及审计不变；事件记录与平台审核在不同库提交，恢复和并发需最终联调。新增 engagement/0056 仅结构迁移文件，未执行测试或迁移。

### 协商退款的原成就快照核验
成就 UNKNOWN 快照中的普通协商退款，平台审核现通过该笔退款关联的真实 NegotiationExecution、各方确认和老板退款流水核验；积分退款继续核对其独立 OrderPointsRefund，普通直接退款继续核对退款自身流水。仅纳入原成就事件时已发生的退款，其他订单及之后退款不计入原快照；已解锁成就不因退款撤销。未测试或迁移，追加协商及转单凭证仍受其真实资金核验范围限制。

### 全退主单触发的成就事件
主单在确认前已全额退款时，事件快照单独记录该订单真实付款和全部退款作为事件来源；它不参与主单实销金额和订单数。平台审核原授权 ALLOW 时先按本店原周期核验该零净额来源的各笔退款和结算时点，再按同一快照中其他已确认主单、加购和当时规则判断达标；证据不全仍待核对。已解锁成就不因退款撤销，VIP 开关不影响成就统计。未运行测试或迁移，多次协商及转单的真实结算需最终联调。

### 积分订单的成就退款构成回读
成就 UNKNOWN 快照审核遇到积分支付服务订单的真实退款时，在本店订单资金互斥内复用支付构成历史回放，逐笔核验原抵扣积分、店币来源、退回积分及钱包流水。审核要求事件时点前的退款与原快照一致；之后退款只参与当前来源一致性检查，不改变当时统计或已解锁成就。该回放不在持有资金互斥后反向获取其他订单锁；底层无法证明的版本继续待核对。未运行测试或迁移，并发锁序与复杂转单需最终联调。

### 加购成就原结算来源
真实加购实销确认要求当时有效责任段与已结算段一致；UNKNOWN 成就快照现额外保存每笔加购在确认时已有的普通或逐段结算行。平台审核逐行对照原订单、履约段、报单及陪玩收入流水；有净实付而没有对应结算行仍待核对，全额退款且无剩余责任的有效零结算保留。后续退款不改原快照或已解锁成就，多笔加购逐笔核对且不依赖 VIP。未测试或迁移，双陪、接替及退款后历史结算仍需最终联调。
