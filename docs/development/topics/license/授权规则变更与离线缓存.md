# 授权规则变更与离线缓存

平台修改默认宽限期、某店宽限期或档位增值功能时，对受影响且已初始化的门店，先在各门店库使旧授权缓存失效，再提交平台规则和审计；提交后重新读取平台规则并刷新各店缓存。默认宽限期不影响已设置独立宽限期的门店；档位功能修改覆盖曾激活该档授权的门店，包括未来授权可能使用该档的情况。

门店成功激活新的授权码时，也先使该店旧缓存失效，再提交激活并刷新。未来生效的续期或调档因此能写入离线缓存，控制库故障期间仍按已核验的生效和到期时间切换；重复提交已激活的码仍返回原结果。

平台和门店数据库没有共同事务：若某门店缓存无法失效，平台变更不会提交；若部分缓存已失效但平台事务随后回滚，这些门店可在控制库恢复后通过正常在线核验重新生成缓存。提交后刷新失败时，门店不能把旧缓存当成新授权；已有用户的订单、履约及资金业务仍按控制库不可用时的既定规则处理。

本轮未运行测试或迁移。最终联调须覆盖授权激活与重复提交、默认及独立宽限期、当前及未来授权档位、平台变更与门店查询并发、跨库失败与回滚、控制库断连和双店隔离。
