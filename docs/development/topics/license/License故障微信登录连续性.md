# 控制库故障时的微信登录连续性

门店路由已经通过域名及控制目录或签名路由快照确定后，老板和陪玩微信 H5 登录发起时，如控制库读取失败，返回来源仅接受该本店对应端在可信门店记录中的入口；不能凭请求头、查询参数或其他门店来源确定身份。正常情况下仍沿用既有来源配置。

网页登录会话的管理后台票据识别在控制库故障时，仅当票据中的门店编号与当前已解析门店一致、且本店业务库确有对应网页登录会话时，继续走门店登录。会话有效期、微信真实授权、账号状态、令牌签发及新增账号配额仍由原流程验证；无法核实的后台或未知票据不作本店票据处理。控制库恢复后继续在线识别。（微信小程序桥接票据相关内容已按用户 2026-11-17 决定删除）

已有 License 签名快照及账号、权益门禁继续负责按授权时间判断准入；没有可信授权时不新增账号或权益，本次不改变钱包、订单或已有权益。后台平台登录仍依赖控制库；微信渠道仍须实际配置并完成真实授权。

未执行测试或迁移。最终联调需覆盖控制库故障前后 H5 和微信网页授权登录、可信路由快照与授权快照、无快照阻断新增账号、跨店票据和失效会话，以及微信实际渠道回调。
