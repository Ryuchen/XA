# 控制库故障时动态门店任务恢复

当前 HTTP 和 WebSocket 路由已支持在控制库故障时，从服务端固定门店域名绑定或签名域名索引定位门店，再核验本店签名路由快照及数据库身份；身份令牌仍须匹配本店账号，路由缓存本身不是身份或 License。授权另由本店签名 License 快照验证；没有可信授权时新增账号和增值权益继续受限，核心业务不因授权缓存缺失被当作新权益开放。

此前周期任务只扫描当前进程已注册的门店数据库别名。动态门店 worker 刚重启、尚未在该进程处理请求时，即使门店可信快照存在，控制库故障后也可能找不到任何门店，导致订单超时、实销或收益释放扫描无法入队。

现在离线周期扫描从服务端固定域名绑定及签名有效且启用的域名索引恢复候选动态连接，再逐一验证目标门店的签名路由快照、域名版本及数据库身份；同一门店按真实标识去重，存在冲突时不推断目标。恢复连接仅注册进程内配置，不创建、迁移或清理数据库。未知、停用、签名无效或与本店快照不符的动态域名不会回落至其他门店。

动态域名跨实例恢复仍要求部署配置可信共享 `STORE_DOMAIN_INDEX_DIR`，并先成功发布门店路由快照与索引；目录或本店数据库不可用时不能凭空恢复。未执行测试或迁移；最终须在隔离环境联调控制库故障、worker 冷启动、HTTP/WebSocket、无 License 缓存、动态域名停用、重启恢复及跨店身份和周期任务。
