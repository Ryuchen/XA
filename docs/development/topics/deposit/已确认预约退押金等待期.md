# 已确认预约与退押金等待期

退押金资格现纳入尚未转单的已确认预约：单陪以本人确认的真实预约为准；双陪仅在本人席位已确认时计入，即使另一席仍等待确认也阻断退押金。未确认邀请不冒充本人承诺。后台预览和锁内实际退还使用同一检查，并返回 `active_reservation_count` 及具体原因。

已确认预约取消、过期或转单后，根据预约结束状态和对应真实状态日志确认结束时刻；与既有订单、收益、售后及押金缴清证据取较晚的实际结清时刻，再计算七天。转单还须能找到本人参与的真实订单，后续订单和收益继续按既有规则核对。确认或结束事实缺失、时序异常、转单归属不可证明时返回 `REVIEW`，不推测时间。新确认预约出现时重新阻断，结束后重新起算；未变更押金金额、退款或钱包记账。

本次未新增结构迁移，按要求未运行测试或迁移。仍需隔离联调单陪、双陪一席确认及另一席拒绝/超时/重选、预约取消/到期/转单、七天边界、本人周期变化、确认与退押金并发和双店隔离；现有特殊退款及转单组合的既有待核对边界仍然存在。
