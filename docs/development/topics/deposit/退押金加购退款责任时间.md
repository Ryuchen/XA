# 退押金等待期与加购退款责任

加购退款可以由非加购原负责人共同承担，资金可能来自本人其他未结收益、钱包或押金。退押金结清回放此前只在本人作为原负责人或接替份额持有人的加购中查退款，遗漏这种参与人。本次改为直接查真实退款参与人，并核对确认方案、责任金额、老板退款流水以及本人钱包扣款和押金承担流水，将真实记账与责任记录的时点纳入七天等待。没有参与该笔退款的陪玩不会因该笔退款额外重算等待期。现有资格预览和后台退还事务均使用此回放。

资金凭证无法核对时仍为待核对；此改动不扩大现有订单、加购或售后的资金支持范围，也不替代在途业务和收益冻结的门禁。没有运行测试或迁移。最终隔离联调应覆盖双陪另一人承担退款、钱包及押金组合、无本人责任的退款、等待内新增售后与结清，以及退押金与业务并发。
