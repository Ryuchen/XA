# KOOK 积分门店配置

本店有 `engagement:view` / `engagement:edit` 权限的后台人员可通过 `GET/PUT /api/admin/config/kook-points/` 读取和设置版本、启用状态、KOOK 服务器和签到频道；开业前首位管理员也可保存禁用草稿。启用在配置锁后重新检查 CHECKIN License，关闭不依赖授权；此配置不会创建机器人连接或虚报在线。语音频道仍由每店监听器以真实 KOOK API 发现，机器人凭据沿用该店 KOOK 派单配置。

配置变化增加 revision、清除旧心跳及频道并记录新起点；监听器的事件、计时 checkpoint、在线快照和频道更新均绑定对应 revision，旧连接不能在新配置上发分，重连后以真实在线快照重新开始。上次 checkpoint 后到配置切换之间没有可靠的完整在线事实，不猜测补发；已发积分和历史绑定不清除。监听进程仍须按店实际部署，接口保存不等于机器人已连通或渠道已验收。

新增 engagement/0044 结构迁移文件，未运行迁移或测试。最终须联调跨店、配置与 checkpoint 并发、授权到期、切换/断线和在线快照、真实 KOOK 频道权限及失败恢复；开关、消息及外部网络不可伪造成功。

在线积分规则支持毫秒配置后，状态接口的规则说明保留小数秒，例如 1500 毫秒显示为 1.5 秒，不再向下显示为 1 秒；实际计分仍按保存的毫秒数计算。本次仅修改状态说明，未运行测试。
