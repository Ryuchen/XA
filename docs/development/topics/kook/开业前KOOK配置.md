# 开业前 KOOK 派单配置

初始化门店的首位本店管理员可依原 `dispatch_config:view` / `dispatch_config:edit` 权限读取和保存 KOOK 配置，并预览模板。禁用状态下可录入机器人密钥与频道草稿；Token 沿用现有加密存储、路由校验和 revision 并发校验。每次保存启用状态均检查 CONTENT_OPERATIONS License，授权失效时仍可关闭或保存禁用配置。

仅放行配置与本地模板预览，不开放外部频道查询、测试发送或客户业务。企微群尚无同等后台配置接口，本次未实现。未运行测试、迁移或建库；门店隔离、凭据读取、授权变更及版本竞争须最终联调，渠道是否真实可用仍需外部验收。
