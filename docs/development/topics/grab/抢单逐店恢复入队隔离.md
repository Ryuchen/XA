# 抢单逐店恢复入队隔离

逐店 `orders.tasks.check_pending_timeouts` 扫描待开池订单、到期及留池单陪／双陪仲裁、普通到期取消时，每笔任务独立入队。某笔入队抛错只记录该订单的入队结果未确认，继续处理本店其他候选；原订单与收件事实不被改写，下次扫描按持久状态重新发现。消息可能已被代理接受，重复任务依原订单锁、时钟和退款幂等规则处理。

扫描返回值是普通到期候选数，不表示已仲裁、已退款或客户端已收到通知。不开启抢单开关，不改变窗口、排序、老板取消优先、组队或退款规则；无需新增迁移，未运行测试或迁移。最终须在隔离环境联调代理故障、重复入队、逐店隔离及真实仲裁退款。
