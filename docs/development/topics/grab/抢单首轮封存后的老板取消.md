# 首轮封存后的老板取消

首轮候选集合已封存但订单仍待分配时，老板仍可在该轮真实总等待期限内提交取消。此取消按总期限保存独立收件，不改变已封存的首轮候选摘要；单陪和双陪仲裁在分配前先读取已提交的取消，确认及时后复用原取消退款事务。待确认的真实收件仍阻止直接分配，已分配订单不能再按待抢单取消。

老板请求先在本店订单锁内登记取消，再触发仲裁。取消使用总等待期限，时间不确定时保留待核对，明确已晚时返回 `GRAB_CANCEL_CLOSED`。逐店任务可以恢复已登记的取消。主动取消的普通币退款单和流水保存经办老板。Mac 隔离 MySQL 和 Celery 已验证首窗封存后的双陪取消，以及同期限时定时任务等待原取消证据。单陪实库、跨截止区间和混合资金待联调。[验收记录](../../16-开发进度.md#2026-11-21-抢单取消登记与截止竞争)
