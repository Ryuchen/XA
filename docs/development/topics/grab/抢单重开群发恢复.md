# 抢单重开后的群发恢复

首名候选失格重开时，轮次实际激活提交后会重新调度仍待发送的 KOOK／企微派单记录，不继续等待首轮的通行证可见延迟。已有的逐店恢复扫描也会发现仍使用旧延迟的记录，按最新真实轮次补排；每次实际发送仍重新锁定订单并检查资格、截止和渠道。重开轮次尚未完成激活时，旧任务保留待发，不提前发送或标为跳过。

只处理待发送及明确队列入队失败的记录，已发送、发送中和外部结果不明的记录不会自动重发。初轮分级延迟不变；群发和派单结果各自独立。依赖原有逐店恢复任务、正式抢单时钟及 `GRAB_POOL_GROUP_DISPATCH_ENABLED`（默认关闭），不新增迁移。未运行测试或迁移；须最终隔离联调激活中断、队列异常、不同门店及实际渠道反馈。
