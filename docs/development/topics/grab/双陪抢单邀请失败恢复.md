# 双陪抢单邀请失败恢复

邀请请求始终在本店生命周期锁中记录邀请人及受邀人的真实账号周期。`GRAB_INVITE_NOTICE_RECOVERY_ENABLED` 打开后，逐店任务使用这些已保存的收件事实恢复失败投递，不再依赖陪玩注销生命周期集成总开关。未保存原周期的旧事实不发送。

投递锁定本店订单及双方账号，核对邀请人与受邀人原周期、真实邀请及轮次状态；邀请人退店重入、受邀人周期变化或邀请结束时记录跳过，不向新周期发送。发送事务失败不创建成功记录，下次扫描继续尝试；已创建站内消息不代表客户端实时收到。

专属恢复开关默认关闭，需已应用现有收件与通知结构并运行逐店任务；未运行测试或迁移，双店、周期竞争与 worker 恢复留待最终联调。
