# 免费安全箱单陪抢单取消退券

对尚未分配陪玩的零实付安全箱本人抽成订单，单陪抢单的用户取消与无候选超时取消共用同一退款事务。订单锁及资金互斥下，先核对已提交并观察的开池意向、原零金额付款记录、原已用券及老板业务周期、平台补贴和待分配资金覆盖，确认没有陪玩分配或补贴份额；随后复用现有零额退款和原券返还流程。只有退款记录为零、原券确实返回原周期且没有补贴份额时，才在退款权益事实中记录意向、付款、补贴和券的来源。任一核对失败则事务回滚，不能虚构钱包退款。

取消退券不要求当前 License 仍有效，也不因之后关闭开池或补贴开关而剥夺原券。券返回后仍须符合原有效期和正常使用条件。已分配或已开始服务的取消、补贴份额结算、双陪、预约抢单及其他零付款来源不在本次范围；原退款流程对原价分段记录仍标记待核对，不表示已经发生平台补贴支出。
