# 免费安全箱三角洲单陪抢单

老板使用本业务周期已获的免费安全箱券、订单真实应付为零、未指定陪玩且选择公开单陪自动抢单时，可保留付款时冻结的三角洲本人档位规则，待接单人确定后才生成本人抽成及平台补贴份额。券消费、订单、零金额付款记录、平台补贴、分段资金覆盖和开池意向在同一门店事务提交；任何证据不一致时整笔回滚。零金额付款记录只确认本次确实无需扣款，陪玩收入仍须由真实平台补贴结算，不将零付款冒充资金来源。

开池意向在事务提交后由既有数据库时钟观察流程处理，重复核对同一老板周期的已用安全箱券、零付款、正额补贴、订单折扣和冻结的三角洲规则；不能证明时保持待重试或待核对。候选人入池时按付款冻结规则与本人资格验证，最终分配在锁内重验，单陪补贴份额按本人冻结比例计算并进入既有履约、审核和补贴结算链。不得绕过候选人资格或提前写入补贴收入流水。

此路径要求正式 MySQL 抢单时钟与 `GRAB_COMMITTED_OPENING_ENABLED`、`GRAB_SINGLE_WINDOW_ENABLED`、`PROVIDER_LIFECYCLE_INTEGRATION_ENABLED`、`GAME_COMMISSION_PAYMENT_ENABLED`、`VIP_SAFE_BOX_SUBSIDY_ENABLED`、`VIP_SAFE_BOX_SEGMENT_CAPTURE_ENABLED`、`ORIGINAL_ATTRIBUTION_ENABLED` 和分段资金快照能力均已启用；缺少条件时继续拒绝。服务范围快照也须启用。本次未覆盖双陪、预约抢单、积分抵扣或其他零实付来源；此前已接入的指定陪玩免费安全箱预约转单不属于本次范围。指定陪玩和普通正额订单沿用原流程。

本次未运行测试或迁移。最终需在隔离真实数据库联调提交前不可见、提交后开池与重试、券与补贴证据不一致回滚、候选资格变化、并发抢单及超时取消、改派、报单和平台补贴结算，以及相关配置开关和锁顺序。
