# 默认本金主单退款后的授权核对

已结算、实销前已发生主单退款的默认本金普通订单，在原付款和当前门店 VIP 开关均启用时，记录实销时 VIP_GROWTH 决定；无论是否有已付款加购，主单与加购分别留决定。UNKNOWN 不创建主单会员成长确认，并按实销时实际未退本金及付款倍率保留消费积分待核对事实；DENY 不因续期自动补发。订单付款、履约结算和已发权益不重做、不撤销。

平台仍使用既有会员和积分核对接口。会员核对核实原本金支付流水、付款来源、所有已登记退款和实际退回钱包流水，并用核对时当前净本金判断是否恢复成长；积分核对以实销时退款基线及此后新增退款分别计算，防止重复补发。全额退款不会恢复成长，账号业务周期变化仍按现有核对规则处理。含加购的主单与加购独立处理，不用一笔决定代替另一笔。

本范围不覆盖转单、来源单或来源证据不完整的组合。当前逐段转单及协商退款的既有校验要求 formal `funding_terms` 和专用份额证明；默认 `funding_terms` 为空的记录不能冒用该证明。本次未改底层订单/退款资金路由，也不代表该类组合已可达或已完成开发。
