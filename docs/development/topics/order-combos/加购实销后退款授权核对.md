# 加购实销后退款的授权核对

加购会员与积分的原授权决定在实销时分别保存；其中 UNKNOWN 可由平台超级管理员通过现有加购授权核对接口按原时点资料裁定。若实销前已有退款、核对前又发生后续退款，核对会复用真实加购付款及退款流水校验，并逐笔读取已执行退款方案的原付款来源：实销前退回的本金须等于授权决定中的本金退款基线，各来源所有退款合计须等于当前实际退款。来源缺失或不一致时保持待核对，不猜测金额。

核对允许时按核对时尚未退款的实际本金和付款时积分倍率计算，原请求幂等，后续退款继续走已有积分冲回。全额退款不再标记为恢复会员成长；已发权益及原付款流水不修改。明确 DENY 不补发，账号业务周期改变时不向新周期恢复；平台审计和原有待重算流程不变。该证据校验只用于人工核对，不插入正在执行的退款链路。

参考 [Payments Wallet Service 的部分退款账本处理](https://github.com/SaiKrishnaMulukutla/payments-wallet-service/blob/main/docs/PLAN.md) 对已付款额与累计退款分别对账；本项目依照现有来源快照、会员规则和授权决定实施。
