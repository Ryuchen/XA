# 未付款加购意向的主单授权确认

默认本金主单曾创建加购意向但没有加购付款时，该意向本身不代表消费。主单完成实销后仍须按实销时 License 单独记录会员授权；UNKNOWN 留待平台核对并按已有规则单独保留消费积分决定，DENY 不在续期后自动补发。主单结算、未付款意向和已获得权益不被重新处理。

原决定记录实销时只有未付款加购意向。平台沿用既有会员和积分核对入口，核对主单原付款、净退款与原账号周期，并检查加购扣款与付款凭证一致且不存在付款；若之后出现加购付款凭证或孤立扣款，主单保持待核对，不能把它默认为未付款或重复计入。默认本金真实转单使用同一保护，并保留逐段清单及加购独立实销的既有核验。实际已付款加购仍按自身付款、实销和授权决定独立处理。

参考 [Frapp 付款意向与实际付款对账](https://github.com/pdcarlson/Frapp/blob/main/spec/behavior/billing.md) 区分意向与真实付款；本项目付款、授权及退款规则以自身代码和 PRD 为准。

按开发期要求未运行测试或迁移，仅完成 Python 语法解析；实际待付款意向、原付款与退款流水、控制库故障、主单并发和转单实际入口须在隔离环境验证。来源单、无真实来源凭证和其他未接通的资金组合仍不在本项范围。
