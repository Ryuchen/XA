# 普通转单接替确认到账作用域

有共享到账、且转单版本之后已有真实加购退款时，三方接替决定入口需要回读该本单资金版本；到账核验此前把正在确认的 PENDING 接替视为无权读取，阻断真实确认。现在接替请求在事务内绑定本单及付款，决定入口同时传入方案编号；同一付款仍最多一个待确认接替，其他付款的待确认方案不因本次回读而改变。普通转单能力、真实到账来源及原用途事件仍须核对。

加购退款完成真实退款和受影响接替失效后，在同一事务内以退款 ID 绑定到账回读：退款付款及逐份额实际扣减的其他付款不能仍有待确认接替，未受影响付款的待确认方案保留原状。方案确认和退款后的资金版本更新、到账 RELEASE 与逐段结算继续使用原事务路径；其他未完成退款方案并行时仍保留限制。未运行测试或迁移，须最终联调共享到账、多付款/退款、三方重复确认、跨付款收益扣减、方案失效及整单补资后逐段结算。
