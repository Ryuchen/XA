# 普通逐段结算推荐佣金本金

主单推荐佣金按实际支付店币计算；未发放时随已退店币重算，加购不产生推荐佣金，已发放佣金不追回。普通逐段订单最终结算原本会给推荐人写钱包收益流水，但非积分、非普通转单资金版本下没有给老板推荐人登记可供后续支付辨认的本金资金批次。

现有最终结算事务在普通逐段路径给老板推荐人入账后，复用推荐佣金本金来源写入；重读已完成结算时核对关联流水及本金批次。推荐人为陪玩时继续只按其钱包收益处理；积分和普通转单版本沿用各自已有批次及回读规则。本次不改变佣金基数、发放时点、退款或资金补足门禁。

未运行测试或迁移。最终须在隔离环境联调普通逐段订单的老板和陪玩推荐人、退款前后结算、资金来源消费与退款、结算重试，以及与积分及转单路径的区别；其他已发佣金退款的未接通组合仍受原门禁限制。
