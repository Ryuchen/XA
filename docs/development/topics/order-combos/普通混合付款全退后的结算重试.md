# 普通混合付款全退后的结算重试

普通服务订单使用本金、赠送和赔付混合付款后，经双方确认协商并全额退回店币时，成熟任务现会发现已终止但尚未结算的订单。任务本身只筛选候选；实际处理仍在本店事务中核验原付款及退款来源、客服协商和终止、整单补资、每位陪玩的报单和实际收益，未足额不入账。零收益也按现有结算凭证处理，以便完成对应押金补差机会，不制造零金额收入流水。

已完成请求与已结算人员继续复用既有凭证和重试保护；该改动不扩大退款操作权限或尚未接通的转单、加购、追加售后范围。未运行测试、检查或迁移。最终联调须覆盖本金/赠送/赔付混合全退、分次到账补资、零和正额陪玩收益、双陪不同报单成熟时点、重复任务、双店隔离、并发与失败回滚。
