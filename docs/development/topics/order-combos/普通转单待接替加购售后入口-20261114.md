# 普通转单待接替加购售后入口

普通转单订单的加购存在待确认接替时，售后创建入口现在允许进入既有普通退款能力域，并按当前已生效而非待确认的加购份额核对所选陪玩。目标付款的待确认方案仍须通过本单接替/退款能力检查；申请本身不会变更接替、退款或释放资金，订单售后有效期等原限制保持不变。

后续退款方案沿原路径由老板及实际承担陪玩确认；执行时仅实际受影响的接替方案随真实退款失效，按原支付来源退款并写资金版本和到账 RELEASE。客服处理完成后仍须通过现有售后结案入口关闭该售后，才能解除本人结算阻断；随后可按当前真实剩余份额重提接替。结算和资金重算继续使用原有凭证及整单补资规则。

本次不扩展已结算人员承担、未支持积分时序或其他资金范围。未运行测试或迁移；最终联调需覆盖售后创建、跨付款及本付款承担、失效后重提与三方确认、正数及零 RELEASE、售后结案、逐段结算、重试与回滚。
