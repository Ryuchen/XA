# 普通退款后的会员券条款

普通退款事务在现有老板钱包锁之后、退款和会员券写入之前锁定本店会员配置。退款导致 VIP 降级时，即使可选条款保护开关尚未开启，也使用该次锁定的配置，将本周期有效未用月券和安全箱券当时生效的条款固化，再沿用原有降级和已发券锁定逻辑。退款不依赖新增权益 License，保留已有券及原资金处理。

此次只接 `orders/services.py` 的普通退款调用；协商退款、加购退款及其他独立入口仍按各自原有锁和开关处理，尚未声明覆盖。对无法确认归属或共用的专属券沿用既有异常和事务回滚；需在最终隔离库联调锁顺序、退款并发、规则变更及授权不可用。未运行测试或迁移。


协商与加购补充：常规协商、后续协商、普通订单加购后续协商、普通转单后续协商在原有钱包锁后获取本店会员配置，将实际锁定配置传给会员退款降级；加购独立退款执行在实际老板钱包锁后、原付款来源及积分回退前取得同一配置，再传入加购实销冲回。均仅在真实退款导致等级降低时固化已有券，不依赖增值授权。零退款分支和未调用这些写入的其他资金路径不以本记录宣称覆盖；仍需隔离库联调跨钱包、配置与券锁并发及失败回滚。
