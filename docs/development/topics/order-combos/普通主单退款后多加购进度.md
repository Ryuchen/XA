# 普通主单退款后多加购进度

普通无转单订单在一次主单退款后，可在受限范围内对两笔不同加购分别办理一次退款。两笔可归属于同一陪玩，也可分别归属于不同陪玩；每笔按本人原付款、同单其他加购和主单的未结收益，再到本人钱包和押金依次承担。不同陪玩时，未受主单退款影响的人须仍在履约，且不得已有人员结算。

该范围支持首次主单退款前后对多项付款办理多次退款，包括同一付款的多次退款；按每次真实剩余来源，依次使用本人未结加购收益、主单收益、钱包及押金。每笔客服操作、确认、逐段承担和资金版本均须可核验。到账本地回读按事件时点核验付款剩余来源、逐付款和履约段扣减、钱包及押金流水，并复核每个前驱资金版本及实际 RELEASE；零释放也保留版本，钱包零余额使用事务内事实而不生成零金额流水。同次回读复用已经核验的前驱，避免重复递归展开。已结算人员、转单及其他未闭合时序继续受限。

这些修改尚未运行测试或迁移，接口、并发、双店隔离和最终逐人结算须在最终联调中验证。
