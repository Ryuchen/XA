# 普通转单前加购资金事件回放

修复普通服务订单中，已付款加购或已确认的三方接替产生补资版本后再发生服务转单的回放：当转单前没有主单退款时，`ordinary_prestart_release.capture` 现在核对真实转单及分段资金链，并按原加购事件时间读取当时的履约段。不能使用转单后的当前席位重建原资金版本。

原资金版本由加购付款/接替事务写入，后续首次普通转单主单退款的到账用途回放会经 `addon_funding_release.verify_run` 使用该版本；本次修复这一调用链中因后来出现转单而误拒绝早前版本的问题。真实三方确认、原付款和补资账本仍按原有流程校验，未修改账务或重复写入释放流水。

本次未宣称所有转单、加购退款和多轮协商组合已开放；具体能力域、历史退款顺序、待确认接替以及补资版本仍遵循各自门禁。未运行测试或迁移；最终联调需覆盖转单前付款和三方接替、正数共享到账释放、首次主单退款和逐段结算，并检查跨门店、并发及重试。
