# 普通多付款售后绑定

同一服务订单有多笔加购售后时，退款方案创建未指定售后编号的入口现在优先选择本次付款对应的开放售后；不存在绑定售后时才考虑未指定付款的售后。同一优先级有多条候选时要求明确选择，不再默选可能属于另一付款的售后。显式指定售后、老板和受影响陪玩确认、原付款退款及门店隔离检查保持原规则。

此修复让不同付款的开放售后并存时可以到达既有逐段承担、退款、接替失效和补资 RELEASE 事务；售后结案后继续走原逐段结算。实际资金版本、受影响方案以及时限仍须满足各入口的既有规则，不能据此视为所有资金组合已开放。

未运行测试或迁移。最终联调需覆盖不同付款各有售后、同付款多售后明确选择、跨付款扣减和方案失效、重提三方确认、共享到账正数/零 RELEASE 及结案后的逐段结算。
