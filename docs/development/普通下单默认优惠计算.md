# 普通下单默认优惠计算

普通服务在未提交优惠组合令牌时，改用与预约相同的优惠组合计算：会员折扣与门店活动折扣只能选择一种；若请求指定金额券，可与所选比例折扣组合；折扣券单独使用。应付价格向上取整至整数店币。服务端在付款事务内重新读取门店、会员、活动和券的条款并核对报价，券使用后仍由原流程记录。

未指定券的默认路径不会自行消耗已有券；完整的全部合法组合推荐及老板主动切换仍走现有优惠组合报价令牌流程。体验套餐继续使用专价和资格券，不走普通优惠。微信网页直付仍不属于本期交付范围。

开启优惠组合付款时，老板优惠选项接口即使没有单独开启只读预览开关也可查询；响应中的 `payment_selection_enabled` 和 `preview_only` 与实际能否使用选择令牌付款保持一致。选项接口仍只做报价，正式付款在原事务中重新核验并使用优惠券。

订单资格校验和免费安全箱补贴基数使用同一份当前有效的会员券条款：规则调整后未锁定条款的券按现行规则判断，因降级等原因锁定的券仍使用原条款；付款时继续锁券并保存本次实际使用的条款。报价阶段不把旧券面直接当作现行安全箱补贴依据。

本轮未运行测试或迁移。最终联调须覆盖老板自助、客服代单、预约转单、会员与活动互斥、金额券和折扣券、积分、会员券条款变化、体验套餐及双店并发。
