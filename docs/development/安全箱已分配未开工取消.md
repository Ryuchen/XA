# 安全箱已分配未开工取消

老板请求客服协调取消已分配、尚未开始服务的免费安全箱订单时，仍由具备 `order:refund` 权限的后台人员使用既有退款入口并填写原因；不改变普通订单的老板自助取消权限。零实付安全箱不经正金额退款解析：锁定订单及资金互斥后，须核验原零付款、原老板周期已用安全箱券、平台补贴、未开始的履约分段及本人抽成快照，且补贴份额没有支付或资金流水。可证明时复用零额取消和原券返还，在同一事务把未支付补贴份额置零、保存原份额与退券来源、取消订单并刷新陪玩占用；没有钱包退款流水。预约转单仍保留原预约记录，其占档依订单取消状态释放。

原券返回原业务周期，实际是否可再次使用仍取决于券有效期及适用规则；已有 License 到期不阻止返还。已开始服务、已支付补贴、来源或分段不完整、现有分段验证器不支持的改派/转单，继续按既有售后规则或待核对处理。本次未新增老板对已接单订单的自助取消入口，也未修改加购资金。原价分段记录仍按退款路径标记待核对，不表示平台补贴已支出。

未运行测试或迁移。最终需在隔离环境联调老板请求与客服权限、同请求重试、普通及已转换预约的占档释放、资格与补贴快照、用户开始服务并发、券过期、失败回滚及通知。当前通知沿用事务提交后现有消息发送方式，消息投递失败仍需现有通知机制处理。
