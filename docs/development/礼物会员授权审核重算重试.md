# 礼物会员授权审核后的重算重试

礼物付款时会员成长授权未知，经平台审核确认 ALLOW 并写入原周期会员实销后，会员等级重算可能因门店授权或配置暂不可用而保持待处理。原平台审核入口现支持使用同一请求编号、结论和原因重试待处理重算；不会重新创建实销确认或改写原审核记录。不同请求仍按原规则拒绝。

重试锁定原订单并重新核对原付款、全部实际退款和资金来源，再核对原实销确认的账号、周期、金额、确认时点、当前累计退款和全额退款冲销状态；随后按钱包、账号的既有顺序加锁，只有当前仍为原老板周期才调用既有会员等级重算。重算使用当前有效实销和退款，沿用现有等级权益发放幂等及当前 License 门禁；门禁未放行时继续保留待处理。已全额退款的实销确认保持冲销，不补发其成长。资料不足或账号已进入其他周期时由人工继续核对，不向新周期发放旧权益。已有后台定时重算机制保留。

本次未修改付款、退款、原授权判断或已发权益，也未扩展其他订单类型的审核范围。未运行测试或迁移；最终仍需在隔离环境联调审核后多次退款、全额退款、退店重入、授权恢复、重复请求和并发锁顺序，以及后台定时任务与人工重试交错。
