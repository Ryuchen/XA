# 会员授权重算任务的周期隔离

加购、服务退款和礼物的会员授权审核可能已确认 ALLOW，但会员等级重算因授权或配置不可用而待处理。后台任务取得原老板钱包和账号锁后，仅当该老板的旧业务周期存在对应退店审计，才关闭旧周期待重算标记；不补发旧周期权益。钱包缺失、账号类型异常、旧周期缺少退店审计或记录周期晚于当前周期时保留待处理，不推断退店事实。

只有存在属于当前业务周期的待处理审核，后台任务才触发当前周期的既有会员重算。旧周期待处理记录单独存在时，不触发新周期重算或权益发放；当前周期的重算仍按已有实销、退款净额、授权门禁和权益幂等规则执行。本次不改审核结论、付款退款记录或已发权益，也不新增退款凭证核验能力；证据不完整的分支仍需人工核对。

本次未运行测试或迁移。最终需在隔离环境联调退店与重入并发、缺失退店审计、未来周期异常、当前和旧周期同时待处理、多次退款，以及后台任务和平台审核重试交错的锁顺序与幂等。
