# 普通转单并存独立加购售后

普通退款后转单订单中，不同加购付款的退款方案可以与其他付款的接替或实际退款并存：当前付款和实际改变收益涉及的付款、陪玩均与未完成退款方案独立时，接替创建/确认及实际退款的资金版本和共享到账 RELEASE 可以继续；其他付款的方案保持原状态。到账读取仍绑定本单实际接替或已执行退款，沿原订单、资金、到账锁与原资金版本校验。

普通转单加购退款方案新增逐付款、逐履约段的预计收益承担快照；双方确认和实际退款前重算对比，执行时还核对实际逐项扣减与快照一致。其他付款的已确认方案在真实接替或退款改变责任后，若其付款来源、本人份额或逐付款承担计划发生变化，在同一事务标记失效并记录触发事件；核对仍一致的方案保留。没有此类可核验快照的受影响方案仍须先处理，同一付款未完成退款仍不允许接替。保留原整单补资、本人报单与逐段结算门槛。

未运行测试或迁移。最终联调需覆盖多个付款的退款方案与接替并存、实际跨付款收益扣减、方案失效重提、共享到账 RELEASE、重复请求和最终逐段结算。
