# 开业前订单流量配置

已初始化但尚未营业的门店首位管理员可通过 `GET/PUT /api/admin/order-traffic/` 读取和保存本店峰谷时段、自主下单开关及下单、抢单、订单池刷新、报价的三套配额。原接口继续要求 `order:view` 或 `order:traffic`，保存时校验完整配置、时段不重叠和 revision，提交后使本店缓存失效；实际流量限制读取同一配置，并受现有全局运行开关控制。

此变更仅放开后台配置，不开放老板下单、抢单或其他客户业务，不新增开业必填条件。未运行测试、迁移或建库；最终须联调角色权限、双店缓存隔离、并发版本冲突、缓存故障与开业后实际限流。
