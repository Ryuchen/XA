# 积分转单追加退款的已付加购回放

积分订单已有实际服务转单、加购及首次主单退款后，如一名未受后续退款影响的陪玩已经结算本人主单及加购收益，原追加退款计算已核对这些收入和付款快照，但共享到账回放此前无条件拒绝含加购的已结算快照，阻断后续退款后的补资和逐段结算。

现允许该快照进入已有真实凭证核验：核对本人履约段、报单及等待期、主单收入和押金流水，逐笔核对已付加购的付款、报单及实际收入流水，并验证追加退款未更改已结算加购份额。后续资金按原退款及 RELEASE、到账用途和分段结算版本回放；缺失或不一致仍待核对。该修改不创建付款、退款或结算流水。

适用范围仍受既有转单、接替、退款时序和已结算人员证据门禁约束；不据此开放全部加购接替或已付收益后的退款组合，也没有新增加购负责人变更次数上限。主单每席最多转单两次的既有规则不变。

未运行测试或迁移，正式开关保持原值。最终须在隔离 MySQL 联调首次主单退款后的接替、再次转单、加购部分退款、已付与未付人员、真实及空 RELEASE、共享到账、补资不足与补足、重复请求、锁顺序和回滚。
