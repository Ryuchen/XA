# 首轮封存到留池的真实收件

首轮候选水位已封存而仲裁尚未推进时，订单仍在总等待期内的单陪抢单、双陪邀请／确认／退出及老板取消，现在按留池总期限保存真实收件，不改已封存的首轮摘要。仲裁先处理有效老板取消和首轮候选；首轮确无候选而已有待核实或有效留池候选时，先进入留池并立即继续仲裁，不会仅因任务延迟到总期限后就丢弃期限内的真实候选。队伍须双方真实确认，时间无法核实时仍待核对。

首轮已完整的双陪队伍在封存后、实际分配前退出，保留原队伍及退出事实并纳入首轮历史排序；若原排序第一已退出，则按首名失格重开或到期退款，不直接递补。未完成的邀请退出不构造首轮候选。生命周期锁包括这些真实历史候选，分配、退款、通知和逐店扫描复用原事务与任务。

不同候选提交观察区间重叠、无法证明具体先后或真实完全同分的情况仍待核对，不能据编号猜测。相关正式时钟和抢单开关保持原默认值；无新增迁移，未运行测试或迁移。最终须隔离 MySQL／Celery 联调水位封存并发、双陪退出、老板取消、总期限和原路退款。
