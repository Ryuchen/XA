# 成就实销授权与已获权益

普通服务主单、退款后积分服务、转单退款服务和独立加购的实销确认入口，分别保存成就功能在真实确认时的 License 决定、当前业务周期和实销统计快照。独立判定 `ACHIEVEMENTS_RANKINGS`；VIP 配置或 VIP 成长授权不改变普通服务实销统计。只有原事件判定 ALLOW 时按当时可达成的成就配置持久化解锁；DENY 不发放，UNKNOWN 保存来源、授权证据、统计及候选快照，不能用恢复后的当前授权自动回填。用户确认老板已解锁的消费成就不因退款后有效实销低于门槛而取消，成就馆和会员标签均按本周期已解锁记录展示；消费统计仍按实际退款冲减。授权到期或降档不抹除已获权益。

成就授权快照和已解锁记录与对应实销确认处于同一门店事务；写入失败时回滚本次实销确认，如结算也在同一事务内会一并回滚，不再只记日志后丢失成就；此前已提交的付款和资金流水不会被撤销。原授权判断为 UNKNOWN 时仍保存事件，平台核对入口及其适用范围见《成就授权未知平台核对》。本次没有执行迁移或测试，最终联调须覆盖实销重试、写入失败回滚、加购及退款后成就保持、授权未知和门店隔离。

本次未运行测试。最终需在隔离环境联调所有实销入口、授权到期和宽限时点、VIP 停用、加购与退款并发、账号退店重入、控制库与门店库故障、重复实销事件、迁移后首次部署和钱包/账号锁顺序。
