# 正式抢单池截止与可见性

正式 MySQL 抢单轮次的总等待时限以真实激活提交证据计算。陪玩池列表不再仅凭付款／开池事务内的暂定 `auto_cancel_at` 过早隐藏订单；暂定时间已到时，只有最新轮次的真实截止上界可核验且尚未确定到期，才继续展示。接单仍由原收件、资格与仲裁事务决定，不因列表展示而延长时限。

订单序列化的 `pending_deadline_expired` 对正式抢单返回 `true`（确定到期）、`false`（确定未到期）或 `null`（截止证据或边界不确定）；单陪抢单操作只在确定未到期时开放，前端应按未知状态处理 `null`。非抢单及非正式时钟路径保留原行为。正式时钟和抢单相关开关不变，未新增迁移；未运行测试或迁移，须隔离联调慢激活、重开、边界竞争、双陪和多店。
