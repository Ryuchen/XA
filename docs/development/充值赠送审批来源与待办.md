# 充值赠送审批来源与待办

充值赠送例外仍由本店具备 `recharge:gift_approve` 权限的后台人员处理：本金先到账，审批通过按申请金额发放，驳回按该次充值保存的标准档位金额发放。审批前核对原充值本金流水、钱包归属、档位组合和标准赠送快照，并在钱包及老板账号锁内确认仍属于充值时的业务周期；来源缺失、钱包归属冲突或周期已变化时保留待核对，不向新周期发放。标准赠送不按当前档位重算。

同一审批人以相同结论及原因重试时，返回前核对实际赠送金额、到账流水和赠送资金批次；零赠送不创建赠送流水。与已处理结果不同的重试继续拒绝，避免重复入账。后台充值记录可通过 `gift_approval_status=PENDING|APPROVED|REJECTED` 筛选相应审批，沿用本店后台角色权限及门店隔离。

审批结果为零赠送时，接口明确返回“本次无赠送金额”，不提示赠送已到账；有实际赠送时才提示入账。该响应不改变审批和资金处理。
