# 普通订单完成通知恢复

普通单陪完成服务及双陪所需结单凭证齐全后完成服务时，状态机按入口显式要求，在真实 IN_SERVICE → COMPLETED 状态日志的同一事务中保存老板通知意图。开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 和默认关闭的 `ORDER_COMPLETION_NOTICE_RECOVERY_ENABLED` 后，提交后独立投递，消息创建失败由本店任务重试；每条完成状态日志最多创建一条通知。

投递核对原完成状态日志、订单当前完成状态、原订单老板账号及业务周期；订单状态变化、来源不明、退店或重入时记录跳过。老板周期保护开启但恢复开关关闭时仍使用原周期即时发送；生命周期集成关闭时沿用原路径。消息失败不回滚服务完成或资金事实，创建站内消息不代表客户端已收到实时刷新。

此链仅替代原单陪和双陪完成入口的老板通知；房间结单及协商终止沿用各自路径，入队截图齐全和房间结单凭证提交本身不冒充订单完成。启用前须各店应用 `site_messages/0027_ordercompletionnotice` 及依赖并运行逐店 worker/beat。最终联调覆盖单双陪、转单和积分订单适用链、失败回滚、消息插入故障、重复和并发恢复、完成后退款竞争、账号退店重入及双店同号；正式注销保持关闭。本轮未运行检查、测试或迁移。
