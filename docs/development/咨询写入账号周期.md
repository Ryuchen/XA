# 咨询写入账号周期

启用账号生命周期集成时，老板或陪玩发送咨询、标记已读前，在既有事务取得本店账号锁后，重新核对请求中的账号类型、业务周期、在店状态及登录状态。账号在认证后发生退店、注销或重新入驻时，旧请求返回 409，不向新周期写消息或修改已读状态；会话及历史消息仍保留。

会话创建、历史读取、未读数、本人发送结果查询以及陪玩本人履约详情也在读取事务中持有并核对该账号锁，避免查询期间账号进入新周期。客服端查询、私有图片和实时消息仍按各自授权流程核验；本次不表示所有入口都已完成周期并发联调。生命周期集成关闭时保持原有授权规则。

本轮未运行测试或迁移。最终联调须覆盖老板退店重入、陪玩注销重入、发送、已读及查询与账号状态变化并发、消息重试和双店隔离。
