# 普通转单同付款退款与接替并存

普通退款后转单订单中，同一付款已有未完成加购退款时，可继续创建和确认接替，但退款方案须带有已确认的普通逐付款、逐履约段收益承担快照，且原支付来源、参与人份额和承担计划在操作时仍一致。老板、原负责人和接替人仍分别确认；未确认或拒绝的接替不产生资金版本。

接替最终确认后，同一订单资金事务立即重算未完成退款方案；实际责任或来源变化的方案标记失效并记载触发接替，未变化的保留。接替资金版本与共享到账 RELEASE 在原事务写入。若退款先执行，原退款事务按实际逐份额扣减失效受影响接替并记载来源，再写资金版本和 RELEASE；无关方案保留。未结售后仍阻止对应陪玩提前结算，重新提案使用当时真实份额。

只覆盖普通转单能力域和带真实承担快照的方案；缺少快照、来源或受影响范围无法核验时继续要求先处理。未运行测试或迁移，须最终联调同付款两种先后顺序、各方确认、失效重提、正数及零 RELEASE、退款原路来源、跨付款承担、整单补资及逐段结算。
