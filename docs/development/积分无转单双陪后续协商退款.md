# 无转单双陪的后续积分协商退款

现有实际流程为：首次主单部分退款终止受影响陪玩的履约，另一陪玩继续服务；本店客服为后者登记独立售后并预览方案，老板与该陪玩确认后，由具备退款权限的客服执行。原付款的积分及钱包构成、陪玩待结收益／钱包／押金承担、资金版本、实际 RELEASE、售后结案和审计在既有订单事务内核对和写入。整单补资足额后，使用退款后逐人结算入口按报单、售后时限及资金凭证分别结算。

本次修复真实共享到账回放：首次主单退款与第二次退款之间可发生平台已核验的新补资，第二次退款的分配快照须匹配当时真实分配，并分别核对首次退款前已有分配与后来分配的实际时间和 RELEASE。首次退款时尚无分配时，以同单真实后来分配作为历史零释放核对的到账见证，不增加或伪造原退款释放。该核验被既有退款执行、到账用途登记和后续资金／结算读取调用。

范围限于已确认的无转单双陪、第一人部分退款后另一人继续服务并就本人范围再次协商的路径；仍依赖现有功能开关、角色权限、真实付款和平台到账凭证。未运行测试或迁移；需在隔离 MySQL 联调先无补资后补资、两次退款之间补资、存在和不存在实际 RELEASE、共享到账竞争、双方确认、补资不足后补足、逐人结算、重试及失败回滚。不能将代码接线视为资金验收通过。
