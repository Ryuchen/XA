# 双陪预约重选通知恢复

老板在双陪预约的拒绝或超时空席重新邀请陪玩后，真实邀请事件同事务记录另一在席陪玩的原业务周期、席位和空席来源。提交后向另一在席陪玩发送重选结果；失败按门店恢复，按邀请事件幂等。新受邀人的预约邀请使用既有链路。

恢复时核验预约仍待处理、老板发起、原空席事件和当前邀请、受邀人仍等待确认且未超时，以及收件席位和原账号周期均未变化；已确认、再次变更、预约结束或账号周期变化时跳过。通知只说明已重新邀请、正在等待对方确认，不称为已接单、付款或成单。

`RESERVATION_TEAM_REPLACED_NOTICE_RECOVERY_ENABLED` 默认关闭，依赖 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED`，关闭期间事件不会补发。上线前需执行 `site_messages/0039_reservationteamreplacednotice` 结构迁移并隔离联调重选、确认、再次拒绝、超时、账号周期变化与失败恢复。本轮未运行测试或迁移。
