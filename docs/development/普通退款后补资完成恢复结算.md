# 普通退款后补资完成恢复结算

平台财务将实际到账分配给普通混合付款订单后，只有本店分配流水与平台操作确认均已提交，才向对应门店发送该订单的成熟处理任务。恢复操作和原请求重试也可再次触发；任务复用现有订单锁、真实资金来源和补资核验，不直接创建收益流水。任务投递失败时，既有逐店定时扫描继续重试。

对一次协商退款的双陪订单，处理时仍须整单完成、整单补资足额，并分别满足受影响陪玩从协商确认起算的等待期、另一陪玩的适用等待期和各自报单冻结与审核；已结算人按原凭证校验，不重复入账。其他尚未接通的退款、加购、转单和权益组合保持原有范围。该触发也复用同一平台补资入口支持的其他订单自身门禁。

本次未运行检查、测试或迁移。最终联调须覆盖两次跨库提交及失败恢复、原请求重放、任务重复和投递失败、不同门店同号订单、未完成或补资不足不结算、双陪时钟分离及资金守恒。
