# 积分双陪加购接替后的补资

积分双陪订单的同单加购接替已由原流程保存实际付款、三方确认和资金版本。平台财务分配真实到账时使用本店订单的 `funding` 作用域；此前已完成接替的历史只接受付款、退款、报单或结算阶段，导致正常补资入口被拒绝。

现将补资阶段接入已有接替历史核验，包括主单已有退款的受控路径。原入口仍核对付款、接替、退款、逐项资金版本及到账释放，按既有平台权限和跨库幂等记录分配；仅补足真实资金缺口，收益仍须满足报单、等待期和整单资金要求才结算。本次不改变加购接替、售后确认或资金计算规则。

业务范围仍受现有同单、实际履约和历史时序门禁限制；服务中转单、已结算后退款等其他组合不因本次开放。正式积分功能开关保持原值。未运行测试或迁移；须最终联调有／无原到账、主单退款前后接替及加购退款、分次补资、双陪报单等待、跨库恢复、重复请求、并发及资金守恒。
