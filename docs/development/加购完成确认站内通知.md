# 加购完成确认站内通知

客服创建真实加购完成确认请求时，在同一门店事务为老板和受影响陪玩各自保存通知意图及原业务周期。提交后尝试投递，失败保持 PENDING；逐店恢复由 `ADDON_COMPLETION_NOTICE_RECOVERY_ENABLED` 控制，默认关闭。确认请求已处理或作废、本人已处理、原账号周期变化或对应责任已变时不发过时提示；责任仍在待处理接替或退款中时保留待重试。缺可信周期或请求事实转 REVIEW。

确认或作废状态变化时，已生成的站内提示会原位更新，不重复创建消息；消息只提示查看订单，不表示外部短信或微信已发送。首次部署依赖 `site_messages/0046_addoncompletionnotice`（依赖 0045 及原订单结构）。本轮未执行测试或迁移，须在隔离环境联调双店、双方分时确认、失败恢复、请求更新、加购结算及退店重入；现有 WebSocket 刷新为尽力推送，站内记录已保存不代表实时信号送达。
