# 老板退店与部分退款订单结清

老板退店预览及实际确认都会检查已完成但收益尚未结清的服务订单。部分退款订单如果仍有尚未结算的收益，也会提示先结清；不能因为付款状态从已付款变成部分退款，就清空本店会员权益并结束原业务周期。

全额退款后，如果已有协商终止凭证且订单仍需结算陪玩收益，退店也会等待结算；零实付安全箱协商终止的待结补贴按同样原则处理。普通已取消退款且没有这类待结算事实的订单不因此被一概阻断。

未运行测试或迁移，最终需在隔离环境联调部分及全额退款后的逐人结算、退店与结算并发、钱包及权益留痕。

参考 [django-oscar-accounts 的账户关闭实现](https://github.com/django-oscar/django-oscar-accounts/blob/master/src/oscar_accounts/abstract_models.py)：关闭前检查账户余额；本项目还需按既有业务规则核对订单收益是否结清，不能仅凭钱包余额判断。
