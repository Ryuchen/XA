# 预约免费安全箱补贴接入

老板将已确认的单陪预约转为服务订单并使用符合条件的免费安全箱券时，预约付款事务复用普通下单的有效券条款与补贴基数判定，记录券及平台补贴基数，再建立陪玩的补贴份额和分段抽成快照。老板实付仍为零；报单、售后和补贴释放沿用既有安全箱路径。优惠或券锁定校验、预约转单、补贴及订单写入同属一个事务。

所有单陪预约转单统一建立陪玩参与份额，包含普通百分比抽成，供分段归属、个人业务周期与后续结算使用；此前只在部分抽成或积分路径建立份额。

现有安全箱券适用范围限制为符合配置的单陪服务；双陪不在此券范围。对已选定陪玩的三角洲本人档位抽成，普通下单及预约转单可识别有效免费安全箱券，锁券后重新核对补贴基数，并以陪玩本人档位快照计算补贴；其他零实付个人抽成和未选陪玩的待分配路径仍保留原门禁。该接入仍受 `VIP_SAFE_BOX_SUBSIDY_ENABLED` 等既有功能开关与结算条件约束，不代表整条业务已验收。

按当前开发安排未运行测试或数据库迁移。最终应在隔离环境联调有效和失效券、预约付款与截止并发、零实付付款记录、补贴份额、报单结算及协商终止，并核对各功能开关组合。
