# 普通双陪后续协商的经营成本

经营 ROI 对没有转单、积分、平台补贴和已付款加购的普通双陪服务，在存在真实 `NegotiationFollowupLink` 时，复用两次协商、双方确认、实际退款及售后结案凭证。两次可以分别为正退款或零退款，但至少一笔须有实际退款；没有付款的加购申请不会被当成消费或成本。

另接入一类普通双陪订单：有一笔或多笔已付款加购，每笔可以有零笔或多笔实际退款；主单依次发生两次不同陪玩参与的协商，其中第一次为正退款、第二次可以为正退款或零退款。全部加购及其退款须包含在第一次退款后的结算证据中。计算前核对双方协商、原付款和退款来源、每笔加购付款和退款、跨加购的收益扣减、两个陪玩各自的主单与加购收益及门店补资凭证；整单完成结算时还须核对最终结算流水，核对不齐时保持待核对。

整单补资足额后，若恰好一位陪玩的主单及所属加购收益已经结算，另一位仍在等待，可凭个人报单、入账流水、待结算份额和整单资金凭证计算期间应计成本。`operating.partly_settled_provider_evidence` 额外列示已核实订单：本次查询期间按实际钱包入账时间统计的已入账收益，以及查询时点待结算的主单和加购金额。后者是即时状态，不代表查询期间末的历史余额；列表不是全店全部待结算负债。`provider_cost_fen` 仍是按付款和退款期间确认的应计成本，不等同于本期已入账或实际打款。

每笔加购还允许一次已生效的同单双陪换人：换人须在第一次主单协商退款前完成，换人前该加购不得已经退款或被其他加购退款扣减收益。系统以原付款抽成快照、接替人的主单抽成快照、老板及两位陪玩的确认、客服审计、换人后的逐段收益及真实结算凭证共同核对。换人带来的原预计收益差额按换人确认所在期调整一次，之后的退款仍逐笔按实际退款期冲减，避免重复计算。整单补资不足、两位均未结算或其他未完整核实的结算状态、每笔加购超过一次换人、首次协商退款后的换人、换人前该加购已有退款或收益扣减、结算快照之后新增加购或退款，以及其他不在以上范围的组合仍保持待核对。

加购本身的实付收入和原收益归其实际付款期，加购退回店币、陪玩承担金额及赠送／赔付来源冲回归实际退款期；主单继续各自按付款与退款发生期归属。推荐佣金仅按主单净实付及其原比例计算，不以加购金额重复计提。对已结算的该类订单，报表使用现有收退款流水及结算事实，不触发任何实际资金操作。

主单实付、原陪玩成本和原推荐佣金归付款期；每笔退款按其发生期分别冲减实际陪玩承担和原来源中的赠送／赔付。推荐佣金在发放之前按主单净实付逐笔调整，已经发放后不追回；如果佣金流水和退款发生时刻无法区分，结果保持待核对。只要付款、退款、来源、佣金或协商凭证无法互相核实，经营利润和 ROI 均不以零代替未知金额。

本次按要求没有运行测试、检查或迁移，也尚未与真实业务数据联调。正式验收需覆盖两笔正退款、先零后正、先正后零、跨月退款、佣金在两笔退款之间发放、已发佣金不追回、赠送及赔付来源退回、多笔加购及跨加购收益扣减、多次退款的取整与跨月、换人前后不同抽成及跨月成本差额、三方确认和逐段收益缺失、双陪分别先结算和另一人等待、查询期间与实际入账期间不同、加购退款后收益流水、资金凭证缺失、双店隔离和结算／退款竞争。若退款记录与实际客户退款流水落在查询期间不同侧，报表保持待核对。本次不改变实际订单退款、收益结算或授权开关。
