# 咨询转交站内提醒

已编写本店咨询转交的站内消息恢复模块：真实转交事件保存目标后台员工及其业务周期，通知不含咨询正文。发送时核对事件版本、当前接待人、员工账号周期和 `chat:view`／`chat:reply` 权限，消息与事件结果同事务保存；转交被撤回、再次转交、人员离职或权限变化时不发送过期提醒，来源周期缺失保留待核对。频道通知只说明站内消息发生变化，不代表客户端已读。

已在客服转交及主管重分配的实际事务中保存该意图，提交后尝试发送，失败由逐店任务恢复；同一转交事件最多产生一条站内消息，不因提醒改变会话接待人。普通领取和交还继续使用原有工作台刷新。

本模块受 `CHAT_NOTIFICATION_OUTBOX_ENABLED` 控制，默认关闭；启用前须应用 `chat/0014` 及依赖并运行逐店 `chat.tasks.drain_chat_notifications`。未运行测试或迁移；需隔离联调客服转交、主管分配、撤权、再次转交、消息失败恢复、重入、两店同号和重复投递。
