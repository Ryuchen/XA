# 开业前已有老板时配置预存和基础积分

平台首次开业初始化此前对全部会员配置统一要求门店没有老板账号。如果门店已先创建老板，仍处于开业前配置状态时，平台无法保存预存档位、普通会员基础积分倍率和生日倍率。

现允许该状态下使用原初始化接口保存预存档位及基础倍率，继续使用本店数据库、原配置版本、并发锁和平台／门店审计。预存仍由充值试算读取本店启用档位；基础积分和生日倍率供付款时快照读取，不改已有付款事实或余额。

已有老板时，平台初始化入口的老板分级、VIP 等级及开关操作仍保留限制：后续须接通会员重算、既有权益和在途业务处理，不能把当前限制当作最终产品规则。本次未运行测试或迁移；最终须在隔离环境联调先建老板再保存配置、两店不同档位及倍率、支付快照、配置并发和会员变更。
