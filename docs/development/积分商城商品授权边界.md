# 积分商城商品授权边界

门店后台新增并立即上架积分商品，或调整／重新上架当前在售商品时，使用已有 `POINTS_SHOP` License 能力校验。授权明确不支持时拒绝，控制库及可信缓存均无法核验时返回授权暂不可用。未上架的商品草稿可以继续配置；已经在售的商品允许单独下架或停用，但不能通过同一请求附带修改商品条款绕过授权。

本次只限制商城商品配置，不改变积分余额、已经获得的兑换权益、进行中的交付、取消时的积分原路返还，也不改积分在服务订单中的使用。共享给抽奖或其他权益但不在积分商城上架的奖品按各自原有规则管理。授权档位、宽限期和缓存判断复用现有策略，不新增开关或数据库结构。

最终联调需要覆盖有效／宽限／过期／降档及控制库不可用时的可信缓存、草稿保存、上架与下架，以及到期前已有兑换在到期后的交付和取消返还。并发下授权改变与商品修改的边界也需在隔离环境验证。本轮未运行测试或迁移。
