# License 旧码重发校验

平台超级管理员通过 `POST /api/admin/platform/licenses/{code_id}/reissue` 重发已作废码时，在控制库事务中锁定门店并重新检查当前授权：首次授权要求尚无当前授权；调档要求当前授权仍存在且到期时间相同；续期要求当前授权仍存在、档位相同且新到期时间晚于当前到期时间。已有待激活或待生效安排时仍拒绝重发。条件不满足返回 400，不创建新码、不改变当前授权、合同或收款。符合条件的重发继续沿用原合同和收款记录，已获得权益不受影响。

该校验与当前签发规则一致，使用当前有效授权而非旧码作废时的历史状态；未来授权已激活后被取消的情况仍遵循原作废与重发流程。参考 [Dodo Payments License Keys](https://github.com/dodopayments/skills/blob/main/dodo-payments/license-keys/SKILL.md) 区分激活与撤销；本项目的门店绑定、条款与合同规则来自自身 PRD，不照搬其设备激活模型。

按开发期约束未运行测试或数据库迁移，仅完成 Python 语法解析；需要后续在隔离控制库验证条款变化、并发重发、合同与收款保持、门店权限以及已有权益。此变更不代表 License 其他业务入口或整条授权链路已完成。
