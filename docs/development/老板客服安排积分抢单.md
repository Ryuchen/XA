# 老板选择客服安排的积分抢单

老板本人选择客服安排、没有指定陪玩，且订单符合既有待分配本人抽成积分范围时，单陪和双陪可获取正式积分报价并以该报价完成付款。报价签名绑定派单路线、派单方式、陪玩人数、抽成快照及原有付款事实；付款时按当前数据重新核验。客服安排仍不得携带指定陪玩，付款后沿用同事务的积分与店币付款凭证、提交后开池意向和自动抢单，不走客服直接指派。

无人接单超时或老板取消沿用原积分订单取消流程，核对真实原付款后按原构成退积分、店币和适用券；派单与退款仍受现有订单、门店、资格、配置和资金证据约束。积分抵扣比例低于 100%，不能纯积分零实付。

本次仅接入既有待分配本人抽成的正式积分范围，不扩大其他抽成或资金门禁。未运行测试或迁移；最终须在隔离 MySQL 联调老板 STAFF 单陪／双陪报价与付款、入池时钟、报名排序、超时退款、重试及其他门店隔离。
