# 平台新店运营字典配置

平台超级管理员可在门店首次开业配置期间使用现有目录接口，读取 `GET /api/admin/platform/store-management/<门店ID>/setup/catalog/dictionary`，并以返回的 `version` 调用 `PUT` 创建或编辑本店运营字典。`configuration` 复用门店字典字段和校验，支持薪资岗位、投流渠道和运营成本类别；字段、唯一编码、不可改编码及平台财务岗位限制均沿用原规则。响应返回保存项及新版本。

平台操作继续使用独立平台授权、本店数据库上下文和双库操作审计，不写薪资、投流或成本流水，也不要求开业必须配置这些可后补项。本店原字典写操作与平台目录共用本店目录锁；并发修改会使旧版本失效。权限仍分别由平台授权及本店字典权限控制。

未执行测试或迁移。最终需联调新店空库、平台及门店角色权限、并发版本冲突、重复编码、本店隔离、下游薪资/成本选项和双库审计失败。
