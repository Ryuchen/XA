# 退款后加购实销联调

积分主单退款后的正式单陪／双陪及受控转单结算，在主单退款、资金与结算凭据核验通过后，继续按现有加购结算能力确认每笔已付款加购。加购沿用独立付款时 VIP、积分倍率与本金来源快照，并按实际加购退款后的净实付、净本金及确认时授权决定会员成长和消费积分；成就由既有确认实销查询按本店业务周期汇总，主单与加购不重复计算订单数。全额退回的加购净额和可获积分均为零，不产生消费权益。

定时任务补充扫描已结算但仍有未确认付款加购的订单，即使主单已确认实销或已全退也可重试；实际处理仍受各自退款结算能力、售后、资金及加购结算凭据限制，不意味着所有组合已开放。主单确认无有效事实、账号周期不符或能力不满足时不能凭待处理加购单独放行。

本次未运行测试或迁移。最终联调须覆盖本店双陪、积分转单、主单全退但加购保留、加购全退、主单与加购分别退款、VIP／积分和 License 开关变化、重试幂等、失败回滚和 MySQL 并发，以及双店同号隔离；实际受限资金组合仍以各自入口门禁为准。

积分转单主单退款后的会员确认补充：已核验最终逐段资金清单中的加购净店币和净本金须与各笔加购的真实付款、退款与本金来源一致；从整单资金净额中分离加购后再核对主单的实退店币与本金。返还积分不作为店币退款，加购权益仍按独立付款快照及自身 License／VIP 判断确认；最终联调须覆盖加购部分／全退及主单与加购退款的交叉组合。

双陪积分转单的已付一人、另一人后续独立退款，在实际付款、两次退款及最终逐段资金清单核验通过后，会员实销按主单净店币、消费积分按剩余本金及付款时倍率确认，已返还积分不再从店币扣减。全额退款且已结算但尚无实销决定的订单也进入定时处理候选；处理仍须满足原积分能力、售后和 License 决策，零净额不产生会员成长或消费积分。该范围及其底层资金代码未经测试和 MySQL 联调；加购、多次后续退款及第二人已先结算等仍以实际资金门禁为准。

第二次退款扩展到该陪玩待收益不足时，须验证本人待收益、钱包扣款及押金缺口之和等于实际承担，钱包和押金回收不另行抵扣老板实销；会员成长仍仅减实际退回店币，消费积分仍按实际退回本金冲减。
