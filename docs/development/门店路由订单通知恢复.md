# 门店路由与订单分配通知恢复

订单分配通知的恢复任务已在定时计划中注册，现同时加入门店任务的逐店调度清单。定时任务按有效门店分别入队，在各门店独立数据库内恢复待发送通知；控制库暂不可用时，沿用已签名且身份可核验的门店路由快照，不能把任务回落到默认门店。具体通知仍受原有开关和消息权限约束，单店处理失败不会把消息写入其他门店。

本次未运行测试或迁移。最终须在隔离环境联调多个门店、控制库故障与恢复、单店数据库不可用和重复投递，核对通知幂等及任务重试。没有可信路由快照的门店不能由本任务推断身份。

已对照当前生产 `CELERY_BEAT_SCHEDULE` 中全部静态及追加注册的任务：其余门店业务任务均已在逐店清单中；License 通知扫描和提现审计分发是平台全局任务，使用独立任务基类及自身的跨店处理，不加入门店扇出。以后新增定时任务仍须按实际作用域登记。
