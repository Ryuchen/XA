# 试音邀请与账号认证

客服创建的独立试音活动与老板服务订单的招募试音是两类业务。独立邀请的分享链接只用于读取活动信息和核对邀请；`exchange` 不再凭链接签发登录令牌，老板或陪玩须先通过本店统一登录，再与绑定的对应账号核对。老板邀请提示不限定微信登录方式。陪玩报名要求已登录；链接绑定了陪玩时只能由该陪玩报名，未绑定的公开活动仍允许合资格陪玩报名。最终报名事务锁定链接并重新核对有效期、启停和绑定，避免并发撤销或改绑时接受过期邀请。

首版空库迁移 `audition/0006_account_signup` 允许没有旧用户映射的本店业务账号报名，并以活动和业务账号唯一约束防止重复报名；保留已有的账号来源周期和审核通知机制。不能将旧邀请地址视为认证方式，调用方需先完成账号密码及短信／OTP 或已绑定微信登录，前端由其他开发接入本接口结果。

代码及迁移未执行测试或应用。最终联调须覆盖双门店同号、未登录与已登录身份、绑定／未绑定活动、活动过期与改绑并发、重复报名、无旧映射账号，以及通知周期与失败恢复；微信和短信仍使用真实服务接入边界。
