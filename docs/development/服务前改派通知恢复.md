# 服务前客服改派通知恢复

真实来源为 `orders.prestart_handoff.reassign`：付款完成且仍处于服务开始前的订单，客服实际完成改派后，在同一订单事务中保存改派事件、原陪玩和接替陪玩的席位业务周期、TRANSFER 日志及收件意图。双陪批量调整给老板一条，给实际受影响的原陪玩和接替陪玩各一条。通知只说明服务安排已调整，不把客服操作称为陪玩确认或接单。

提交后尝试创建站内消息，失败由门店任务定期恢复；按事件和收件账号幂等，恢复时核验订单及事件、操作者、快照和原账号周期。原周期缺失、账号周期变化、订单已终结或后续再次改派时跳过，不向新周期发送。已创建消息保留既有规则。本实现不涵盖其他改派或待确认入口。

`PRESTART_HANDOFF_NOTICE_RECOVERY_ENABLED` 默认关闭，同时需要 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED`；关闭时不追补期间事件。上线前须执行结构迁移 `site_messages/0037_prestarthandoffnotice`，配置逐店任务并联调单陪、双陪、重复恢复、周期变化和实际权限；本次按要求未执行迁移或测试。
