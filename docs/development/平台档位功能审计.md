# 平台档位功能审计

`GET /api/admin/platform/license-tiers/{tier}/features/{feature}` 返回该档当前配置值 `mode`、`default_mode` 和是否存在显式覆盖 `overridden`，以及控制库中该项真实变更审计。审计按时间倒序返回平台操作者、时间、变更前后覆盖值；覆盖值为 null 且对应 `*_recorded=true` 表示使用默认值，`*_recorded=false` 表示原审计字段缺失，不能把未知当作默认。恢复默认后即使覆盖行删除，原审计仍可查询；具体门店能否使用该功能还取决于其授权状态。

沿用独立平台超级管理员和统一后台域名权限；响应不含授权码。无结构迁移；未执行测试或迁移，最终需联调覆盖、恢复默认、平台角色撤销及控制库故障。
