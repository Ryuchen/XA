# 首次开业抢单能力核验

首次开业诊断和提交共用 `opening_readiness`。除已确认的门店抢单窗口配置外，现在还核验正式 MySQL 抢单时钟、陪玩生命周期集成、付款后正式开池及单陪、双陪窗口能力。缺项通过 `grab_dispatch.details.missing` 列出；不把测试时钟作为生产能力，也不会自动开启运行开关。

该项阻止在老板未指定及客服安排新单无法进入既定自动抢单流程时误报可开业；不改变预约、指定订单、抢单排序或付款。代码只核对配置与数据库类型，不代表 worker、消息代理、MySQL 并发或三端链路已验证。无需新增迁移，本轮未运行测试或迁移；部署前需逐店联调并确认所有进程的配置一致。
