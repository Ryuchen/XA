# 已有优惠券与周期发券隔离

老板查看已有优惠券或使用已获 VIP 安全箱券报价时，会顺带尝试补发当期会员权益。该附属发券若因会员规则或月券历史证据待核对而失败，现仅回滚发券保存点并记录门店日志，继续读取和核验已获券；后台原有周期任务仍会重试，长期异常须由门店或平台根据日志核对。License 到期或无法核验时仍按原有门禁暂停新增发券。

优惠券的实际归属、业务周期、有效期、适用范围、付款锁和报价重验仍由原业务路径执行；不能因为附属发券失败跳过这些校验。数据库故障以及既有券本身的条款无法确定仍按原规则报错，不猜测优惠金额。已有订单、付款和资金流水不变。

普通订单、积分订单退款后的实销确认以及会员等级更新也使用同一发券封装：周期券配置或月券证据需要核对时，只回滚本次周期发券并记录日志，不让附属发券阻断已符合条件的订单结算和消费确认。原有周期任务继续重试；会员成长、消费积分及实际付款校验的错误仍按各自规则处理。
