# 双陪抢单逾期组队席位释放

双陪抢单邀请或队友确认经真实数据库收件证据判定为截止后，分类和对应席位释放现在在同一门店订单事务内完成；包括等待轮次激活证据后再分类的路径。进程中断时事务回滚，仍待分类的收件由现有逐店恢复任务继续处理，不会因已写逾期状态而遗留占位。首轮结束后订单仍留池的情形继续按实际轮次与总期限判断，不能仅因首轮窗口结束释放有效邀请。

释放时核对成员当前关联的原收件，避免影响其他有效组队；原邀请逾期但队友在证据待确认期间已加入时，释放该无效队伍的全部占位。同请求编号仍复用原收件，不同请求编号不能覆盖已经提交的队友确认及其时间证据。无法判明截止先后的记录仍待核对，不推定逾期。

无需新迁移，依赖现有正式数据库时钟、双陪窗口与逐店恢复任务，相关正式开关保持默认关闭。未执行测试或迁移，最终需隔离联调提交竞争、回调中断、首轮留池与多店。
