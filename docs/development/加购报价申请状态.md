# 加购报价的申请状态

老板的加购报价返回 `intent_available` 及 `intent_reason`：在本单、计价、履约陪玩及抽成快照可核对，且无需客服核实条件时，可继续发起加购申请。启用陪玩生命周期保护时，也核对本人当前周期和生命周期锁是否存在。需要客服核实、条件异常、抽成或陪玩事实待核对时分别返回原因。

报价只反映读取时的申请资格；已有的 `purchase_available` 仍为 false。申请须重新锁定事实并记录支付来源，实际付款继续由申请详情的 `payment_available` 和付款事务核验，报价不代表扣款、资金可用或支付成功。列表尚未指定陪玩及具体数量，仍不声称可直接购买。
