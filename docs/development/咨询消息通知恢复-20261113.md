# 咨询消息提交后通知恢复（2026-11-13）

老板和陪玩发送咨询、接待客服或主管回复均经现有 `schedule_chat_message`：在消息事务保存通知意图及会话用户的账号周期，再尝试保存 outbox 并在提交后投递。outbox 写入暂时失败时，消息和原周期仍提供逐店恢复依据。定时任务在通用会话刷新 outbox 开关关闭时也恢复真实聊天消息的 outbox；领取、交还等会话状态刷新的既有开关不变。

接收端仍按当前接待归属及主管权限重读，用户目标按发送时业务周期核验；共享广播不携带正文。重试是消息刷新通知，不生成重复聊天内容；channel layer 接收不代表客户端已读或收到。各店需有既有 chat/0012 及依赖，并运行逐店 worker/beat。最终联调须覆盖首次发送、同一消息重试、转交竞争、主管回复、账号重入、Redis 故障和双店隔离；未运行测试或迁移。
