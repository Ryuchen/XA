# 积分服务前改派：会员实销联调范围

积分服务订单在服务前改派、未发生服务中转单时，会员确认复用该订单既有的门店积分结算能力。未退款主单以原积分付款、结算和本金来源为依据，在实销时记录 VIP 授权决定；付款与实销时 VIP 均启用且授权允许时才计成长。授权未知时保留原时点决定，供平台人工核对，不因授权恢复自动追发。消费积分使用付款时倍率和保留本金，不把积分抵扣、赠送或赔付当作本金。

主单退款按各笔真实退回店币与本金核对。已付款加购的实销及授权按各笔加购的付款、退款和本人收益结算独立处理，不并入主单本金或重复计算。所有路径仍受现有积分资金能力、到账用途及结算凭据约束，不因本文开启业务开关。

本次没有运行测试或数据库迁移。最终联调需验证双店隔离、改派前后人员及流水、无退款与部分退款、加购付款及退款、VIP/License 两时点变化、未知授权人工核对、重试、失败回滚和 MySQL 并发。尚未接通的改派后加购或其他资金组合应继续按底层能力限制处理。
