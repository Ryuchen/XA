# 开业前服务加购配置

初始化中的门店，首位本店超级管理员可按原 `service:view`／`service:edit` 权限，读取本店主服务的加购关系，并通过既有 `config/service-addons/<服务ID>/<加购ID>/` 及其 `price-options/` 接口维护关系、条件和计价单位。保留服务同店同游戏、主服务/加购类型、配置版本、价格和后台审计等原有校验。

该入口只写配置；客户加购报价、支付、资金与履约仍受其原有营业状态、权限及业务门禁控制，不作为新开业强制项。

未运行测试、建库或迁移。最终需联调无授权初始化、角色权限、版本冲突、商品更改竞争、双店隔离、开业前购买拒绝与开业后真实订单链。
