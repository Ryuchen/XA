# 普通双陪跨加购退款的经营成本

普通主单未退款、无积分抵扣、未转单且没有加购换人的双陪订单，付款后可有多笔加购。加购退款由同一陪玩本人的另一笔加购待结算收益承担时，系统继续以每笔真实付款确认原应计收益、以退款发生期冲减实际承担，不将被扣减付款再冲减一次。主单、每笔加购的赠送和赔付来源按实际使用与退款原路冲回；推荐佣金仍按主单原规则计算。

当整单补资已足额、恰有一位陪玩已结算、另一位待结算时，经营报表会额外核对原订单及两位陪玩的收益快照、加购退款和跨付款扣减、整单资金预留与补资使用、已结算陪玩的报单及钱包流水，以及另一位的主单和加购待结算金额。只有收益和资金能够守恒且真实流水能够完整对应，才在 `operating.partly_settled_provider_evidence` 中展示该订单。

`income_posted_in_period_fen` 按查询期间的钱包收益流水时间统计，不代表线下提现打款；`pending_main_fen` 和 `pending_addon_fen` 是 `observed_at` 查询时的待结算状态，不是历史期间末余额。该列表仅列本次已核实订单，不是全店全部待结算负债。`provider_cost_fen` 是基于付款与退款事件的应计成本，不等于已入账收益。

主单发生退款、加购换人、转单、积分订单、补资不足、已结算人数不是一人或缺少真实资金凭证的情况不属于本次新增的部分结算展示范围；其他已有报表路径是否适用仍由各自的完整凭证检查决定。无法核验时，相关经营成本和 ROI 保持待核对。

本次未运行测试、检查或迁移，也尚未联调。最终联调需覆盖跨两笔及多笔加购扣减、先退款后个人结算、退款冲减主单收益、退款和结算跨月、部分及全额退款、赠送和赔付原路退款、推荐人同时为陪玩、资金版本缺失、同一流水重复、两店隔离及退款与收益结算并发。
