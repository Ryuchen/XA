# 积分抵扣配置状态

门店积分抵扣配置接口增加 `pass_redemption_status`。当抵扣规则及上限已配置、通行证积分功能和本店积分使用开关启用，且通行证销售与 License 允许时返回 `ENABLED`；门店未配置、暂停或授权明确不允许时返回 `DISABLED`；积分开关或授权无法核验时返回 `UNKNOWN`。未初始化的积分发放配置沿用通行证报价现有的启用默认值。

该状态只表示门店级条件，不代表具体陪玩一定可以购买：已有生效通行证、积分不足、余额不足等仍由报价及付款接口按本人情况判断。原有 `redemption_available` 字段保持原值，不能用它判断通行证能否使用积分；服务订单积分链仍以实际服务订单接口及其独立条件为准。保存配置不会自动打开受限的服务订单积分能力。

本次未运行测试或迁移。最终联调须覆盖开店配置、积分开关、License 到期与控制库不可用、通行证销售开关、个人资格和门店隔离。
