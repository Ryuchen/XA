# 开店积分抵扣配置读取

平台开店初始化保存积分抵扣规则后，以及平台和店内读取该规则时，返回本店服务积分抵扣的实际运行前置状态；不再固定显示不可用。判断使用本店已保存兑换组和上限、积分使用及发放开关、正式 MySQL 支付和资金来源配置、分段资金能力。无法核实门店上下文或积分开关时返回 `UNKNOWN`，没有满足条件时返回 `DISABLED`；通行证抵扣继续独立判断。

`ENABLED` 只表示店级前置条件满足；真实报价和付款仍须逐单核对服务、本人积分、订单类型、陪玩、资金和现有业务门禁，不代表所有订单及售后组合均可使用。配置保存继续复用原版本冲突检查、平台真实身份与门店审计。未运行测试或迁移；最终需隔离联调不同门店配置、功能开关、积分停用、有效报价和实际付款及后续售后。
# 补充：通行证积分抵扣状态

本店积分发放配置尚不存在时，通行证积分抵扣状态返回 `UNKNOWN`，不把未完成初始化的规则当成已启用。实际购买仍在事务内重新核对积分使用开关和门店授权；未运行测试或迁移。
