# VIP 券付款条款固化

普通服务和预约使用优惠选择付款时，服务端把实际生效的 VIP 券折扣、封顶金额、适用服务和有效期保存到该券，再标记已使用。报价确认信息也包含实际封顶金额，门店配置变化后须重新报价。券随订单全额退款且仍有效时，沿用当次使用时的条款，不回退到此前的旧封顶金额。

预约未使用显式优惠选择时，付款前在本店事务内锁定会员配置及等级，复核报价后同样保存实际生效券条款。非 VIP 券及没有变化的条款不会额外改写；此变更不改变退款资格、会员折扣互斥或积分计算。

本轮未测试或执行迁移。最终联调须覆盖同等级修改折扣及封顶、报价与付款并发、预约与普通下单、退款退券、VIP 停用或降级、过期券及双店隔离。
