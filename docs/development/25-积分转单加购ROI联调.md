# 积分转单加购的 ROI 事件口径

已接入受限的一次积分主单退款、转单及单笔加购：加购付款在主单退款之前，且没有加购退款或已确认换人；须存在可核验的最终逐段结算、原付款来源、主单退款凭据和一致的加购资金版本。主单原分段收益按主单付款月记入，主单退款承担按退款发生月冲减；加购陪玩收益和赠送／赔付成本按其独立付款月记入。推荐佣金仍以主单实付和已核验流水为准，加购不计推荐佣金，平台补资不作营业收入。

上述一次主单退款范围扩展至加购早于或晚于首次转单，并支持退款前一次经老板、原负责人和接替人确认的加购换人；加购付款时的原收益归付款月，确认后的收益差归换人确认月。仍须核验最终逐段清单、加购资金版本和责任份额，换人后退款仍不在此范围。

另接入无主单退款、已有转单、单笔加购独立退款且未换人的已结算范围：先核验积分转单资金能力、到账与最终逐段结算，再以扣加购退款之前的主单分段收益归主单付款月，加购原收益归加购付款月，退款的本人实际承担和资金来源变动归加购退款月，避免把主单收益扣减重复计入。加购付款可早于或晚于首次转单。

无主单退款、单笔加购且无加购退款的已结算积分转单，同样允许一次经三方确认的换人：核验双方履约段、确认时间与最终结算份额，付款时原收益和换人造成的收益差分别计入各自事件月。

普通逐段转单的已结算订单按每次已确认加购换人和退款分别归期，包括存在可核验主单退款的订单：依次使用换人确认时保存的逐人份额，扣除前次换人后至本次换人前的真实收益退款扣减，计算本次确认月差额；退款承担按退款月另计。逐项核对三方确认、前驱、实际付款退款和最终逐段清单；主单结案后发生的加购换人和退款还须有对应的可核验资金版本。主单原收益按扣加购退款前的分段事实计入，避免重复扣除。时序不清、版本或最终清单缺失仍待核对；多次事件代码尚未联调验证。

新增代码接入先有一笔加购退款、再转单并发生一笔主单退款的受控范围：无换人，核对最终逐段清单、加购退款编号、资金版本与本单付款来源；原始主单分段收益按付款月，加购退款与主单退款各按各自发生月冲减实际承担。该资金组合及其报表均未经最终联调。

已全退加购可没有责任份额及收益流水：报表仅在最终逐段清单明确记录对应退款、空加购份额和零净付款／来源／收益，且付款与退款凭据通过核验时按事件归期。积分资金代码已增加在一次主单退款叠加加购全退时核对零份额的受限分支，ROI 同样要求最终资金版本、原付款和两笔退款凭据一致；该新增代码未经联调，缺少清单不当作零。

缺少结算或资金版本、来源不一致、多笔加购、换人后加购退款、积分转单多笔主单退款等仍返回待核对，不按零成本处理。付款、退款和加购收入仍由独立真实流水的期间核验产生。

本轮未运行测试或迁移。最终联调须覆盖两店隔离、付款与退款跨月、退款后再转单、各陪玩分段收益、真实共享到账和赠送／赔付来源、已发佣金、幂等、异常回滚和 MySQL 并发；不据此开放资金开关。

非转单两次积分退款的 ROI 补充：订单已最终结算时，无论推荐佣金是否为零，均须核验最终结算和资金凭据；零佣金不得绕过核验。已有佣金仍须与实际收款流水和结算归属一致。

无加购双陪积分转单，两笔退款之间另一名陪玩可已真实逐段结算；第二次退款由不同陪玩依次以待结算收益、钱包及押金承担时，报表要求两次退款、原已付清单、追加资金版本、到账释放和最终逐段清单可重建。钱包扣款和押金缺口、门店扣款流水单独核验；退款成本只按该次本人承担合计冲减一次，不把资金移动再重复计成本。原始分段成本按付款月，两次承担分别按退款发生月冲减。推荐佣金须绑定最终清单与真实收款流水，已发放之后的退款不追扣；无法确定到账与退款先后或缺少凭据时待核对。该范围及底层资金代码均未执行本阶段测试或 MySQL 联调；第二人已结算及加购仍不属于本次范围。
