# 门店内容运营授权

门店后台首页轮播、运营内容和播报规则沿用各自角色权限，新增和编辑在服务端检查 `CONTENT_OPERATIONS`；控制库不可用时沿用本店已验证授权快照和到期／宽限时间，无可信状态时返回暂不可核验。首次校验与保存前校验之间发生授权变化时，轮播实际创建以前再次判断。

`club-content` 的老板权益、俱乐部活动及旧版弹窗均受内容运营授权约束；修改类型时同时检查原类型和目标类型。旧版弹窗仍由现有客户端逻辑排除，并未因此恢复展示。下单须知、陪玩保障、售后标准和积分规则继续作为基础服务规则按原角色权限管理；公告也保留原权限与行为。

授权不可用时，已有内容可读取，可按原权限下架现有轮播、运营内容及播报规则；单纯重复已保存状态不产生新内容。恢复展示或修改其他内容须重新取得授权。删除沿用原角色权限和既有业务，不影响订单、资金或已获得权益。未运行测试或迁移，最终应在隔离环境联调档位切换、宽限、可信缓存、无缓存及并发变更。
