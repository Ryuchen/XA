## 5 完成定义与门禁

“完成”分三层，缺一层都不能写成验收通过。

1. **代码与结构**：Django `check` 0 issues、`makemigrations --check --dry-run` 为 `No changes detected`、`git diff --check` 通过。
2. **隔离验证**：SQLite → `config.migration_test_settings` → `config.mysql_test_settings` → `config.multitenant_mysql_test_settings`，配合 Node 契约运行时、隔离 Caddy/Redis/Celery。行锁与并发只有真实 MySQL 才算。
3. **业务签认**：资金、真实渠道与生产就绪由用户认定，统一归 M7。
