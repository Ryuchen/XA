# 第三轮后首笔加购到账回放

第三轮主单退款后首笔加购付款的 0284 资金版本可由到账用途账本逐笔回放：核对本店、原第三轮退款、实际付款及资金来源、付款前到账与历史释放、前后资金守恒和本次真实 RELEASE。`record_third_addon_release_locked` 由付款事务写入用途事件，分页核对通过统一加购释放来源分派读取相同事实，不反向获取订单锁。

订单资金事务可调用 `verify_run_locked` 核验已有 RELEASE、零释放及无到账情况；无到账复用订单锁内第三轮原始凭证核验，不虚造到账或释放。仅支持第三轮后的首笔加购付款，其他事件时序仍由原业务门禁限制；该接口本身不开放付款或结算。

后续扩展：到账回放支持同单多笔付款的 0284 前驱链，逐版核验原付款、前版哈希、各到账历史释放与付款时资金守恒；两次付款间新增的真实本单到账按发生顺序加入，不重复扣除前版释放。前述“仅首笔”是原有支持范围；真实多笔付款仍需资金写入口、最终清单和门禁配合，第三轮后加购退款或接替仍未覆盖。
