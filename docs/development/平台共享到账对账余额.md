# 平台共享到账对账余额

平台到账可部分分配给本店多个订单及通行证退款缺口，未分配额度保留；已接通的推荐佣金退款承担也占用同一到账。原平台对账读取只累计通行证和订单用途，遗漏推荐佣金用途及其释放，会把已占用资金显示为可分配金额。

本次修改实际对账接口：对已建立用途账本的到账，在本店事务内核验完整账本后，按通行证、订单、推荐佣金及各自释放的净额计算已分配与剩余金额；通行证实际分配与账本不一致时仍显示待核对。没有账本的到账继续使用既有计算和证据门禁。该读取不替代分配事务的到账锁及逐项核验，也不改变通行证核销不写门店钱包的既定规则。

未运行测试或迁移。最终须在隔离 MySQL 环境联调同到账多订单与通行证混合分配、佣金占用和释放、超额拒绝、跨店隔离、平台与门店跨库失败恢复及并发；订单具体资金时序仍受各自现有门禁限制。
