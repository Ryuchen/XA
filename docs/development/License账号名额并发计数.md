# License 账号名额并发计数

首版空库在本店类别锁中维护老板和陪玩在籍计数：正式创建、重入、老板退店清空及陪玩注销与对应计数增减同一事务。停用、封禁、退押金不改变计数。账号准入读取已锁定类别行，避免 MySQL 可重复读事务的旧普通快照遗漏并发建号。关闭授权准入开关仍记账，重入仍恢复实际在籍状态；该开关仅决定是否核验授权。关闭开关时的账号批量创建逐个经过同一保存逻辑，先按类别排序取锁。

普通账号保存不会回写旧账号类型、在籍状态或业务周期，且只能通过生命周期服务显式变更；后台老板与陪玩 API 不开放删除，Django admin 不开放账号增删改；历史数据迁移命令存在直接更改账号类别，不属于首版空库部署流程，不能用于本计数方案。平台运营总人数统计并非授权名额统计。本店授权状态 API 对本店超管或已核实激活管理员返回同一计数器的 `account_quota`；档位不可核验时 `limit` 与 `unlimited` 为 null，可信无限档位的 `limit` 为 null、`unlimited` 为 true；计数器不存在时 `used` 为 null。新增 club_accounts/0012 结构迁移，计数从空库零开始，不支持带存量数据直接套用。
