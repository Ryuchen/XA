# 抢单激活后收件恢复

轮次激活证据已提交为 `OBSERVED` 后，如果提交回调因进程或消息队列故障未完成，原有报名、组队确认、退出或老板取消会保留为 `WAIT_OPENING`。本店定时扫描现会逐轮重新投递恢复任务，复用原数据库时钟证据分类和单双陪仲裁调度；每条收件仍在订单锁及独立事务下处理，重复投递不会重新分类已处理收件。单次队列入队失败不妨碍其他轮次，未完成记录由下次扫描重试；入队不代表已分配或已退款。

仅恢复已有可信激活证据的轮次，不重造丢失的时钟证据；`PENDING`、`PREPARED`、`REVIEW` 证据仍按原人工核对流程处理。依赖现有逐店 `check_pending_timeouts`、正式 MySQL 时钟和对应抢单开关，不引入新迁移。未运行测试或迁移，需最终隔离联调回调中断、重复投递、竞争取消、双陪及多店故障。
