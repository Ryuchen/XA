# 私有文件的账号业务周期

录音、报单凭证、咨询图片及其他受保护文件的短期链接，除原有门店、账号、文件和权限校验外，保存签发时的账号类型；老板和陪玩链接还保存本店业务周期。访问或续签时重新核对账号类型、在店状态及当前周期，退店或注销后原链接立即失效，重新入店后的账号不能续签旧周期链接。

重新登录后可通过业务接口按当前权限重新获取文件链接；历史消息保留规则不因旧链接失效而改变。后台员工继续按当前角色、接待责任和资源权限逐次核验，跨店链接仍不可使用。

按首版规则，未绑定上述身份快照的旧链接不再使用。此修改无需数据库迁移，本轮未运行测试；最终联调须覆盖本店及跨店同编号、退店重入、停用、客服转交或撤权、录音与图片，以及重新获取合法链接。
