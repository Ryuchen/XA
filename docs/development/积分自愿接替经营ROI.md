# 积分自愿加购接替的经营 ROI

积分转单首次主单退款后的经营报表，遇到已确认自愿加购接替时，改用既有只读结算范围核验真实退款、结案及资金，而不请求仅供退款执行事务使用的能力。加购多次接替后，同一付款、同一履约段的多笔责任份额按真实最终结算清单合并；每次接替仍核对当事人确认、实际责任和资金事件。主单与加购收益归付款期，接替收益变化归确认期，退款承担及赠送／赔付退回归退款期；推荐佣金和续单奖励继续走原真实流水路径。

加购退款的期间收入和成本使用该退款直接关联的老板钱包入账时刻，避免同一事务跨日或跨月写退款单时将两者错误分到不同期间。积分返还仍单列，不计为退回店币。

本次只在既有资金版本、已最终结算清单和各项来源均可核验时输出成本。陪玩分批结算但整单尚未完成、自愿接替或退款版本尚未被上游结算范围支持、主单退款及积分流水跨期间未证明的情形仍待核对，不按零成本输出。未运行测试或迁移；最终须隔离联调多次接替、同段重复份额、多笔退款和分批结算、跨月、已发佣金及续单奖、共享到账、失败回滚和门店隔离。

## 后续：整单未结清的逐人实付

已履约完成、整单尚未结清但已有陪玩逐段结算时，积分转单首次或第二次主单退款的报表路径可在资金和清单可完整重建时读取部分结算：核验清单版本、整单补资、已付本人及加购钱包流水；已付款后发生的加购退款还须具有真实的自愿接替已付快照。报表按原付款、退款和接替事件归集应计成本，并在结算证据中单列查询期间实际入账与当前观察到的待结算主单、加购金额。待结算金额不是历史查询期末余额，也不表示已经付款。

此范围不开放尚未履约完成的提前结算，也不覆盖上游资金、真实已付流水或结算版本无法核验的组合；主单退款与积分返还的跨期证据限制仍保留。未运行测试或迁移；最终须以真实多次退款、已付后接替与退款、报单等待期、到账释放、跨月以及并发回滚进行隔离联调。
