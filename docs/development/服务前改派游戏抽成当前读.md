# 服务前改派的本店游戏抽成

门店可配置三角洲按陪玩本人资格档位抽成，瓦罗兰特及英雄联盟按陪玩、代肝两类抽成，上分映射代肝。服务前改派原来先锁住本店游戏配置，随后又用普通查询重新读取；若事务在等待配置更新前已建立 MySQL 快照，转入陪玩可能保存旧比例。

改派事务现将锁定读取到的本店游戏配置直接交给原有付款规则解析，使用原订单已购服务范围和转入陪玩本人资格生成新快照。三角洲保留本人档位及完整规则证据，其他游戏沿用陪玩／代肝映射；原价格、原陪玩已成交规则及已保存订单事实不重写。

未运行测试或迁移。最终隔离 MySQL 联调须覆盖配置与改派并发、双陪不同档位、三款游戏、上分映射、原商品范围变化、后续结算及两店隔离；其他转单和资金版本仍以各自现有能力为准。
