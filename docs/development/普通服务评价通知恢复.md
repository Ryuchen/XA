# 普通服务评价通知恢复

普通非低星评价在真实评价事务中，开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 和默认关闭的 `EVALUATION_NOTICE_RECOVERY_ENABLED` 后保存陪玩通知意图；收件账号及原业务周期来自评价和原订单的持久履约事实，不从当前账号推测。提交后独立投递，失败由本店任务重试，同一评价最多创建一条消息。投递时核验真实评价仍未作废、属于原订单陪玩、订单来源周期及账号在店周期；不可证明或账号重入时记录跳过。

生命周期集成开启而恢复开关关闭时，仍按原周期即时投递，但不能恢复失败；生命周期集成关闭沿用原路径。已创建的评价消息不因评价作废而修改或删除；本功能不创建或修改售后，也不改低星判断、售后期限、订单状态或评价广播。消息创建不代表客户端收到实时刷新。

启用恢复前须在各店应用 `site_messages/0023_evaluationnotice` 及依赖并运行逐店 worker/beat。最终联调须覆盖多维评分、单双陪及转单、评价作废与投递竞争、已发送消息保留、消息插入失败恢复、并发扫描、账号停用与重入、双店同号和评价事务回滚；其他实时事件仍有缺口，正式注销保持关闭。本轮未运行检查、测试或迁移。
