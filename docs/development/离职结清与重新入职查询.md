# 离职结清与重新入职查询

有 `salary:view` 权限的本店后台可通过 `GET /api/admin/payroll/separation-settlements/?kind=settlements` 查找结清记录，默认返回尚未登记重新入职的记录。`state` 可选 `pending_reemployment`、`reemployed`、`all`；可按 `account_id` 过滤，使用 `after_id` 和响应中的 `next_after_id` 顺序翻页，每页最多 100 条。

结果提供员工、最后工资确认记录和月份、真实线下结清金额（人民币分）、参考凭证、备注、确认人和时间，以及存在时的重新入职记录和时间。查询不创建凭证或确认工资；原结清放弃项查询保持原接口。授权人员可用返回的结清 ID 经既有 `salary:confirm` 入口登记重入并选择薪资方案，原工资与已确认结清不被修改。

无需结构迁移；本次未运行测试或迁移。仍需隔离环境联调多次离职重入、分页、授权与门店隔离，以及重入和结清并发。
