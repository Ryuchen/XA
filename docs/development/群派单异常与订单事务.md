# 群派单异常与订单事务

KOOK 和企微自动派单的配置读取、授权核验和记录创建在本店独立事务或外层支付事务的保存点内执行。配置读取、控制库授权不可核验或入队失败时先回滚该附属操作并记录订单标识，避免错误使客服代单或老板付款事务回滚；不放宽新增群发所需 License，不表示消息已入队或送达。

已有抢单池恢复任务会按已观察开池事实扫描仍有效订单的缺失群发记录，再执行原有授权和配置判断；无相应开池事实的其他订单目前没有自动补建记录，须查看订单和日志并由有权人员人工预览后发单。已有未知送达状态不得自动重发。数据库连接整体不可用或外层事务已被数据库主动中止时，保存点不能保证核心事务继续，仍需真实故障联调。

未运行测试或迁移；最终联调须覆盖本店控制库和配置读取失败、外层支付回滚、恢复任务、多店隔离及不重复群发。
