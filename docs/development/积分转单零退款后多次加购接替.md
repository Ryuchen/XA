# 积分转单零退款后的多次加购接替

已接入的积分转单零退款终止后加购退款路径，原先把同一付款的已确认接替链硬编码为最多两次。现改为逐次核对前驱、确认时间及真实转单负债版本，不以接替次数判定是否允许退款；已有入口继续在订单和资金锁内核对每次三方确认、付款、退款及 RELEASE，再处理实际退款和后续逐段结算。

此修改覆盖当前已有真实转单负债版本且其余资金与履约凭证完整的路径；不改变每席主单最多两次转单的规则，也不代表不依赖主单转单的自愿接替已经接入。未运行测试或迁移。最终须在隔离 MySQL 联调三次及以上接替、不同席位转单、零退款终止、部分退款、共享到账、无释放事件、补资和逐段结算，以及重试和并发回滚。
