# 补差抢单分配并发

退款押金缺口陪玩参加单陪或双陪抢单时，最终分配在既有订单、陪玩派单及资料锁下，对本账号实际缺口与未关闭补差许可使用锁定当前读。其他订单已占用机会或存在非退款导致的押金不足时，不创建第二张许可；该明确资格失效按原首名失格重开或到期退款规则处理。双陪任一成员失去该资格时，整个分配及任何许可写入一并回滚。

原收件时间、排序、普通并发名额及补差收益结算规则不变；资料不一致等其他异常继续核对，不把它们当资格失效。相关能力开关仍默认关闭；未新增迁移、未运行测试或迁移。最终须在隔离 MySQL 联调同人跨单双陪并发、缺口补齐或产生与分配竞争、重开及事务回滚。早于最终分配的列表／报名资格仍是读取提示，实际结果以锁内复核为准。
