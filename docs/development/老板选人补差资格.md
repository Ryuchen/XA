# 老板选人时的退款押金补差资格

启用退款押金补差接单功能时，老板端陪玩列表、详情与可选服务使用同一补差资格判断：现金押金不足但存在本人退款押金缺口的陪玩，不再仅因列表的押金预筛选被排除；已有未结算补差单、存在非退款押金缺口或不满足其他接单条件时仍不可选。

列表结果只是当前可用性提示。付款与实际派单仍在锁内复核押金缺口、补差接单机会和并发名额，只有成功派单才占用该机会。功能关闭时沿用原押金规则。本次未运行测试或迁移；最终须联调指定下单、抢单、双陪、已有补差单、缺口并发变化及两店隔离。

陪玩端单陪抢单操作提示也使用同一补差资格，避免有资格时因普通押金判断隐藏操作；实际抢单仍按订单和陪玩锁内检查。正式抢单截止证据尚不确定时，老板端不提供选人操作；接口以 `null` 表示截止状态未知，而非当作未到期。本次未运行测试或迁移。
