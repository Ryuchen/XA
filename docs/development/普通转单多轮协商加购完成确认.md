# 普通转单多轮协商加购完成确认

普通服务先发生真实协商（包括零退款或正退款）、随后转单并继续追加协商时，加购完成确认现在从已验证的整条协商链按当前加购责任人的实际履约段选择终止执行，不再只识别转单后才建立的首轮凭证，也不按同一账号的最新一次协商替代原段。客服发起、老板及对应陪玩确认、结算时复核共用该来源；必须核对真实付款、接替、退款方案和结案事实。已结算判断按目标履约段，另一段已有收益不会阻止未结算段；新请求不会覆盖其他履约段已确认的记录，旧待确认请求仍按原机制失效并更新通知。转单场景先锁订单与资金互斥，再锁付款，保持既有锁序。最终结算仍要求真实补资、整单完成、本人报单及等待期，历史收益不重算或重付。

未新增迁移；未运行测试或迁移。尚未覆盖的未转单多轮、无法验证的轮次或履约段继续按既有门禁处理。最终须联调首次协商先于转单、零/正金额、多轮及同人不同段、真实加购退款、双人确认、部分已结算、补资与到账、通知失效和并发回滚。
