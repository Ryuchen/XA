# 微信登录令牌认证来源

微信小程序授权成功的老板登录使用 `wechat` 认证来源签发令牌。已绑定 OTP 的用户完成微信授权后无需再次输入动态口令；后续请求与刷新会核对账号当前微信绑定，解绑或身份改变后原微信令牌不再可用。

网页扫码桥接的已绑定微信账号可直接确认登录，不因账号尚无已验证手机号而强制补短信；登录用途不接受顺带的手机号授权作为换绑操作。已登录账号发起微信绑定也不额外强制补手机号；首次建立手机号或更换手机号仍走原来的手机号及短信验证流程。微信未配置时接口继续返回不可用，模拟登录仍须由隔离开发环境明确启用，不能视为真实微信授权。账号密码加短信／OTP 登录继续使用各自现有链路。

代码未运行测试或迁移。最终联调应在隔离环境覆盖已绑定／未绑定 OTP、微信真实授权、解绑后访问与刷新、账号停用、双店身份隔离和未配置微信凭据；真实微信服务尚待申请通过。
