# 双陪预约空席展示

双陪预约的首席位拒绝或超时后，另一个已确认席位仍可保留到预约开始。预约主记录为保证关联完整会保留原主陪玩账号，直到老板选择替代者；席位记录才是当前邀请事实。预约列表及详情的 `provider` 字段现使用首席位的实际账号、姓名及头像：该席位空缺时返回空账号与空姓名，替换后显示新陪玩，避免把已经拒绝或超时的陪玩展示为仍被预约。`seats` 和已转单后的 `current_providers` 仍分别表示预约席位及订单当前履约人。

实现前参考 [slotted](https://github.com/chippad781/slotted) 的预约资源锁与事务内重查思路；本项目沿用既有陪玩档案锁和独立席位，不采用其 PostgreSQL 数据模型或改变预约时限。没有修改前端、迁移数据库或运行测试。最终联调需覆盖首席位和第二席位分别拒绝或超时、剩余陪玩已确认、替换后转单以及双店隔离。
