# 老板 KOOK 绑定与退店周期

KOOK 老板绑定挑战、签到和在线计分、在线状态初始化与重连补充，现在在 KOOK 数据和积分写入前锁定本店老板账号，并复核原业务周期和在店状态，与老板退店、重入共享账号锁。退店后不再累计积分；重入后的旧绑定不作为当前有效绑定，接口返回 `rebind_required`，须本人通过原 KOOK 身份重新发送绑定验证码。

重验时保留历史绑定和已发积分，重置在线累计及已发积分的当前周期基线，先前未满两小时的零头不跨周期延续。`GET /api/club/kook-binding/` 的当前在线时长和积分按当前周期基线返回；授权异常的历史事件由平台核对时也必须匹配原账号和绑定周期，不能向新周期补分。

未新增迁移；本次未运行测试或迁移。最终须在隔离环境联调退店与计分竞争、短时离线及重入后同一 KOOK 本人重验、两小时边界、授权 UNKNOWN 核对、绑定竞争及双店隔离。KOOK 机器人外部连通与消息真实投递尚未验证。
