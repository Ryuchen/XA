# 押金登记与退还站内通知

入驻现金押金登记、客服现金补差和押金退回陪玩钱包，分别在真实资金事务内保存通知意图；前两项关联现金登记和门店押金流水，退还关联本人钱包正向流水与门店押金池配对流水。意图保存账号原业务周期及当时本店币名；提交后尝试发送站内消息，异常保持 PENDING。逐店恢复由 `DEPOSIT_EVENT_NOTICE_RECOVERY_ENABLED` 控制，默认关闭。

恢复时校验真实金额、流水状态、账户和原周期。来源或周期不明进入 REVIEW；陪玩注销重入后不向新周期发送旧意图。退还通知明确款项退回钱包，不称为线下已打款。客服登记接口仍直接返回真实处理结果；现有系统没有单独退押金申请工单，不虚构申请或客服收件人。

首次部署依赖 `site_messages/0049_depositeventnotice` 及前置结构。本轮未运行测试或迁移；需在隔离双店联调现金入驻、补差、押金退款配对、失败恢复、账号重入及 MySQL 锁序。站内记录与 WebSocket 实时刷新、短信或微信外发分别计状态。
