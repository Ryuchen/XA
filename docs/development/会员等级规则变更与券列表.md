# 本店等级规则变更与已发券

门店后台修改仍启用等级的月券折扣、安全箱折扣／服务范围或相关权益配置时，在原会员配置和等级锁内复用平台初始化的券条款同步：核对当前账号周期、券归属及有效性后，保存本店未使用且未锁定的私有月券和安全箱券当前生效条款，使券列表和后续锁后报价一致。归属异常会回滚配置，避免错误改写多人共用券。

月券数量变动不补发或撤销当月已发券，从下次发券决定生效；已使用、过期、因升级或降级等已锁定条款的券不改。VIP 已停用时不重算既有券条款，恢复流程沿用停用基线和既有保护。同步不创建券、不修改到期时间或订单支付历史。未执行测试或迁移；最终须联调本店/平台配置与付款并发、授权状态变化和券列表。
