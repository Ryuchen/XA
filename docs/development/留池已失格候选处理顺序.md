# 留池已失格候选的处理顺序

首轮无候选后，留池应把订单交给最先完成登记且仍合资格的单陪或完整双陪队伍。此前仲裁先比较所有候选的提交时间；当观察区间重叠时，即使其中一人已明确失格，另一候选也会被送入时间核对。现在只在留池阶段、持原生命周期／派单及本人资料锁后，先按当前事实移除可确定失格的候选，并复用原失格记录及通知，再比较剩余候选。双陪任一成员明确失格则整队退出候选。

本次提前处理的事实包括原门店周期失效、账号停用、未认证、离线、实际非退款押金不足及已占用的补差许可；对无法证明的服务资格、并发名额或提交时间仍沿原资格核验及待核对流程。最终分配仍在锁内再次核验，首轮第一名失格的重开／到期退款规则不变。相关开关按原默认关闭；无新增迁移，未运行测试或迁移，最终须隔离 MySQL／Celery 联调多人时间重叠、单／双陪资格变化、补差竞争和退款。
