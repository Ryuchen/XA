# 积分双陪多加购换人的经营成本

本分支覆盖主单尚未退款、未发生主服务转单或服务前改派的积分双陪订单。订单可以有多笔已付款加购，各笔可有多次退款，并可分别发生一次已生效的同单双陪换人；不同加购的换人可以先后发生。仅当整单补资足额，且恰有一人已结算、另一人等待，或全部人员及整单已结算时，才计算此路径。

系统核对主单及各项加购的真实付款来源、每笔退款与钱包流水、三方换人确认及客服审计、换人资金版本、逐段收益、门店到账和补资使用，以及陪玩报单与实际入账。加购的原预计收益按其付款期计入，退款按自身发生期冲减实际承担，换人确认期只调整换人后的收益与换人前剩余收益的差额，避免重复扣除换人前已发生的退款。赠送和赔付按实际使用与原路退回处理；推荐佣金沿用主单口径，不因加购另行发放。

部分结算时，`operating.partly_settled_provider_evidence` 只列本次查询已核实订单：`income_posted_in_period_fen` 是查询期间钱包收益入账，并非提现打款；`pending_main_fen` 和 `pending_addon_fen` 是 `observed_at` 时点待结算金额，并非历史期末余额或全店待结算汇总。经营成本字段仍为按付款、退款和换人事件归属的应计成本。

主单已退款、加购单项发生多次换人、资金或三方确认凭证不足、未有人员结算、补资不足及其他不符合本分支条件的场景由其他已核验路径处理；没有适用路径时保持待核对。退款记录与实际钱包退款流水落在查询期间不同侧时不计算该订单的经营成本。

本次未运行测试、检查或迁移，也尚未联调。最终联调需覆盖多项加购分别换人、各项多次退款及跨加购扣减、先退款再换人和先换人后退款、不同抽成下跨月差额、双陪分别先结算和全部结算、赠送赔付原路退回、推荐佣金实际发放、补资不足、两店隔离及并发失败回滚。
