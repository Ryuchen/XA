# 双陪抢单邀请分页

陪玩本人组队邀请列表先核验邀请人的有效身份及双方原业务周期，再返回最多 50 条，避免无效旧邀请占满前 50 条而遮住可确认的有效邀请。尚未到本人可见时刻的真实邀请仍只显示原有有限信息，不提前暴露订单。

接口保留 `data` 数组，增加顶层 `has_more` 与 `next_before_id`；下一页使用可选 `before_id`，无效游标返回 400。确认、退队和实际分发仍由原收件及仲裁事务决定。未运行测试或迁移，真实 MySQL、周期变化及分页竞争待最终联调。

若某条邀请的入池可见时间无法从真实快照核验，该条返回 `visibility_state=REVIEW`、`visible_at=null`、`order_visible=false`，不输出订单信息；其他邀请仍可查看。可核验时 `visibility_state=KNOWN`；本人确认仍由原收件事务决定。此修正未运行测试或迁移，待最终联调。

正式时钟下，首轮激活尚未观察到时，邀请返回 `visibility_state=PENDING`、`visible_at=null` 且隐藏订单；重开轮使用真实激活时间区间上界，不以暂定开池时间冒充已生效。激活证据无法核验则仍为 REVIEW。此项不改变收件和仲裁；未运行测试或迁移。
