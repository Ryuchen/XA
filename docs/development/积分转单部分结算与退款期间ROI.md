# 积分转单部分结算与退款期间 ROI

没有主单退款的积分转单，若服务已完成、整单尚未结清而已有逐人收益入账，经营报表现在复用本单整单补资、结算方案、实际人员和加购钱包流水核验，并列出期间实际入账及当前待结算金额。自愿接替后付款人员已结算再发生加购退款时，仍要求对应真实已付快照及清单版本；未完成服务或来源不完整不按零成本处理。

主单实际退币按关联老板钱包入账时刻归收入冲减，积分返还独立按积分账本发生时刻列示；积分转单首轮及第二轮退款的陪玩承担、赠送／赔付变化和推荐佣金调整使用实际退款资产入账时刻归期。加购退款继续按其关联钱包入账时刻归期，续单奖励保持单独按真实发放流水计成本。没有完成真实资金验证的分支仍待核对，其他尚未改造的成本分支发生退款记录与入账跨期间时继续提示待核对。

该改动不修改或重算既有订单、结算或流水。未运行测试或迁移；最终须隔离联调跨月退币和返积分、多笔退款与多项加购、自愿接替、部分与最终结算、已发推荐佣金和续单奖励、共享到账、多门店、并发回滚及报表期间汇总。
