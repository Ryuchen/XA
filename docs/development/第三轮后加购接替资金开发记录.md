# 第三轮后加购接替资金开发记录

本轮将第三次主单退款后的受控自愿加购接替接入现有后端入口，未执行测试或数据库迁移，尚待统一联调。

- 未执行的 `orders/0284` 和对应模型增加 handover 来源，付款、退款、接替三者互斥；接替版本与原第三轮及前一资金事件关联。
- `points_third_addon_handover` 提供锁内捕获与写入：使用真实当前付款份额、各方决定、目标抽成与整单到账余额，计算接替前后收益差，记录零或正数释放并调用到账用途核验。最后一方确认时先捕获、再确认和写入，失败整体回滚。
- 三轮资金历史和逐段结算计划增加按事件顺序读取接替版本；到账用途本地回放由并行工作接入。
- 公开创建和决定作用域限定为真实已付款的 VOLUNTARY 接替，来源为仍在履约的原段，现有入口核对目标资格与实际份额；同一已接受或已拒绝的请求按原方案及资金事实回读。确认次数没有新增产品上限。

仍受限：该路径要求整单尚无已结算人员；STANDARD 转单待交责任、来源段已转出、目标段终止、其他未接通的售后交错组合继续走既有门禁。尚须集中联调三方确认、混合退款及多次接替、零／正 RELEASE、补资足额后的逐人结算和会员实销，不能将代码接线视为业务验收。
