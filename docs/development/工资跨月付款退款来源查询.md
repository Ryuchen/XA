# 工资跨月付款与退款来源查询

工资计算已按主单、加购付款及退款各自的真实事件月份核算，并沿用主单经核实的派单归属。但工资业绩列表的月份筛选此前只按主单付款查派单来源：主单上月支付、本月加购或退款时，工资实际已有事件，本月列表却不能找到对应人员和来源。

列表现复用工资计算使用的逐月真实付款及退款事件，返回当月有事件且已归属的原派单记录；迟核记录仍按补发月份可查。退款的钱包流水或付款凭证不能核验时沿用工资计算的待核对处理，不猜测来源。原确认工资快照、资金流水及后期调整算法不变；该改动修复查询入口，不代表新增工资记账屏障或扩大订单资金能力。
