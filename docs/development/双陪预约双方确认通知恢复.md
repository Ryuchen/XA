# 双陪预约双方确认通知恢复

双陪预约仅在两名陪玩都完成本人确认、预约从待确认转为已确认的事务内，记录两席各自的账号、原业务周期、原用户和确认事件，复用预约状态日志保存发送意图。分别向两名陪玩发送“双方已确认预约”，不称为已付款或已成单；老板侧已有独立确认状态提醒，此处不重复发送。

事务提交后尝试发送，由现有门店任务逐店扫描失败的意图；按日志和收件位置幂等。恢复时核验双席、本人确认事件、原账号周期及预约当前状态。预约取消、过期、转单、付款时限已过、席位或周期变化时跳过过时通知。已发送的站内消息沿用现有规则。

`RESERVATION_TEAM_CONFIRMED_NOTICE_RECOVERY_ENABLED` 默认关闭，依赖 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED`；关闭期间的事件不会补发。复用现有字段和表，不新增迁移。本次未运行测试；启用前须在隔离环境联调双方确认、重选、超时、取消、周期变化及失败恢复。
