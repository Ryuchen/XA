# 四维低星评价的后台筛选（2026-11-13）

后台已有评价查看权限的列表支持 `low_rating=1`，筛选综合、技术、态度、沟通任一项为 1–2 星且未作废的评价；原 `score` 仍只筛综合评分。支持 `low_rating_aftersale_state=EXPIRED` 按真实已保存的售后过期结果筛选，亦可筛选 OPENED、ATTACHED、CLOSED、INELIGIBLE；条件可组合。其他取值返回参数错误。该接口沿用本店 `evaluation:view` 权限和已有匿名评价后台展示授权，不改变评价、售后、通知和退款状态。

提交入口要求四项独立填写；低星期内按本人建单或追加，期外保留 EXPIRED 提示；评价作废后重复提交仍被拒绝。以上为代码接线，最终须联调四维各自低星、期内期外、双陪及转单、匿名、作废与两店隔离；本次未运行测试或迁移。
