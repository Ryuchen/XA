# 加购付款站内通知

加购真实付款事务创建一条通知意图，关联付款、本店陪玩、原履约段和段上的业务周期；提交后立即尝试投递。失败时意图保持 PENDING，按店任务可以重试，不重复支付或重复创建站内消息。恢复任务由 `ADDON_PAYMENT_NOTICE_RECOVERY_ENABLED` 控制，默认关闭；意图写入和提交后首次投递不依赖该开关。

投递核对原付款及资金来源、原履约段与收件周期，并重新核对当前加购责任。缺失或矛盾的周期和付款来源转 REVIEW；原账号退店／重入，或责任已转移、退款结清时不向新周期发送。该消息仅为站内通知，不代表短信或微信消息已发送。

首次部署须先完成数据库结构迁移，包括 `site_messages/0045_addonpaymentnotice`；本轮未执行迁移或测试。需最终以隔离的双店真实支付、事务回滚、发送失败重试、责任转移、退款和账号重入场景联调，另有其他通知入口未在本轮覆盖。

恢复范围是持久意图到站内消息写入；现有 WebSocket 列表刷新信号为尽力推送，失败不会单独重发，已保存的消息仍可从消息列表读取。
