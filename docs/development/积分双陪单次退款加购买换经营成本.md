# 积分双陪单次主单退款与加购换人

本报表分支覆盖本店未转单的积分双陪服务：主单发生一次真实协商退款，已有加购可发生多次实际退款和每笔一次已确认的同单换人；换人可以位于主单退款之前或之后，加购退款也可以位于换人前后。仅当后续加购事件的资金版本、整单补资和人员收益可以完整核对，且一位陪玩已结算另一位等待，或两位及整单均已结算时，才计算该分支。

报表按实际主单及加购付款时间确认原收入与陪玩应计收益；按每笔退款发生时间冲减实际退回店币、陪玩承担及退回的赠送／赔付来源。换人须核对三方确认、客服审计、资金释放版本及逐段收益，按确认时换人后收益与换人前剩余收益的差额调整一次应计成本；换人前退款已扣减的收益不会再次冲减。返还积分单独展示，推荐佣金依主单净实付和既有凭证核算，已发佣金不追回。

部分结算订单通过 `operating.partly_settled_provider_evidence` 仅展示当前查询中已经核实的记录：`income_posted_in_period_fen` 为查询期间钱包收益入账，`pending_main_fen` 与 `pending_addon_fen` 为 `observed_at` 时点的待结算金额。钱包收益入账不是提现打款；当前待结算金额不是历史查询期末余额，该列表也不是全店待结算汇总。员工工资仍依既有工资核算与跨期调整规则处理，本分支不写入工资或资金流水。

`operating.verified_provider_settlement_evidence` 同时列出本分支已核实的部分结算和整单结算订单。`status`、`settled_segment_ids` 与待结算字段均为 `observed_at` 时点状态；整单结算显示待结算为零仅在所有陪玩和加购收益以及最终资金凭证已经核对后给出。`income_posted_in_period_fen` 单独按真实入账流水时间归属查询期间；查询历史期间时，不能把当前结算状态或待结算金额解释为当时的期末状态。该列表只代表本分支中进入本次查询且核实通过的订单，不是全店汇总。

无法核实事件顺序、退款来源、换人资金版本、报单、个人收益、门店补资或佣金时保持待核对；主单转单、两次主单退款、每笔加购多次换人和未产生任何个人结算凭证的组合不由本分支推断。主单与退款钱包流水或加购退款与钱包流水落在查询期间不同侧时也保持待核对。

本次未运行测试、检查或迁移，也尚未联调。最终联调需覆盖先退款后换人和换人后退款、多笔加购及跨加购收益扣减、多个退款跨月、已结算一人与另一人等待、整单结算、赠送与赔付原路退款、积分返还、收益冻结与补资不足、已发佣金、工资已确认后的跨期调整、订单及门店隔离，以及并发和失败回滚。
