# 通行证积分付款的门店配置当前读

平台和门店可配置通行证日价、销售开关及积分整组兑换规则。通行证购买原先取得通行证配置互斥锁后，销售开关和日价仍使用普通查询；MySQL 可重复读事务若已建立旧快照，等待配置修改后仍可能按旧开关售卖或按旧价格扣款。积分兑换组和积分使用开关的最终核验原本已使用锁定读。

购买事务现在在取得本店通行证配置锁后，对销售开关及所选档位日价使用当前锁定读，再与已确认价格和积分报价核对。原积分抵扣上限、整组换算、余额、24 小时生效及已有有效通行证不可再买的规则不变；只读报价仍不锁定或预占资金。

未运行测试或迁移。最终隔离 MySQL 联调须覆盖开关与日价修改并发购买、积分报价变化、整组及上限、重复请求和两店不同规则；其他积分订单资金门禁仍按各自现有范围处理。
