# 签到配置授权边界

门店后台修改签到消费门槛、补签卡及全勤规则，或创建、启用及修改生效的签到奖励时，除原有 `checkin:edit` 权限外，还必须通过当前门店 `CHECKIN` License 能力判断。授权明确不支持时返回权限拒绝，控制库与可信缓存均不可核验时返回 503；配置期内符合既有初始化身份规则的门店超级管理员可完成其允许访问的配置。

规则和奖励查询、纯停用奖励、未启用奖励草稿与原有删除权限不受增值配置校验拦截。奖励更新与规则编辑在本店事务中锁定相应配置后核对授权，避免并发更新使用旧的启用状态。单独停用不能同时修改其他奖励条款。

本次只处理后台配置入口，不修改签到发奖时原有授权判断，不影响既有补签卡使用、已确认消费和已发放奖励及其记录。已有权益与在途业务仍依赖原有链路，不由此声明全链路已验收。

最终应在隔离环境联调有效、宽限、过期、降档、可信缓存不可用及双店隔离，同时验证初始化账号权限、草稿／停用、并发修改和到期后已有补签卡使用。本轮未运行测试或迁移。
