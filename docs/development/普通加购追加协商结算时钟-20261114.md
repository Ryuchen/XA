# 普通加购追加协商结算时钟

普通双陪订单发生首次协商及后续协商、并使用加购追加协商结算路径时，首位陪玩的真实结算入口改为复用 `negotiated_aftersale_start`：服务中协商终止的本人从原协商确认时起算；正常履约结束后才协商的本人从整单完成时起算。两种情况都仍须整单完成、整单补资到位、本人没有未结售后，且本人报单审核和收益冻结期满足原条件后才执行真实收益及加购结算。已付记录继续走原回读，不重复付款。

这次只修正已接入的追加协商结算路径的时钟，不代表其他主单、加购和转单交错组合已经开放；例如其他历史补资释放及转单前加购退款/接替的部分组合仍受现有资金版本门禁约束。未执行测试或数据库迁移；最终联调需覆盖两种时钟、双陪整单完成前禁止付款、待补资、本人未结售后、报单冻结和已付重试。
