# 同单主单与加购授权批量重算

普通钱包付款的服务订单中，主单退款会员授权与该单加购会员授权均经平台确认 ALLOW、但仍待重算时，后台可批量复核。任务先锁同一订单及既有订单资金互斥，再复用主单和每笔加购的原审核入口核验付款、当前退款和实销依据；锁定原老板钱包与账号后复核全部待处理审核集合，全部可证明且属于同一业务周期才重算一次。任何凭证不足、待处理集合变化或周期变化，整个事务回滚并保留待处理；平台原审核和操作者不重建。

仅覆盖原审核验证器已经支持的普通付款、无转单场景，并要求主单与全部待处理加购属于同一订单。积分支付、转单、礼物混合、跨订单和原审核验证器无法证明的多退款继续待核对；不同订单的完整批量锁契约仍未实现。单独加购批次沿用原范围。

未运行测试或迁移。最终须以隔离真实业务联调部分及多笔退款、主单与加购同时退款、授权恢复、新审核并发、退店重入、资金互斥和钱包账号锁顺序及跨库审计。
