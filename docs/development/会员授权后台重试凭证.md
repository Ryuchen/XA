# 会员授权后台重试凭证

会员授权审核后台任务不再直接调用会员重算。当前周期恰有一笔待重算审核时，任务使用原审核的请求编号、平台操作者、结论和原因，在独立事务中重进对应的加购、礼物或服务退款审核入口；入口复核真实付款、适用范围内的当前退款及原业务周期后才重算。原平台审核事实不重建，旧周期仍仅在退店审计可核实时关闭待处理。

会员重算会汇总同一周期的实销并批量清除待重算标记，一笔审核不能证明其他待处理审核。因此同周期存在多笔待重算审核时，自动任务与上述单笔人工重试均保留待处理；新建礼物或加购审核时也不据单笔证据触发批量重算。服务退款审核创建时锁定原老板钱包和账号以核对周期。缺失资金凭证、退款分支超出原验证器范围、账号周期变化或当前 License 不允许时继续待核对。

本次没有实现多笔审核的整批证据核验与结案；其他触发会员重算的入口及后台任务与其交错仍需整体联调，不能将本改动视作所有自动发放入口已核验。未运行测试或迁移。最终需在隔离环境覆盖多笔待处理、退款并发、授权恢复、退店重入、任务重试、跨库审计及订单和钱包锁顺序。
