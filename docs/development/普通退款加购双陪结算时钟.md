# 普通退款加购双陪结算时钟

普通双陪订单含加购、且发生一次协商退款时，原逐人结算和已结算回读对受影响陪玩均从协商确认时重新计算售后等待。若协商发生在整单完成后，这会把已经从整单完成起算的等待错误延后。

实际逐人放款与已放款校验现共用 `negotiated_aftersale_start`：服务中协商终止的陪玩从本人终止时起算；整单完成后才协商的陪玩从整单完成时起算。两条路径仍要求整单已经完成、该陪玩无进行中的相关售后、本人最后有效报单已审核且其付款快照冻结期届满，并继续核验真实收益及门店补资。

本轮未运行测试或迁移。最终需在隔离环境联调服务中终止、整单完成后协商、双陪报单时间不同、部分放款重试及共享补资等情况。
