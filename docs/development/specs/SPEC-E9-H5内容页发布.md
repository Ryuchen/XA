# SPEC-E9 H5 内容页生成与发布

2026-11-25 当前执行切片。依据功能排期第 40 项、开发 28 E9、PRD 40 §2.4 及现行文本合规规则。

## 完成定义

- 每店可生成价目表、点单须知和门店介绍三类页面；草稿预览不产生公开页面。
- 发布保存不可变内容快照、版本、摘要、操作者和合规回执；公开端只读当前已发布版本，修改资料不追改历史。
- 域名决定门店，公开 token 不能跨店；撤回后 HTML 与 JSON 均不可读；未知域名、未发布、停用店及写方法按契约拒绝。
- 发布要求独立权限、版权声明确认和当前文本合规；合规或审计失败不产生半成品。图片型内容未接入前显式拒绝，不能静默丢图。
- 发布与撤回使用 `client_request_id` 和预期版本；同号同内容恢复原结果，异内容或陈旧版本冲突。
- 后台提供列表、预览、发布、撤回、历史和受权限保护的回执读取，覆盖加载、空、失败、刷新失败、权限与未知结果恢复。

## 非目标

不实现老板端 H5 商业购买、品牌定制、实名、图片内容识别或公开旧版本读取；不改变平台及门店既有模块边界。

## 验证

后端发布、快照、撤回、权限、合规、幂等、双店同 token/数字 ID 与公开路由测试；Admin 契约测试、类型检查、构建；Django 检查和迁移一致性。真实浏览器 1366×1024、公开域名与五入口另留联调记录。

## 回退

反向提交应用及页面接线；已发布版本和审计保留，通过撤回停止公开，不删除历史。
