# SPEC-E4 收益冻结可信时钟

2026-11-25 当前执行切片。依据功能排期第 27 项、开发 28 E4、D55/D56 及根指南资金守恒规则。

## 完成定义

- 收益冻结、释放与逐段结算使用本店数据库可信时间及持久证据，不以应用时钟或 SQLite 冒充生产时钟。
- 数据库断连、证据不完整、时间倒退或身份不一致时，保持原冻结和待核状态，不推定到期、不发收益、不显示已知零额。
- 证据关联门店、订单、结算主体和操作；重试复用原事实，重复任务不得重复入账。
- 不修改既有冻结时长、金额、退款承担、报单审核和锁序规则；流水、冻结及时钟证据不得被覆盖或删除。

## 非目标

不扩展资金组合，不开启正式资金开关，不裁定加购工资归月或退款分摊争议，不替代 M7 的真实 MySQL 并发与业务对账。

## 验证

聚焦冻结创建、到期前后、时钟故障、恢复重试、逐段结算及双店隔离；相邻钱包与结算回归；Django 检查和迁移一致性。真实 MySQL、Worker/Beat 与逐人流水对账单独登记。

## 回退

应用代码按切片反向提交；已发生冻结、流水及证据只通过补偿或前向修复处理，禁止篡改。
