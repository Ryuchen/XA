# 退押金收益解冻时点

退押金预览和后台实际退还共用 `deposit_clearance.clearance_evidence`。收益冻结释放任务先采集 `released_at`，之后获取锁并写入实际钱包解冻流水；两者可能跨越一段时间。结清回放现核对该冻结关联的真实 `EARNINGS_RELEASE` 流水、钱包、订单、金额和余额变化，并把流水创建时刻计入最后结清时刻。七天等待因此从实际解冻到账及其他相关业务结清的最晚时刻起算；在等待期间新增业务仍由既有实时资格计算重新确定起点。资金流水缺失或不一致时继续待核对，不推定到账。

本次没有修改订单、提现通知或前端，也没有执行测试、迁移或操作数据库。最终联调须在隔离环境覆盖冻结释放与事务排队跨时点、等待期间新增订单或售后、部分追回后的释放金额、重复预览及退还，以及流水缺失时的待核对。其他资金回放受限组合仍按现有门禁处理。
