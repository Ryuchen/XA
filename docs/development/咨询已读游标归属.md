# 咨询已读游标归属

老板、陪玩和已获授权的客服/主管标记咨询已读时，`through_id` 必须为当前会话内的真实消息编号；`0` 仍表示没有需要标记的消息。外部或已不存在的游标返回明确校验错误，不更新未读数。消息 ID 列表模式仍只更新当前会话内对应消息。

客服或主管回复同时提交 `read_through_id` 时，在本店会话锁和正文权限核验后、创建回复或保存上传图片之前核验游标；无效时不保存回复、不修改未读数。主管直接回复不会改变原接待客服，领取及转交权限沿用现有规则。共同校验同样用于独立已读接口，发送与已读使用会话锁串行化。

本次无新增结构迁移，未修改前端；按要求未运行测试或迁移。需在隔离环境联调有效与失效游标、主管代答、普通客服领取/转交竞争、图片回复、并发新消息和双店同编号。
