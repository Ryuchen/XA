# 零退款协商结案通知恢复

普通服务零退款协商、积分订单后续零退款协商及安全箱协商实际完成后，若同时开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 和默认关闭的 `ZERO_REFUND_CLOSURE_NOTICE_RECOVERY_ENABLED`，售后结案通知调度从本次售后周期中唯一的已执行零退款方案及执行事实识别收件人，在原业务事务中为老板和该方案受影响陪玩分别保存通知意图。启用后这组专属消息替代相同收件人的通用结案消息；没有唯一来源时继续原通用结案路径，不推测执行结果。

提交后独立投递，失败由逐店任务重试；同一结案事件和收件账号最多创建一条。投递核对原零退款执行记录、实际双方确认、原售后历史、老板订单周期及陪玩履约周期；来源不明、售后重开或账号重入时记录跳过。消息只说明协商无退款，不表示收益已到账。发生整单房间异议同步处理时，异议处理消息仍作为独立事实按房间异议通知规则发送；部分终止不会因本通知关闭异议。消息发送失败不回滚业务或资金，站内消息创建不代表客户端已收到。

此功能不改变协商计算、原场景开放门禁及房间计时。启用前须各店应用 `site_messages/0033_zerorefundclosurenotice` 及依赖，运行逐店 worker/beat。最终联调覆盖普通、积分和安全箱适用场景、单双陪及转单、受影响人与未受影响人、整单异议同步处理和部分终止、结案后重开、消息失败与并发恢复、账号重入、双店同号及业务事务回滚；正式注销保持关闭。本轮未运行检查、测试或迁移。
