# 平台初始化通行证配置

平台超级管理员可通过 `/api/admin/platform/store-management/<门店ID>/setup/provider-pass` 在门店首次营业前读取和保存本店通行证配置。GET 返回 `configuration`（四档 `products` 及 `no_pass_delay_seconds`）、`sales_enabled`、`sales_configured` 和配置 `version`；无显式销售选择时继续按既有默认启用，不擅自停用。

PUT 的字段固定为 `kind`、读取到的 `version` 和 `configuration`：

- `rules`：`configuration` 包含四档 `products`（每项 `tier`、`daily_price`、`delay_seconds`）和 `no_pass_delay_seconds`；复用门店现有完整档位、价格及延迟顺序校验。
- `no_pass_delay`：`configuration` 只包含整数 `delay_seconds`，复用无卡延迟不能短于各档通行证延迟的规则。
- `availability`：`configuration` 只包含布尔值 `enabled`；开启前须通过现有 `provider_pass` 配置确认，关闭仅暂停新购，不改变已购通行证期限和抢单权益。

保存使用本店通行证配置锁与版本比较，写入既有实际配置，并在门店侧及平台侧记录操作者和操作审计；平台接口仅允许有平台管理权限的超级管理员，且仅可修改处于首次开业配置中的门店。保存后仍须通过现有配置确认及开业核验，不自动开业或激活 License。控制库与门店库提交失败的既有不确定结果处理不变，需重新读取配置核对。

未运行测试或迁移。最终需在隔离环境联调平台及本店权限、并发修改、启用前确认、明确停用后无卡延迟确认、License 激活、首次开业，以及已购通行证在开关变化后继续有效。
