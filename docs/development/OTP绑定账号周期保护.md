# OTP 首次绑定的账号周期校验

老板、陪玩及后台继续使用现有账号密码登录策略：已绑定 OTP 时默认验证动态口令并允许切换短信，未绑定时使用短信；已绑定微信的快捷登录仍走真实微信身份验证。短信和微信服务未配置时沿用明确的不可用响应，不伪造验证码或授权结果。

已登录账号首次绑定 OTP 时，本店事务内重新核验账号和原密码；开启 `PROVIDER_LIFECYCLE_INTEGRATION_ENABLED` 时，还校验老板或陪玩请求所属业务周期及在店状态。绑定挑战指纹包含老板／陪玩的原周期，注销或退店后重入不能用旧周期挑战完成新周期绑定；店内后台账号沿用现有绑定方式。已绑定验证器不能通过此入口覆盖。绑定响应包括密钥、二维码或一次性恢复码时均返回 `Cache-Control: no-store`。

本次复用现有字段，无新增迁移。按要求未运行测试或迁移；需在隔离环境联调老板退店及陪玩注销与绑定竞争、旧挑战重放、各端密码+OTP、短信切换与未配置错误、双店隔离，以及真实微信/短信获得资质后的外部联调。
