# 普通转单跨付款保留段退款

普通转单加购退款实际扣减另一付款的陪玩收益时，该付款即使有待确认接替，也不再仅因被扣减的是该接替中已保留的履约段而拒绝执行。退款仍依据双方确认的逐付款、逐段承担计划和逐份额凭证执行；只对实际被扣减的付款中待确认方案生成失效事实，无关方案不改变。

退款、受影响接替失效、真实原路退款和资金版本/到账 RELEASE 在原事务中处理；既有已付段和收益流水不修改。计划或历史份额无法证明、资金不足及其他未接通能力仍由原规则阻止，后续重提必须按当前责任重新确认。

未运行测试或迁移。最终联调需覆盖双人各自承担、同一付款重复履约段、保留段与当前段分别扣减、多个待确认付款、失败回滚、共享到账释放及整单补资后的逐段结算。
