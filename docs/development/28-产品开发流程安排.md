## 3. 每 Epic 的 SDLC 步骤（S1–S7 实例化）

1. **S1 规格**：编排者与用户访谈补齐未决点（多选提问直至可写 spec）；产出 `SPEC-<Epic>.md`＝任务卡集合＋定义完成＋边界/异常清单＋引用 PRD 条目；未决项标【待确认】不得进入 S4（G1）。
2. **S2 设计**：设计子代理产出方案（数据/迁移/契约/锁序/权益键）；独立红队子代理（只读）复核边界与资金守恒；重大变更 G2 用户批准。
3. **S3 计划**：按 SPEC 拆垂直切片；独立 Epic 分配 worktree；文件所有权冻结表登记；.worktreeinclude 等价清单（.env.example、隔离配置）；依赖图与并行批次 G3 确认。
4. **S4 实现**：新会话/实现子代理从 SPEC 出发；资金/状态逻辑先 characterization/失败测试再实现（red-green）；schema 与组合类 high effort；任务卡含 "be ambitious" 范围声明（空/错/加载态、键盘/触控、边界）；小步提交 codex/ 分支。
5. **S5 验证**：检查阶梯（§5）逐层跑；评审子代理对 SPEC 逐条核对需求与边界测试（只报正确性缺口）；证据包＝命令＋输出＋对账；G5 资金/真实渠道验收用户认定。
6. **S6 发布**：G6 清单全绿＋用户授权＋手动触发；逐店灰度五步；资金事实只补偿不回滚。
7. **S7 反馈**：定时回归（cron）＋告警诊断→补偿提案→人工批准；度量回流（§9）。

## 4. 确定性强制清单（零例外，harness/CI 执行）

| 规则 | 机制 | 实现要点 |
| --- | --- | --- |
| 禁读/禁提交密钥 | deny 规则＋commit 扫描 | Read(.env*/secrets/**) deny；PostToolUse/commit hook secret 扫描，onFailure block |
| 已应用 migrations 禁改 | PreToolUse 保护＋CI | 编辑 migrations/ 历史文件 exit 2；新迁移仅 makemigrations 生成；CI migration check |
| 完成前类型＋测试必过 | Stop 等价钩子 | 脚本跑 typecheck＋受影响测试子集，失败 exit 2 送回继续；块上限防死循环 |
| 租户上下文/依赖方向 | CI 静态检查 | 业务禁 import console；orders/wallet 单向；关键写无上下文即失败（R1） |
| 权益绕过 | CI 静态检查 | 新增发放入口必须声明 entitlement 键（R3） |
| 生产部署/force push/清库 | deny＋人工门禁 | 分类器＋G6/G7；仓库配置检查不构成上线许可 |

其余为指南（AGENTS.md/路径规则/skills），允许模型判断；强制集保持 6 条，新增须证明"零例外"。

## 5. 检查与证据阶梯

1. **prompt 级**：任务卡写明"跑 X 测试直到绿"＋单测命令（`manage.py test <app>.<module> --settings=config.test_settings`、`pnpm vitest run <file>` 等价入口）。
2. **goal 级**：长后台运行设 goal 条件（子集绿＋lint 净），每轮独立检查。
3. **Stop 级**：§4 钩子强制 typecheck＋子集＋migration check。
4. **独立评审级**：read-only 子代理对 SPEC（§10 prompt），只报正确性缺口。
5. **CI 级**：三 job＋§4 静态检查＋覆盖率门禁（R2 后）。
证据要求：命令＋输出摘要＋资金对账（资金类）＋未覆盖边界声明；"测试通过"四字不构成证据。

## 6. 并行与无人值守

- **worktree 并行**：E3/E5/E9 等无文件交集 Epic 各自 worktree；所有权冻结表防碰撞；合并前 CI＋评审。
- **无人值守五问表**（每波次运行前填写）：①done＝SPEC 定义完成＋检查阶梯绿；②自检＝Stop 钩子＋goal；③可触＝worktree＋deny＋所有权表；④上限＝--max-turns/预算；⑤签退＝PR＋G 门禁人工批准。
- **headless 批量**：机械迁移/改名类用 `-p`＋--allowedTools＋dontAsk＋OK/FAIL 回报；先 3 个样本验证再放量。
- **定时回归**：cron  nightly 全量隔离回归＋链接/残留扫描；红即诊断提案，不自动改生产。

## 8. 上下文工程

- AGENTS.md 保持短（现行 11 章）；只留看不到的决定/命令/陷阱；重复被忽略的线移入 hook。
- 路径作用域规则：`services/backend/**` 资金/锁序/迁移规则；`fronted/**` 契约/状态结构规则（前端团队所有，仅约定接口）。
- skills：发布流程（disable-model-invocation 等价＝仅人工触发）、事故补偿 runbook、隔离联调准备；按需加载不占常驻上下文。
- SPEC 文件为评审锚点；会话间以 SPEC＋dev/16 为准，不依赖会话记忆。

## 9. 度量与回退

切片前置时间/一次通过率/证据覆盖率/返工率/人类干预次数/待核验积压/缺陷逃逸（红线 0）；每波次末汇总。回退：切片独立 revert；资金事实只补偿；波次门禁红即停，不跨波次带病推进。

## 10. 模板

**SPEC-<Epic>.md**：背景与 PRD 引用／定义完成（可执行检查列表）／需求逐条（含空/错/加载态与边界）／非目标／迁移与开关／验收证据要求／待确认项。

**评审 prompt**：`你是未参与实现的评审者。对照 SPEC-<Epic>.md 逐条核对变更：每条需求是否实现、列出的边界是否有测试；只报影响正确性的缺口，跳过风格；输出缺口清单＋证据引用。`（子代理 tools 仅 Read/Grep/Glob）
