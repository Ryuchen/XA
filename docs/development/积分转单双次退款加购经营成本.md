# 积分转单双次退款加购经营成本

经营 ROI 的积分转单双陪两次主单退款分支，现可读取已有加购付款、退款和接替的真实资金版本。报表先核验两轮主单退款、共享补资及最终逐段结算，再复用加购逐笔付款来源、退款和接替事实与最终清单的校验：主单和加购原收益分别归各自付款期间，逐次承担和赠送／赔付退回归对应退款期间，接替产生的收益变化归确认期间。推荐佣金沿用已发放事实及实际付款时的净实付规则，补资不计营业收入；续单奖励继续走独立真实流水成本。

仅当现有两次主单退款范围、最终结算清单及全部加购历史可以被既有核验链证明时计算；未完成结算、资金版本缺失、时间不能区分、重复份额或其他核验未支持的组合仍显示待核对。收入及积分返回仍使用独立的真实流水归集，跨期间凭证不一致仍受既有核对限制。

未运行测试或迁移。最终须在隔离环境联调多加购和多笔退款、两轮退款前后接替、逐段收益及本金／赠送／赔付、已发推荐佣金与续单奖、共享到账、查询不同月份、重复请求、回滚和多店隔离。
