# 积分双陪预约售后退款

双陪预约双方确认并转为积分服务订单后，未发生服务前改派或服务中转单的首次协商部分退款，按现有积分退款正式范围处理。现覆盖既有受控加购资金链可核验的已付款加购：预览与执行合并主单和加购的真实付款、退款、陪玩收益及整单补资，补资不足或凭证不一致时不执行。老板和售后范围内的受影响陪玩各自确认，另一位陪玩不因同单而需要同意；退款执行继续核对原店币本金、赠送、赔付、积分抵扣及实际退款凭证，按原有资金规则处理承担和补资释放。

退款预览和执行核验预约老板、服务、转单状态和时间、两席本人确认事件以及订单实际席位；正式退款及退款后逐人结算再次核对同一预约事实。付款与补资、已确认方案、流水和后续各人结算仍由原有路径核验。事实缺失或不一致时保留待核对，不能据预约记录推断资金到账。

首次退款后的另一陪玩追加协商及退款后逐人结算，继续使用现有双陪后续退款及资金版本链，并在退款及结算业务上下文中再次核验原预约。能力继续受默认关闭的 `SERVICE_POINTS_MYSQL_ENABLED` 及既有协商、结算、补资和账号生命周期等门禁约束；本次未新增迁移。服务前改派、服务中转单、其他资金模型及当前既有门禁未覆盖的加购组合不因此开放。未运行测试或迁移；上线前须在隔离环境联调双陪预约实际付款、主单及加购付款和退款先后、任一人受影响的确认与拒绝、部分退款来源及积分、补资释放、追加退款、另一人和本人逐人结算、重试、双店隔离、并发及失败回滚。
