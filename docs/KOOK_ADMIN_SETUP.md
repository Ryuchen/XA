## 操作步骤

1. 打开“订单管理 → 派单管理”，点击右上角“配置”。账号需要“查看频道与文案”或“配置机器人、频道与文案”权限才能看到配置按钮；编辑与测试需要后者，在“权限系统 → 职位权限管理”分配其他客服的权限。
2. Token 已保存时不用重复填写。更换时输入 Bot Token 本身，不加 `Bot ` 前缀。清除 Token 前先关闭总开关。
3. 点击“编辑文案”，设置文字频道 ID、可选服务器 ID、游戏、玩法、平台、提醒身份组 ID，以及文案。用“预览文案”检查，再点击“应用到配置”。
4. 点击“保存配置”。规则按顺序匹配，订单只投递到第一条命中的启用规则。分类规则放前面，“全部订单”兜底放最后；未命中不发送。
5. “校验频道”确认频道 ID、服务器及文字类型，不证明发送权限。“发送测试”会确认目标后发送标明测试的卡片，不创建订单、资金流水或提醒身份组。测试记录显示 KOOK 消息 ID 或错误。
6. 开启“KOOK 派单”，按需勾选“新订单待接单”“拒单回池”，再保存。已支付、未过期、未指定陪玩、单陪的待接订单自动发送；礼物、双陪和已指派订单不广播。
7. 手工发送：进入“派单管理”，找到待接单订单，打开“一键发单”，选择“KOOK 频道文案”查看频道和实际文案，再勾选 KOOK 发送。关闭自动新单/拒单开关仍可手工发送；关闭总开关则停止 KOOK 投递。
8. 陪玩点击卡片“打开陪玩端接单”，登录陪玩端后按资格抢单。链接不代替后端的状态、资格及并发校验。

保存后，后续入队订单立即读取数据库新规则，Web 与 Worker 无需重启。已入队的文案、角色提醒和链接保留快照；目标频道、匹配规则或启用状态改变时，旧任务停止发送并标记失败，客服检查后可手工重试。

## 文案示例

```text
兴安电竞 · {trigger}
订单号：{order_no}
服务：{service_name}
平台 / 难度：{platform} / {security_level}
区服：{game_region}
数量：{game_rounds} {price_unit}
打手实得：{provider_income} 兴安币（¥{provider_income_yuan}）
履约要求：{gameplay_requirements}
请在陪玩端查看实时订单状态后接单。
```

必须保留 `{order_no}`、`{provider_income}`。其他变量还有 `{escort_mode}`、`{gameplay_name}`，后台可点击插入。大小写必须一致；普通花括号写成 `{{`、`}}`。不提供老板实付、原价、抽成、手机号、账号 UID 或内部备注变量。文案最多 1200 字，保存前检查展开后的 2000 字预算。

金额来自订单冻结的打手实得。例如内部 `provider_income=6400` 展示 640 兴安币 / ¥64.00，不把老板支付金额当作打手收入。

## 状态与排查

| 状态 | 操作 |
| --- | --- |
| 未配置 / 无匹配规则 | 核对 Token、总开关、启用规则及匹配条件 |
| 已入队 / 发送中 | 等待 Worker，不重复操作 |
| 已发送 | 同一订单待接单轮次不重复发送 |
| 发送失败 | 明确被拒绝或未入队；调整权限/配置后可手工重试 |
| 结果待核对 | 先核对频道消息，不自动重发 |
| 已跳过 | 订单已接单、取消、过期或进入新轮次 |

频道详情与列表可能要求不同权限。填写服务器 ID 后，详情接口 403 时尝试已授权的文字频道列表确认元数据；发送权限最终由测试卡片验证。机器人须加入目标服务器，能查看文字频道并发送消息；提醒身份组还需正确角色 ID 与提及权限。

网络失败时保留测试请求 ID，重试只核对原记录。KOOK nonce 仅回传，不是平台去重键；本系统以数据库记录防重复，不承诺跨平台端到端恰好一次。

## 配置与密钥

后台数据库配置优先于旧 `KOOK_*` 环境变量。没有后台记录的旧部署才使用环境变量；腾讯云旧的 `KOOK_ENABLED=false` 不覆盖已保存并启用的后台配置。

Token 密文依赖服务器 Django SECRET_KEY。密钥更换时需保留 SECRET_KEY_FALLBACKS 或重新输入 Token。数据库备份包含密文；配置及密钥仍保存在受限服务器配置和备份中，不能公开分享整个备份。
