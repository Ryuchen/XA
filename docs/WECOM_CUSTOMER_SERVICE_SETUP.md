## 三处配置

1. 企业微信 / 微信客服后台：创建客服账号，为该账号分配接待人员，从接入方式复制客服链接。接待人员使用企业微信「工作台 → 微信客服」接待、回复；可按实际需要设置接待时间和欢迎语。
2. 微信公众平台：在正式小程序的「客服 → 微信客服」相关入口绑定上述企业 ID。菜单位置或主体权限提示以平台实际页面为准。旧测试号的配置不会证明新 AppID 已绑定；须确认新账号实际显示“已绑定”。
3. [系统后台 → 客服消息 → 客服工作台 → 客服名片](https://admin.xaesports.club/support-cards)：填名称、企业 ID、微信客服链接，启用名片并保存。此接入不需要企业 Secret、AgentID、回调 Token 或 EncodingAESKey。

默认客服取排序最小的启用名片，同一排序时取最近更新的名片。订单咨询优先使用该订单负责客服的名片；原客服停用后回到默认客服。更新名片后，用户重新进入客服页或下拉刷新即读取新配置，不用重启后端或重新上传小程序。

后台“参数已配置”仅表示企业 ID、链接均已填写，不代替微信平台绑定或真实接待验证。

## 小程序使用

- 首页或「我的 → 客服与帮助」：先进入标题“联系客服”的客服页，再点击“打开企业微信客服”。未登录的用户也能咨询登录、绑定问题。
- 钱包充值入口：进入充值咨询，消息卡片标题包含充值咨询主题。
- 订单详情的联系客服入口：使用订单负责客服，显示咨询编号和订单号；可点击“复制给客服”，发送给接待人员核对。
- 打开会话时提供小程序消息卡片标题和页面路径；是否发送卡片由用户在微信会话中操作。服务端仍校验订单归属，不因为分享路径而开放其他账号的订单。

企业微信会话由企业微信工作台接待；客服页的“平台客服会话 → 进入会话”连接本站后台“消息与客服”，支持系统内文字与图片咨询。客服页仅保留这两类会话入口，企业微信会话不会同步到本站。

客服核实充值或订单问题后，在管理后台办理对应业务；聊天消息不会自动给钱包入账，也不会自动改变订单状态。

## 手机验收

使用有开发/体验权限的微信扫描本轮预览二维码，打开客服入口。确认显示正确客服账号，发一条测试咨询，请已分配的企业微信接待人员回复。然后检查充值入口和订单咨询的咨询编号、订单号是否正确。

模拟器可验证配置加载、页面、SDK 参数与失败分支；真正打开微信客服及接待回复以手机和接待人员反馈为准。新版上传保持开发/体验版，不自动提审或发布。

## 无法打开时

1. 核对小程序所绑定的企业 ID 与后台名片一致。
2. 完整复制微信客服生成的 `https://work.weixin.qq.com/kfid/...` 链接，不能用客服账号 ID、成员个人二维码或企业微信应用 URL 代替。
3. 核对该客服账号的接待人员、接待状态和平台权限提示。
4. 更新微信后用手机测试；不支持该能力或打开失败时可使用客服页下方平台客服。
5. 开发预览版打开失败时显示“开发预览诊断”，返回页面刷新仍保留本次错误；下拉刷新或重试会清除。正式版只显示用户提示。页面导航失败会弹窗，开发预览版展示微信返回的导航原因。
