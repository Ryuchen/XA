# 管理后台、服务后端和微信小程序更新 · 2026-10-08

管理后台与服务后端已上线 `2026.10.8.1`，微信小程序同版本已通过官方开发者工具上传为开发版。

## 本次功能

- 老板端陪玩列表和服务挑选页接入实时陪玩数据，使用一行两个的头像卡片。
- 卡片简化信息，隐藏通行证等级，以本月接单额替代评价；本月按上海时区自然月统计。
- 服务挑选先展示四个配置推荐位，再展示与推荐位去重的近 30 天接单额前四名，剩余陪玩按实际陪玩等级排序。
- 点击卡片进入独立陪玩详情，支持语音、赠礼和选择陪玩；从服务下单流程进入时，详情选择结果回传到下单页。
- 新增陪玩详情接口 `/api/users/escorts/<account_id>/`。
