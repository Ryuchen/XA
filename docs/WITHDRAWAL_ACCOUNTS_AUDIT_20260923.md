# 提现账户保存与申请隔离验收（2026-09-23）

用户确认规则：微信、支付宝、银行卡各保存一个收款账户。陪玩可自行绑定、修改、解绑；已提交提现申请保留原收款资料。

## 实现

- 新增 `WithdrawalAccount`，按 `ClubAccount + payee_method` 唯一保存。仅登录的陪玩可访问本人账户，客户端不能指定其他所有者。
- 陪玩 H5 钱包提供“管理账户”入口，零余额也可管理。账户页手机竖排、桌面三列；列表展示掩码，编辑及提现确认展示完整资料。
- 同方式保存会更新原行并递增版本。新建、编辑和解绑先锁定本人钱包，再锁定目标收款记录，与提现申请采用相同顺序；操作携带 ID 与版本，防止过期页面覆盖以及解绑重绑后的旧请求覆盖。
- 提现先校验本人绑定记录及版本，再进行资金冻结。失效返回 `PAYEE_CHANGED`，不会产生提现申请、资金变动或占用幂等编号。
- `WithdrawRequest` 独立复制收款方式、账号和姓名，不使用实时关联字段。账户变更不会改写历史申请；已成功提现的回执仍可在账户修改或删除后恢复。
- 为旧客户端保留原手填收款资料协议；当前 H5 使用绑定 ID/版本。绑定方式和手填字段不能在同一申请中混用。

## 接口

均位于 `/api/wallet/`，业务状态使用响应中的 `code`。

| 方法与路径 | 用途 |
| --- | --- |
| `GET withdraw-accounts/` | 本人的绑定列表，返回 ID、方式、账号、姓名、版本、修改时间 |
| `PUT withdraw-accounts/WECHAT/` | 新增或修改指定方式；另支持 `ALIPAY`、`BANK` |
| `DELETE withdraw-accounts/WECHAT/` | 解绑本人指定方式 |
| `POST withdraw/` | 使用绑定资料申请提现 |

首次绑定：

```json
{"payee_account":"example_account","payee_name":"测试收款人","expected_id":0,"expected_version":0}
```

修改时 `expected_id`、`expected_version` 使用最新 GET 返回的值。解绑仅传这两个值。记录或版本不匹配返回 `code:409,errorCode:"PAYEE_CHANGED"`，前端保留编辑内容并要求载入最新资料。

提现载荷中的绑定部分：

```json
{"withdrawal_account_id":123,"expected_payee_version":2}
```

还需按既有协议提交整数账务单位金额、请求编号和已确认试算值。绑定失效时返回 `code:400,errorCode:"PAYEE_CHANGED"`。既有税率/金额校验及资金成功回执协议继续有效。

## 边界

绑定只保存收款资料，不代表微信/支付宝/银行渠道认证，不触发实际打款。本次只使用本地专用测试账户与虚构收款资料，没有生产转账或外部渠道投递。正式平台与服务器联合验收仍按 [当前 PRD](PRD_CURRENT.md) 的剩余条件执行。
