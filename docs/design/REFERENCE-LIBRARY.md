## 后续使用流程

1. 先确认页面角色、业务动作、数据来源和当前实现；读取根目录 DESIGN.md、系统标准、前端基线及对应 PRD。
2. 从参考库挑选与问题有关的具体章节，记录文件路径、提交版本和适用页面。需要的是表格或异常交互时，先核实参考是否真的覆盖这些场景。
3. 写出“借鉴模式 → 本地 token/组件 → 业务约束 → 验收证据”。对现有组件优先补齐共用变体，避免复制整页样式。
4. 用本地完整业务状态验证：加载、空、首次失败、刷新失败、提交中、成功、失败和结果未知；覆盖目标视口、深浅色、键盘与触屏。
5. 在交付记录中区分标准已记录、页面已实施、浏览器已验证及后端待对接。上游更新只触发重新评估，不自动改变已确认基线。

新增选用记录至少包含：日期、来源/版本、涉及模块与页面、采用点、排除项、共享组件/样式位置、验证结果及未覆盖项。
