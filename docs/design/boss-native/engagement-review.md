# 老板端会员运营视觉复核

日期：2026-09-23。模式：保留品牌的整体演进。面向俱乐部老板，在微信原生组件约束下，使用浅色底、玫粉强调、稳定的移动端布局。设计差异 4/10、动效 2/10、密度 5/10；只保留必要轮播和抽奖反馈。

借鉴 design-taste-frontend 的审查与一致性方法。该技能的 Web 布局模板不直接用于原生小程序，采用现有 WXSS 设计变量、Page/Component 结构和微信安全区。

## 审查与保留

- 保留品牌粉色 #b83d68、页面底 #faf7f9、白色内容面、28rpx 标准圆角及系统中文字体。
- 保留首页/服务/订单/消息/我的五个主导航、历史分享路由、订单动作、微信登录与金额单位。
- 原有页面可用；新增页面存在局部样式被全局按钮默认值覆盖、横向筛选换行裁切、长礼物名称撑高、海报抢占首页的问题。

## 已调整

- 首页：喜报压缩到单条可读高度，公告文本正确占据剩余宽度；活动仅保留一行入口，权益卡片使用小缩略图。
- 入场：两页海报弹窗，先近期活动后下单须知，固定操作区，图片可滚动/放大；VIP 海报仅在权益区。
- 活动：时间倒序的简洁列表，详情去除重复标题/文案，仅显示海报。
- 礼物：15 个透明主体、同列一致尺寸，去掉卡片上重复的中秋前缀；三列展示，底部金额/赠送按钮适配安全区。
- 积分：横向不换行的分类，清楚的分栏状态和数量；缺图商品使用现有图标族的类别占位，不冒充实际商品照片。
- 转盘：修复方形中心按钮和文字挤在一行，恢复圆形、双行居中；概率未配时明确关闭。
- 会员：累计充值、下一等级差额及进度；个人中心头像、身份和标签放入完整名片。
- 全局：补齐弹窗/礼物底栏的原生按钮重置；单行输入框移除纵向内边距，防止文字靠底。

官方编译器 47 WXML、48 WXSS 全部通过；28 个原生交互检查通过。开发者工具实际访问与截图覆盖首页、活动、服务、礼物、积分、转盘、会员、我的，以及陪玩、订单、消息、钱包、优惠券、个人资料、签到和客服。
