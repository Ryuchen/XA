# 已建立实时连接的权限变更验收

日期：2026-09-23。范围为本地 WSL 部署的 HTTP / WebSocket 登录态、账号封禁、后台成员停用及权限变更；不包含真实 KOOK、企业微信或腾讯云验收。

## 问题与修复

旧连接持有建连时的账户对象及已缓存的后台成员关系，后续封禁或停用没有可靠影响已建立连接；访问令牌到期也只在握手时检查。另有后台成员停用后刷新令牌仍成功、身份切换后旧访问令牌仍可使用的问题。

现在 HTTP、刷新令牌和实时连接统一校验当前业务账户身份。实时连接在每次心跳和订单/客服消息推送前重新读取账户资格，失效后关闭连接（4401），不再发送业务载荷；后台成员关系同样重新读取。仅移除 `order:view` 时停止订单推送，其他仍有权限的功能及心跳保留。

后台资料与刷新接口在后台资格失效时返回实际 HTTP 401，使已有客户端会话恢复逻辑能清除失效登录态。正常访问令牌到期后仍可凭有效刷新令牌重新获取访问令牌并建连。带有异常账户 ID 的已签名令牌被拒绝；非对象 JSON 帧被忽略，二进制和超长文本帧按协议关闭。

实现入口：`club_accounts/tokens.py`、`authentication.py`、`channels_middleware.py`，`console/auth.py`，`orders/consumers.py`。本次不需要数据库迁移，也没有更改资金或订单状态规则。

## 适用边界

- 权限失效在下一次心跳或业务推送前生效。正常客户端心跳间隔为 25 秒；后台挂起、无心跳且无推送的静默连接不会靠本次修复主动定时断开。
- 已经发送或被用户保存的内容不能撤回。本次没有增加退出登录或修改密码后的全局 JWT 撤销机制。
- 实际验证运行了真实 HTTP / WebSocket 与客户端 HTTP 会话源代码；本轮没有新增浏览器界面或手机真机自动退出的端到端验收。
- 修复后已追加同一场景的本地容量复验 `3b529e54eeef`：100 老板、60 陪玩，2,936 请求零错误，p95 730 ms，160 条连接及测试退币账务核对通过。它是约 65 秒的本地闭环负载，云端持续负载及外部平台仍需独立验收，见 [容量记录](LOCAL_CAPACITY_VALIDATION.md)。
