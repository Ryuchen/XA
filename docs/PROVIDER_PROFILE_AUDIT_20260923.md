# 陪玩资料与老板选人联动核对 · 2026-09-23

本轮落实用户确认的价格口径：老板按后台陪玩档案中的 `price_per_hour` 选人，界面明确标注参考时价。套餐下单继续由服务端报价，不将陪玩时价作为订单金额。

## 本轮修改

- 原生老板端：参考时价区间（兴安币/小时，含边界，最多一位小数）、升降序、语音筛选与搜索组合使用；输入错误显示提示，重置保留当前服务/游戏。默认排序保持后端顺序。未配置与显式 0 时价分别处理。切换筛选后若当前陪玩不可见，停止试听。
- 陪玩 H5：替换浏览器不支持的 `Taro.chooseMessageFile` 调用，使用文件选择器及保留原始文件名的上传；请求结束释放临时 URL。支持语音试听、更换和移除，保留正在编辑的其他资料。
- 后端：文字类型、图片、文件大小、语音扩展名、技能 ID 完整校验后统一提交，防止参数无效时部分更新或意外清空技能；头像同步业务账号和历史用户，老板列表即时可读。认证、等级、时价等继续仅由后台维护。
- 档期文案与实际规则对齐：未配置时不限时，暂停接单切换离线。资料/档期读取失败进入重试界面，避免空表单覆盖原数据。
- 资料页修复深色模式卡片文字对比度和隐藏文件控件外露，语音操作支持小屏换行。
