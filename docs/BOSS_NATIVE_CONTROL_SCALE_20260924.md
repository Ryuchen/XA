# 老板端控件尺寸收紧

本轮针对“按钮和输入框普遍偏大”继续调整，取代上一轮统一 44px 控件的做法。保持原有品牌、页面流转、业务事件及表单字段，按操作层级分配不同尺寸。

## 当前尺寸

| 控件 | 上一轮 | 本轮 |
| --- | --- | --- |
| 主操作按钮 | 44px 起 | 40px |
| 普通输入框 | 44px 起 | 38px |
| 次要按钮 | 44px 起 | 36px |
| 筛选与数量按钮 | 36px | 30px |
| 主要控件文字 | 14px 起 | 14px 起 |
| 紧凑控件文字 | 12px 起 | 12px 起 |

页面布局继续通过 rpx 适配屏幕；控件、字号及常规图标使用固定 px，避免大屏将其进一步放大。单独调整局部内边距，避免内容和 padding 把控件重新撑大。

## 重点修正

- 首页搜索操作改为轻量文字按钮，快捷图标底座由 72rpx 缩为 64rpx，图形由 40rpx 档改为 36rpx 档。
- 陪玩试听由竖排方块改为图标与文字横排，列表底部操作降低视觉重量。
- 赠礼、商城、订单、结算及个人资料等页面同步收紧输入、筛选、按钮和底部操作栏。
- 聊天改为输入框、图片操作与发送按钮同一行；输入从 38px 起步，多行最高 110px，清空后恢复。
- 底部原生导航保留原有点击范围；官方 Tabler 图形改为 60px 居中置于 72px 画布，描边从 2 改为 1.75。原始 SVG 与许可证缓存在 `scripts/icon-sources/tabler/v3.31.0`。
- 原生输入和多行文本继承页面字体，统一占位文字样式。

## 核验

微信官方编译器通过 48 个 WXML 模板、49 个 WXSS 样式；结构检查覆盖 47 个页面。原生核心 32 项回归通过，包含模板事件绑定、礼物累计与页面流转。

截图与测量使用微信开发者工具。截图中的昵称、余额、礼物冠名天数等为内存演示数据，没有写入数据库、支付或发送消息；生产礼物时长仍由后台逐款配置。

对比预览：`docs/design/boss-controls/index.html`。控件实测：同目录 `layout-metrics.json`；数量与页面交互检查：`interaction-checks.json`。本轮未发布小程序版本。
