# XA 三端视觉规范

更新：2026-10-13。用户指定附件《中国传统色卡》蓝色色系，替代此前系统蓝、克莱因蓝与奶白配色。正式入口为老板原生微信小程序、陪玩 H5、Vue 管理后台；历史老板 Taro 页面兼容同一主题。

## 颜色与来源

色值取自用户上传图片的各色块内部像素。图片可能经过压缩，以下数值是本项目的采样值，并非印刷色标准。

| 色卡名称 | 采样色 | 项目用途 |
| --- | --- | --- |
| 远天蓝 | `#CFDDE4` | 边框、浅蓝层级的原色 |
| 潮水蓝 | `#ACD0E1` | 次级品牌色、深色主题亮色 |
| 秋波蓝 | `#88BCCF` | 品牌浅色、深色主题操作色 |
| 宝石蓝 | `#2684B6` | 品牌过渡色 |
| 搪瓷蓝 | `#136398` | 主操作、选中态、金额、链接 |
| 品蓝 | `#003B72` | 主操作悬停、强调层级 |
| 洒蓝 | `#1F3D7C` | 深色面板、图表和封面层级 |
| 宝蓝 | `#1D296E` | 深品牌层级 |
| 海青 | `#050D3F` | 主文字、深色品牌层级 |
| 海军蓝 | `#336B9A` | 辅助文字 |

页面背景 `#F1F6F9`、柔和强调底 `#EDF3F6`、次级表面 `#F5F8FA` 是远天蓝与白色混合形成的浅色。卡片使用白色。成功、警告、错误保留语义色及文字标识，避免只依靠颜色表达状态。

主色和辅助文字与白色的对比度均超过 4.5:1。金额默认使用品牌蓝色，人民币核对与兴安币展示保留各自单位。

## 主题实现

- 颜色唯一来源：`packages/design-system/src/_theme.scss` 的 `light` / `dark`。旧 `klein-milk` 入口仅为共享浅色主题的兼容别名。
- 原生主题：`node scripts/sync-native-theme.mjs` 从共享 `light` 生成 `native/theme.wxss` 和微信导航/Tab 色值。`--check` 验证同步，样式检查已包含该项。
- 原生页面使用 `--xa-color-*`；微信组件 `color` 属性和 JSON 需要具体色值。Tab 与页面图标由 `create-native-icons.cjs` 读取已同步导航色生成。
- 后台用 Element Plus 标准组件，以语义 token 映射外观；陪玩 H5 消费共享浅色主题。业务页面不得再次覆盖整套品牌颜色。

## 控件与间距

| 端 | 控件与排布 |
| --- | --- |
| 老板原生端 | 保留已有紧凑比例：主按钮 40px、输入 38px、次按钮 36px、筛选 30px；陪玩目录双列筛选 44px。主字号 14px，辅助字号至少 12px。相邻独立操作留 8px，短按钮不被长文字挤压。 |
| 陪玩 H5 | 正文字号 14px，手机主要输入和交互目标至少 44px，桌面紧凑尺寸按现有布局保留。报单订单选择采用可滚动、可搜索弹窗，三类截图与操作依次排列。 |
| 管理后台 | 保留现有 small 32px 控件密度；筛选区间距 12px，表单标签和控件上下分组，弹窗正文独立滚动、底部操作可见。窄屏工具栏和表格操作换行。 |

移动页面边距以 24–32rpx 为基准，区块间隔 24rpx，内部分组采用 16 / 24 / 32rpx。尺寸按端和功能适配，桌面表格保留合理密度。

老板端 30–40px 紧凑操作延续已有视觉方案，是 44px 通用触控建议的已知例外；保持相邻间距，密集长标签允许换行。固定底栏适配安全区并给正文留足空间。

原生小程序所有页面保留「首页、陪玩、订单、消息、我的」底部导航。五个主页面使用原生 Tab，其他页面使用共享 `bottom-navigation` 组件，并在正文后预留同等高度。导航为 56px 加底部安全区；下单、服务详情、送礼、陪玩详情的操作栏位于导航上方，聊天视口扣除导航高度。新增子页面须在条件内容外挂载该组件，避免登录、加载或报错时导航消失。

服务收藏选中态使用 `--xa-color-favorite` 红色爱心及 `--xa-color-favorite-soft` 粉色衬底。成功切换时播放轻微心形缩放，进入页面或刷新时直接展示当前状态；减少动画模式关闭过渡和缩放。

各页沿用首页的浅色页面背景和白色圆角区块：标题使用 `page-heading`，筛选、说明和独立操作使用 `section-surface`，已有 `panel` / `card` 保留。区块内边距和间距以 24rpx 为基准，浅色仅用于卡片内的筛选、状态和分隔层级。

紧凑列表采用较小间距：陪玩目录和挑选页共用两列卡片，头像高 164rpx，卡片内边距 12rpx / 16rpx，名称和金额 14px、辅助信息 12px。服务目录封面为 240×135rpx，右侧名称、关键标签、价格三行与封面同高，卡片内边距 16rpx；完整说明在详情中查看。长名称可省略，卡片无障碍标签保留完整名称和报价，需客服确认的项目保留可见标识。

## 交互验收

- 输入保留可见标签，错误显示在对应字段附近；失败不清空已填内容。
- 请求、上传、提交有反馈，防止连点重复操作；业务按钮可用性由服务端权限与状态确定。
- 加载、无数据、失败重试、登录失效分别显示；详情和账号切换丢弃旧响应。
- 保留键盘焦点、屏幕阅读器标签和减少动效偏好；卡片使用轻阴影、细边框和分组背景。
- 测量小屏和桌面无页面横向溢出；表格自身滚动可保留；表单操作区不被底栏遮挡。

本轮使用 ui-ux-pro-max 的触控间距、文字重排、对比度、表单和 Vue 布局指导。设计系统搜索的营销展示推荐不适合当前业务界面，未作为项目版式或配色依据；色系以用户附件为准。
