# XA 三端视觉规范

## 设计原则

- 三端统一采用 Apple System Blue `#007AFF`，成功、警告、错误分别采用 `#34C759`、`#FF9500`、`#FF3B30`。
- 页面背景使用 grouped background `#F2F2F7`，内容容器使用白色，主要文本 `#1D1D1F`。
- 移动端优先使用 Taro 原生跨端组件：`View`、`Text`、`Button`、`Input`、`Textarea`、`Picker`、`ScrollView`。
- 后台优先使用 Element Plus 标准组件，通过全局语义 token 统一外观，不在业务页面重复定义控件皮肤。
- 卡片主要依赖背景层级、细边框和轻阴影；避免霓虹色、重渐变、Emoji 导航和过度悬浮。
- 触控区域不小于 44px/88rpx；底部导航必须适配 `safe-area-inset-bottom`。
- 动效只表达状态：按压缩放约 0.97，普通过渡 150–250ms，不使用持续装饰动画。

## 移动端基础 Token

| 类型 | 取值 |
| --- | --- |
| 页面边距 | 32rpx |
| 小/中/大间距 | 16 / 24 / 32rpx |
| 输入框圆角 | 12–16rpx |
| 卡片圆角 | 24rpx |
| 大卡片/弹层圆角 | 32rpx |
| 正文 | 28rpx |
| 辅助文字 | 22–24rpx |
| 标题 | 32–40rpx，600–700 字重 |

## 组件组织规则

1. 页面只负责业务布局；色彩、圆角、阴影从 `styles/theme.scss` 和 `styles/variables.scss` 获取。
2. 一级操作使用实心系统蓝按钮；次级操作使用浅蓝底或文字按钮；破坏性操作使用系统红。
3. 状态使用浅色胶囊标签，不用高饱和大面积背景。
4. 列表优先采用原生分组列表结构：白色容器、行间细分割线、右侧操作或箭头。
5. 老板端和陪玩端底部导航保持相同高度、图标尺寸、激活背景和文字规则。
6. 后台表格、筛选器、对话框的皮肤统一放在 `apps/admin-web/src/styles/index.scss`。
