# 老板端原生小程序：分区与控件比例优化

本轮根据首页分区模糊、按钮与图标比例失衡的反馈，在现有玫瑰色品牌基础上调整原生 WXML/WXSS。功能入口、业务事件、订单与赠礼规则保持原有语义。

## 视觉调整

- 首页将标题与内容归入同一白色功能区，通过浅灰页面底色、24rpx 分区间隔和细边框区分内容；打卡、老板权益、礼物入口和俱乐部活动分别成组。
- 陪玩、消息、我的、商城、订单、服务详情、结算、签到与赠礼采用一致的标题、内部间距和辅助动作层级。
- 公告与自动播报仍分别展示；首页保留礼物入口，VIP 预存福利仍在会员页面。
- 登录、个人资料、账户安全、客服、聊天、试听、会员、优惠券、积分、抽奖、领奖、订单详情、钱包、榜单、收藏和内容列表同步检查控件尺寸。

## 统一控件尺度

定义位置：`apps/boss-miniapp/native/app.wxss`。

| 用途 | 尺度 |
| --- | --- |
| 主按钮、单行输入框 | `max(88rpx, 44px)` |
| 筛选与紧凑按钮 | `max(72rpx, 36px)` |
| 常规控件文字 | `max(28rpx, 14px)` |
| 紧凑控件文字 | `max(24rpx, 12px)` |
| 图标三档 | `max(32rpx, 16px)` / `max(36rpx, 18px)` / `max(40rpx, 20px)` |
| 卡片 / 控件圆角 | 24rpx / 16rpx |

图标底座、卡片插画和头像按各自用途保留独立比例。微信底部原生导航继续使用现有图标系统。礼物数量按钮采用较大的可点击区域和较小的可见底座；350px 以下礼物网格改为两列。聊天输入区从单行高度起步，并保留多行输入能力。

## 核验与预览

- 微信官方编译器：48 个 WXML 模板、49 个 WXSS 样式通过；结构检查覆盖 47 个页面。
- 原生核心回归：32 项通过，包含模板事件绑定、页面流转、礼物数量与冠名累计、公告/广播边界。
- 微信开发者工具实际截图核验首页、陪玩、消息、我的、礼物、商城、订单、详情、结算、签到，以及登录、资料、聊天、会员与领奖表单。
- 实际操作验证首页进入陪玩、陪玩筛选、礼物加减数量和空动态状态，未执行支付或业务写入。

前后对比与表单截图：`docs/design/boss-refinement/index.html`。测量记录：同目录 `layout-metrics.json`；交互检查：`interaction-checks.json`。
