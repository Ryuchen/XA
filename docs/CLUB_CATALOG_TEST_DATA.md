## 来源与边界

来源为本机“兴安电竞玩法”项目成品数据及 Obsidian“兴安电竞玩法设计库”。采用明确确认的最新日期版本，9 月 21 日四版价目和后续修订优先于历史试价。

已确认的手游趣味价格映射正常展示，迁移后的地图、保底和履约规则仍需客服确认。其他 108 个手游历史试价不出现在老板端。独立品牌“安心电竞”的价格未混入。

“趣味跳房子”“普通黄金矿工”只有封面而缺少可核实定价；“绝密对赌单”“兴安银行单”旧卡仍为模板。没有给这些项目编造售价，也没有创建 0 元商品。现行“物资对赌单”“物资银行单”已单独导入。“环太平洋·任务版”按更名后的“盲盒猜猜乐”维护。

183 个展示价目需要客服确认，包括资格／预约待核对、按实际履约结算及 26 个附加费用。附加费用不能脱离主订单购买；后端同时拦截直接报价和创建订单，且附加费用不会充当首页玩法起价。其余 281 项包含 275 个直接下单服务和 6 个订单赠礼项目。

VIP、充值赠送、活动优惠及动态结算在本次作为价目说明导入，没有自动发放余额、会员或权益。优惠叠加、领取口径及活动有效期由客服核对，活动商品通过客服确认入口展示。

## 重复导入

导入命令允许 `DEBUG=True` 的 SQLite 测试库，或设置 `XA_LOCAL_VALIDATION=true` 且数据库/账号均为 `xa_verify`、主机为 `db` 的专用 MySQL 容器，默认只检查。用 `catalog_key` 更新，不重复创建同一报价。携带素材目录时复用内容哈希命名的本地媒体；不携带时保留已有封面。

```powershell
$env:PYTHONPATH='G:\Github\XA\.tools;G:\Github\XA\services\backend'
.venv/Scripts/python.exe services/backend/manage.py seed_club_catalog --settings=local_run_settings
.venv/Scripts/python.exe services/backend/manage.py seed_club_catalog --settings=local_run_settings --apply --hide-legacy-demos --asset-root 'C:\Users\chenh\Documents\ChatGPT\兴安电竞玩法'
```

原有 34 条明确的本地演示商品已下架，仍保留订单引用。导入前备份：`.tools/catalog-backups/before-catalog-20260922-212002.sqlite3`。原有 3 个订单、8 个钱包的金额和 2 条流水未改变。接口读取时，系统把测试老板原有钱包补关联到其业务账户，未增加余额或流水。

2026-09-22 修正价目导入的人民币换算倍率，按原始 `price_yuan × 100` 覆盖本批572条价目，重复导入不会再次翻倍；后台导入会拒绝兑换比例不符的数据。修正前备份：`.tools/catalog-backups/before-currency-correction-20260922.sqlite3`。

服务目录仅在首次没有内容时展示加载状态；已有内容刷新时保留列表，数据与加载结束状态一次更新。
