## 横向版式、文案和状态验收清单

1. **金额与单位**：列头、详情、按钮、弹窗、错误、站内消息和历史结构化账单一致使用“浪花”；人民币仍写“元”或“人民币”，游戏专有的金币不误改。逐项核对零值、小数和最大可显示金额、负值/退款、长数字、“浪花/小时”换行及溢出；数字与真实接口及账务一致。
2. **状态**：报价与实付、可用与冻结、预计与入账、提交与成功、退款处理中与退款成功分别呈现。空、加载、失败、重试、无权限、请求结果未知与图片失败都有可执行反馈；不以旧截图或示例数据代替真实状态。
3. **品牌与图像**：标题、登录、导航、分享、活动、商品图、通知模板和无障碍名称逐项检查；已发现旧标识的位置必须有修改及运行证据。记录资源是否实际使用、原始路径、修改来源及历史留存；未读取到的动态图片列未覆盖。
4. **可读与交互**：文字颜色与深浅主题背景保持足够对比；焦点可见、图标含义有可访问名称或作为装饰隐藏；长名称换行不截断订单号、金额、错误和确认动作；触控目标保留足够空间，不依赖悬停。
5. **验收环境**：后台与陪玩页面由 WSL 打包容器提供，老板小程序连接同一隔离环境；截图前最大化微信开发者工具并确认完整 iPhone 12/13 (Pro)、390 × 844。分别记录环境、版本、角色、截图、真实/合成数据以及缺陷；图片/历史记录/外部平台未核验不能标通过。
