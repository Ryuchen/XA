## 最终行为

- 已结算、已完成且已支付的订单可申请售后，包括超过原 72 小时窗口、已确认实销的订单。已处理但未退款的售后可以重新申请，保留每轮原因、处理结果和请求标识。
- 具有 `order:refund` 权限的后台账号先核对服务端资金试算，再确认退款。老板按原实付全额退回钱包；按该单原始成功入账追回陪玩、推荐人及平台收益。

- 任一账户金额不足，整笔退款回滚，提示所需、可追回与缺额；不改老板余额、资金流水或售后状态。资金变化或试算过期须重新核对，旧试算不自动执行。
- 原结算快照、原流水保留，新增逐笔关联原流水的反向冲正。每单退款、每条原流水冲正均有唯一约束。成功后订单为 `CANCELLED / REFUNDED`，售后为 `REFUNDED`。
- 已确认实销通过关联退款的撤回记录排除出净实销；积分、相应未用权益和会员资格按服务端规则重算。已使用券及已完成交付保留历史，并在后台列明处理结果。

- 报单审核通过状态及原核定单钱保留作历史，退款后标注收益已冲回；净收益以实际钱包流水为准，避免把原审核快照误算为当前可提现金额。
