## 已核对的共享机制与易遗漏弹窗

- 老板原生 `components/state-view/index.wxml` 的 `loading` 分支**已经绘制骨架**，`error` 显示重试，`empty` 使用图片和文案；并非所有页面都传 `empty`。复用时要逐页读取传入条件，不把详情无记录、零余额或表单空输入当作列表空态。`components/info-sheet` 有打开、遮罩、关闭及“我知道了”状态；结算页使用该组件。
- 使用 `core/page.js::privatePage` 的页面在未登录时 `logged=false` 且 `loading=false`，不能把未登录画成骨架；切换账号会递增请求序号并清除页面数据，页面卸载后不应写回。真实账号切换、失效与慢响应场景仍须隔离设备验收，不能由该静态源码推断已通过。
- 原生 `core/ui.js` 的 `modal` 封装 `wx.showModal`，模板提取不能发现 JS 中的对话框。已直接检索 `pages/**/index.js`：结算页包含“请先核对上次订单”“核对或停止上次下单”“仍需核对上次订单”“确认余额支付/确认下单”“请核对订单结果”；订单详情包含选择陪玩、取消订单、取消原因和提交售后；礼物页包含待核对与确认赠送；签到页包含补签与全勤；预约详情包含取消、转单确认；积分兑换包含确认；聊天包含切换普通咨询与放弃核对；老板登录包含新账号确认；试音邀请包含切换账号确认；首页包含套餐资格和复制活动链接；交付详情使用原生“使用最新资料”确认。会员的“确认生日”展示所选日期及登记后修改需要客服核对，账号安全的“退出登录”确认说明钱包与订单保留。
- 上述静态 modal 只是**本次检索范围内**的发现。通过其他 helper、共享组件或动态返回的弹层、toast 及后续代码变化仍需核查；不要用数量替代逐页验收。

## 老板评价：原生页面与 API 的具体差异

这是依据源码的专项静态核对，不代表用户要求的低星自动售后已实现或已经测试。

- 老板订单详情 [index.wxml](../../apps/boss-miniapp/native/pages/order-detail/index.wxml) 第 71–77 行只显示一个“满意度”滑块，取值 1–5；双陪可切换评价对象。文本和匿名选项在同一评价区域。
- [index.js](../../apps/boss-miniapp/native/pages/order-detail/index.js) 第 133–155 行分别保存对象草稿，并在第 153 行向 `/orders/evaluate/` 提交 `order_id`、适用的陪玩身份、`score`、`content` 和 `is_anonymous`；当前原生页面**没有提交** `skill_score`、`attitude_score`、`communication_score` 三项独立评分。
- [CreateEvaluationSerializer](../../services/backend/orders/serializers.py) 第 1001–1016 行要求综合 `score` 为 1–5，另外三项可选、若提供也须在 1–5；任一维度未传时 `setdefault` 到本次综合 `score`。因此旧客户端只传综合 2 分时，API 将三个未传维度也填成 2 分，而不是一律填 5 分。
- [EvaluateOrderView](../../services/backend/orders/views.py) 第 1690–1727 行先验证订单与评价目标，在事务内锁订单、重查对象和重复评价，再将序列化结果落库。`Evaluation` 模型上三维字段的 `default=5` 是未显式赋值时的 ORM 默认，不能误当作上述 API 的旧客户端回填行为。
- 用户已确定综合、技术、态度、沟通任一项 1–2 星触发自动售后。当前原生画面只能独立选择综合分；若要让老板独立评价三项，产品与 UI/UX 须先设计输入和默认行为，研发需保留旧端回填兼容，并在七角色评审后以 WSL 容器实际测试低星、重复/并发和三端反馈。是否新增三项输入属于产品设计事项，不应由本次只读盘点自行修改。

### 老板下单结算

- **已核模板/客户端：** [checkout/index.js](../../apps/boss-miniapp/native/pages/checkout/index.js) 载入服务、本人资料、可用券、客服卡、已选陪玩及自主下单状态，分别请求 `/orders/services/{id}/`、`/users/me/`、`/coupons/mine/`、`/support/contact-cards/`、`/users/escorts/{id}/`、`/orders/traffic-status/`；报价使用 `/orders/quote/`。这些是客户端实际依赖，不表示容器接口已测通。
