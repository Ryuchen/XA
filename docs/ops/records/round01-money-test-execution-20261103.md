状态：测试准备，未执行。业务目标是将兴安电竞更名为声浪电竞、兴安币和单位简称统一为浪花；1 元人民币 = 10 浪花 = 100 内部账务单位，历史金额、余额、精度和换算保持不变。镜像和专用 WSL 隔离环境部署完成前不得运行功能测试。

## 两套测试数据

| 数据集 | 用途和运行环境 | 内容与证据边界 |
| --- | --- | --- |
| 真实业务场景数据 | 测试人员使用已打包并部署在本地 WSL 的专用容器，验证三端功能、数据和资金结果是否正确更新。 | 用合成账号、订单、钱包、凭证和流水，按已确认规则经过真实接口与真实业务代码产生数据，使用独立 MySQL、Redis、worker 和媒体目录。它是贴近真实场景的隔离数据，不是真实客户、生产账务或真实消息；不得将演示数据、直接伪造的成功结果、mock 核心业务或非容器运行结果充当功能验收。实际微信身份、外部支付与通知按接入情况另列覆盖范围。 |
| 研发本地单元测试数据 | 开发人员为快速反馈在本地运行独立单元测试。 | 使用合成输入、固定样本或局部替身，验证确定的函数、组件或边界条件；与业务验收数据库及容器数据完全分离，不加载生产配置。单元测试可以使用替身，但其结果只证明所测单元，不证明完整接口、真实数据库并发、跨端流程或打包产物通过。 |

场景数据应基于目前已确认业务而非虚构商业规则：至少覆盖老板余额充值和报价下单、公开接单与客服指派、履约报单审核、收益和提现，以及已有规则允许的取消与退款；针对本次更名，保留同一隔离账号及其迁移前后的历史余额和流水样本。为验证数值精度和边界，应包含零值、正数、非整数浪花对应的内部整数、余额不足、重复提交与退款等例子；所有金额和预期依据当前服务端规则确定。单元数据集中准备对同一换算输入和输出、文案及金额格式化的最小样本，不直接复用或写入业务验收数据。

业务场景数据建档需记录规则版本、身份与权限、初始余额、操作顺序、期望订单状态和账务结果，以及关联的测试案例；测试前确认数据库、媒体与 Redis 指向专用隔离项目。**真实业务场景合成数据跨迭代持续保留**，不得为每轮测试重建或删除场景库、其媒体和数据卷。迭代时以新增、可追溯的测试账号和案例为主；需要改变既有记录时先记录前后状态，避免污染历史结论。升级迁移前备份并核对可恢复性，成功后核对历史订单、钱包、凭证和关联记录。

并发、破坏性和 Django 回归可使用独立一次性测试库；其数据库名、容器、卷及清理范围必须与持续场景库区分并在操作前确认。本文件的 `test_xa_test_round01` 是一次性 Django 测试库，不是持续场景库。不得通过 `down -v`、全量重置、重新 seed 或其他清理操作删除持续业务验证数据。数据集完成与否、测试是否实际执行、以及测试结果分别记录，不把数据准备写成验收通过。


## 容器内金额业务回归

由测试人员在核实专用环境和镜像后运行：

```bash
bash deploy/round01-money-tests.sh /path/to/private/round01-state
```

脚本沿用该状态目录生成的随机 Compose 项目名，先调用隔离配置检查，验证运行中的 MySQL 容器属于该项目、服务名为 `db`、数据库及用户名是 `xa_round01`，且不暴露端口；随后仅在此容器中建立测试库权限，并在打包的后端 `web` 容器运行指定 Django 测试。测试库为 `test_xa_test_round01`，不是应用数据库。脚本不连接固定的旧验证项目或持久预览库，不打印数据库凭证。

该回归包括报价与余额扣款、退款及审核、资金回执幂等、真实订单收益后的提现领取与审核、资金边界和提现账户。报告须记录实际通过、失败与跳过，不将某几个标签等同于全系统验收。测试设置将 Redis、Channels 和 Celery 替换为内存，因此此脚本**不能证明**真实 Redis、WebSocket、worker、beat 或跨进程行为；这些另用运行中的隔离容器和真实客户端验证。历史自动化中启动宿主 ASGI 或使用微信宿主替身的用例不能直接计为容器端到端通过。

## 更名前后数据守恒

1. 使用同一个隔离 MySQL 中的合成数据，保留更名前镜像与迁移状态；先构造含余额、冻结、充值、订单、退款、收益和提现的固定样本，停止写入，记录基线、数据库和镜像身份。不得复制真实客户数据。
2. 同一库应用本次更名迁移，再读取同一组记录。核对内部金额及数量、余额、冻结、充值和流水数量、订单与退款、押金、收益、提现和汇率；不应因更名产生资金流水或余额变动。对迁移前不存在的数据和外部消息不作推断。
3. `scripts/fingerprint-finances.py` 可作为钱包、交易、提现和订单的只读摘要辅助工具，但字段覆盖有限，须补查押金、优惠、收益及其它受影响对象，不能仅凭哈希证明全部资金不变。新空库完成迁移也不能证明旧数据保持不变。
