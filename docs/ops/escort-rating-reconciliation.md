# 陪玩评分核对

陪玩评分由评价的综合分计算。新增或删除评价时会按当前评价记录重新汇总，避免多次四舍五入造成偏差。已有缓存不会在部署时自动全量修改。

在 `services/backend` 目录运行以下命令，先核对实际连接的数据库和结果：

```shell
python manage.py audit_escort_ratings --details
```

输出包含检查数量、缓存与评价记录不一致的数量、缓存有评价但找不到评价记录的数量，以及评价条数一致而平均分不一致的数量。`--details` 列出陪玩档案 ID 和缓存、实际的数量／分数。默认只读。

确认核对结果后，可执行：

```shell
python manage.py audit_escort_ratings --repair-averages --details
```

命令仅在缓存评价数与现有评价记录数一致时重算平均分；数量不一致的档案保留原值，需核查历史记录和账号归属。修复时逐条锁定档案并重新读取评价，以便与正在提交或删除的评价串行。完成后再次运行只读核对，查看剩余差异。
