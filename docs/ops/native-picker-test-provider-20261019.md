# 本地联调：服务挑选陪玩为空

2026-10-19，环境为 `XA_LOCAL_VALIDATION=true`、数据库 `xa_verify`。

## 原因

原生小程序的服务详情和确认订单页均进入 `/pages/companion-picker/index`，请求 `/api/users/escorts/?service_item=<id>&picker=1`。本地唯一满足认证、账号启用和展示条件的测试陪玩为 `local_provider`（账号 ID 10，展示名「本地体验陪玩」），但此前没有游戏、服务技能或分平台接单资格，因此按服务筛选后返回空数组。目录入口的展示正常，不能说明该陪玩已经具备具体服务的接单技能。

## 修复

仅给上述既有本地测试账号增加当前目录中可直接下单的 522 个服务技能，同步游戏类目；资格按这些项目已有要求的最高档配置：三角洲行动端游陪玩荣耀、手游陪玩传奇。咨询项目、附加项目和礼物不在此次授权范围。

保留现有服务技能、资格、账号状态、押金、档期、性别及并发校验。账号登录资料、订单、钱包、流水和优惠券数据的指纹在事务前后相同。

## 执行与恢复材料

- `.tools/native-picker-fix-20261019/configure-provider.py`：默认只读预检，`--apply` 才写入；同时校验本地环境、数据库名及测试账号身份。重复运行只补缺失项。
- `.tools/native-picker-fix-20261019/apply.sh`：先备份数据库，再执行上述事务。
- `.tools/native-picker-fix-20261019/before-local-provider-skills.sql`：修复前完整数据库备份。
- `.tools/native-picker-fix-20261019/before.json`：修复前该账号的技能、类目、资格和业务数据指纹。
- `.tools/native-picker-fix-20261019/applied.json`：本次新增 522 项技能、2 项资格的结果。

这些本地材料保存在被 Git 忽略的 `.tools` 下，供当前工作区复核和恢复使用。正式环境的陪玩应通过正常运营认证和技能配置流程开通。
