# 蜂医灰鼠六图下一阶段结构要求

业务源继续使用content.json。保留狗牌绝密4/机密3档、枪械两难度各3档、左轮两难度各4档；保底、积分、枪械清单及本轮已确认同平台价目不变。

- 页面ID继续为dogtag-cover、dogtag-social、firearms-cover、firearms-social、revolver-cover、revolver-social。
- 三封面：横向8:5，计划3200×2000。左侧品牌、标题、版本、核心卖点、端手游同价与两难度文字组分别居中；右侧采用对应已确认蜂医/灰鼠插画。角色与前景道具在净文字区之外，环境沿边角和角色周围补充手绘医疗营地、远景塔台、撤离路线与主题小道具。不写须知或结算例外。
- 三广告：3:4，计划3000×4000。上方左标题右插画及玩法说明，端手游同价条；下方两难度深蓝连续标题栏，暖金/薄荷青浅色面板；价目行数与上述档数一致；页尾核心条件/主卖点。狗牌机密3档单独等分，不补虚构第四档。枪械每档保留完整枪名，优先确保净文字区和手机阅读字号。
- 独立插画原图为1536×1024，只作为图像模型参考和构图素材，不把其alpha黑底预览误当成实体黑色背景。
- 必须等待插画批准后再生成底图；底图需统一手绘风格，不能将Q版人物贴进写实场景，也不能只用程序形状代替要求的手绘环境。
- 背景生成后以真实卡片/装饰边界重新测量，不沿用旧海报坐标直接填字。
