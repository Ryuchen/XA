# 四图文案排版优化 r4

2026-10-09。依据用户本轮明确调用的 ui-ux-pro-max，在已确认底图上修改矢量文案。

## 采用的设计依据

技能的 ux 数据检索匹配到 Font Size Scale、Line Height、Heading Line Balance。应用一致字号层级、语义组间距及完整短语换行。字号和换行以真实静态海报文字区与390px预览复核，网页与应用的尺寸建议不直接当作此海报的最终尺寸。字体继续使用用户指定的 MiSans；人物、奶白雾蓝配色和艺术主标题沿用确认版本。

本轮形成三层阅读顺序：保底数字 → 费用、模式及平台 → 限制条件与规则。强调使用半粗字重、模式色、暖金条件色、浅色标签及细分隔线；普通说明保持常规字重。

## 四页调整

| 页面 | 调整 |
| --- | --- |
| 封面 | 在主标题下补充三角洲行动归属；卖点胶囊分色展示新客专享／每日一单；平台与模式以字重和间距分层，并在左侧净文字区整体居中。 |
| 广告 | 平台标题更大且用奶白，优惠类别用暖金；仅可下一次选择性强调；超值券为独立暖金标签，模式置于下一行；费用和保底之间增加细分隔线；12行固定r/w列。 |
| 端游体验单 | 增加01／02／03段落序号；新客条件突出仅可下一次；平台单独强调；保底标签放大；地图模式标签、排队要求、装备数量和活动限制分层。 |
| 手游体验单 | 与端游共用同一排版体系，各自数值与模式来源独立；装备说明增加行距，以共同标签列与说明列对齐；左轮要求等义合为一行，给房卡与背包段落更多空间。 |

装备规范的普通行中心距离从约31.15px增加到36px，跨语义组44px；可见行间隙至少约8px。左轮“均需携带≥1把”等义保留两种模式均需至少一把的要求。房卡仍显示机密包1张红卡房、绝密按俱乐部规定包金／红卡；背包仍为机密≥30格、绝密≥40格。

## 复核

已查看四张实际PNG、全部390px预览、端游及手游须知局部和前后对照。58个区块、52组数字单位及377项几何／来源检查通过，0处文字相交或越界。数字与r/w共用基线；装备标签和说明共用基线，说明续行统一左起点；真实文字区左右与上下留白平衡。

十二档价格、保底、模式及新客限制逐项核对源数据。所有非艺术标题文字为 MiSans；普通解释与重点字重有区别。详细页规则字号在390px预览中约12.3–14.9px，最终版仍提供高清PNG供放大阅读。
