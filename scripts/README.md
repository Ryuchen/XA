# 项目脚本

本目录存放仓库级检查、隔离联调和运维脚本。三端源码、业务服务和部署入口分别位于 `fronted/`、`services/backend/` 和 `deploy/`。

| 位置 | 用途 |
| --- | --- |
| `scenarios/` | 由后端测试启动的三端控制器与真实隔离 HTTP 场景入口 |
| `fronted-*-contracts.mjs`、`fronted-test-runtime.mjs` | 上述场景使用的共享契约和测试运行环境 |
| `test-*`、`verify-*`、其余场景脚本 | 当前仍由测试、部署脚本或历史验证记录引用，按现有调用路径保留 |
| `icon-sources/` | 图标源文件及其第三方许可 |

场景入口由对应的 Django 测试准备临时数据并传入参数；不能仅运行入口就视为业务通过。涉及真实数据库、消息或外部渠道的脚本必须先核实环境隔离和调用对象。标准开发环境统一使用 `deploy/dev.ps1`，本目录不替代该入口。

部分脚本和名称来自已退役页面或历史验证，文件名不代表当前页面已经通过验收。顶层遗留旧端驱动脚本（125 个，含 51 个混合调用脚本）已按用户 2026-11-17 批准的外科式口径清除：测试中旧端 UI/node 步骤移除或改纯 HTTP 重实现，后端业务断言保留，历史 UI 覆盖损失逐模块登记于[外科式清除审计](../docs/ops/records/legacy-script-surgical-removal-20261117.md)；11-15 的[混合调用复核](../docs/ops/records/legacy-script-followup-52-20261115.md)仅作历史追溯。微信小程序相关脚本（顶层 `native-*`、`visual-native-*`、桥接检查及仅依赖旧小程序端的联调脚本）已按用户 2026-11-17 决定删除；`scenarios/` 下的入口为当前 React 契约测试，予以保留。现存顶层 `.cjs` 仅为隔离后端 HTTP/WS 覆盖、当前 React 平台浏览器覆盖与部署/验收基础设施。
