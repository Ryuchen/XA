# 声浪电竞三端业务前端

2026-11-11 本轮仅负责前端：产品化为可供俱乐部入驻的 SaaS。后台与陪玩端是固定模块，使用统一 B 端规范；老板端 H5 独立可购与定制，定制不侵入公共订单、资金、权限和固定模块。平台独立身份统一管理俱乐部与订单。新增接口保持待对接，不以样例冒充业务闭环。详见 `../docs/prd/34-SaaS产品模块与三端前端闭环.md`。

本目录按用户2026-11-04指令重新通过官方shadcn CLI建立React前端，逐页迁移现有apps业务。老板端与陪玩工作台适配桌面和手机；后台最小视口为1366×1024，保留平板触控范围。统一React、TypeScript、Tailwind CSS 4与shadcn组件。

2026-11-05 用户恢复三端整体视觉更新：优先直接采用新版原型已有页面和组件的代码样式，没有对应页面的按同套样式扩展。原型与现有业务实现冲突时，保留现有字段、流程、权限和动作，再延展视觉。老板端与陪玩端继续适配手机触屏和桌面，后台以1366×1024为最小适配范围。

老板选择服务、陪玩和套餐，核对真实报价、支付路径及余额，管理订单、预约、权益、消息和资料。陪玩处理报名、邀请、接单、履约凭证、报单、预约、提现、消息和个人档案。后台按真实角色授权处理派单、审核、资金、内容、用户及配置。

后台新增岗位薪资方案、员工月度安排、业绩归属核实、月度成本快照、每日投流及其他成本、经营ROI和统一字典入口。按实际安排人数计算工资，日常提供明确标注的暂估结果，确认后保留快照；该模块登记经营成本，不执行工资转账。岗位、渠道和成本类别使用统一字典，原有业务分级及资金规则保留专用校验。详见 `../docs/ops/payroll-roi-20261104.md`。

视觉沿用design-demos/shenglang-web-prototype已有原型及声浪Logo，海洋蓝、奶白与已有深色层级。原型提供视觉结构，不提供业务数据或资金规则。数据来自本机隔离MySQL验证栈的真实接口；资金、订单状态、资格、权限、允许动作与试算以服务端为准。

迁移保留完整业务字段、幂等请求、版本校验、会话隔离及结果未知后的核对恢复。既有apps保留用于逐项追溯。页面需有加载、空、失败、更新中与真实结果反馈；不以示例数据或可点击占位页认定功能迁移完成。

门店作为租户边界：老板与陪玩入口按门店子域名绑定，不提供切换门店。统一后台不在未登录时选店，业务身份由真实认证确定，不能以 query/header 覆盖。平台身份使用独立接口与授权，聚合记录保留所属门店及业务ID。账户、余额、订单、活动、配置及经营数据分别归属独立业务库。新店登记、初始化、配置与可营业状态明确区分。

老板端仅使用微信快捷登录，网页扫码后通过已实现的最小小程序桥接页完成微信身份授权、微信手机号读取、短信验证与显式确认；不提供密码或独立手机号登录。隔离环境已验证真实票据、账号与JWT链路；微信桥接页发布、手机可访问的HTTPS及合法域名、真实短信服务仍需对应配置联调。微信手机号授权及支付、外部通知不能用浏览器模拟宣称完成。业务拓展以用户确认与后端既有能力为边界。
