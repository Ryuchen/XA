# 后台加载、空结果与异常态（逐页复核后）

2026-11-11 本轮修订替代此前的独立静态异常框架。页面始终渲染原有页面和组件，加载或异常只改变区块内部的显示；原筛选、表头、字段标签和区块保持一致。已删除 `PageUnavailable.tsx` 与 `page-regions.ts`，避免维护两套结构。

共享实现为 `components/page-data-state.tsx` 和 `components/business.tsx` 的 DataPageState / DataTable / Pagination，及 Catalog 的 SourceDirectoryCard。DataValue 只保护显示值，不修改金额库、业务计算或表单提交；DataRegion 放在真实卡片内部，未知配置保持空值/—，不作为默认配置提交。独立来源显式传 snapshotAvailable 或独立读态，成功来源不被父级失败遮掉。

本轮浏览器已逐一打开 59 个门店入口，其中 13 个实际读取异常；均保留真实结构，无页面渲染报错。加载到异常/成功的结构对照、成功空查询、五类共享读态与配置未知态检查通过，记录见 [逐页审查](PAGE-STATE-AUDIT.md)。平台 7 页完成源码修复、类型与构建验证，当前门店身份下未作独立平台身份实测。

## 实现边界

- `components/PageUnavailable.tsx` 与 `lib/page-regions.ts`：57 个常规业务页面的静态区块框架。列表页展示筛选和表头，配置页展示分组字段，统计页展示指标/趋势区。我的工作台与模块中心使用各自现有的数据反馈，不接入此 REST 页面包装器。
- `components/business.tsx`：DataPageState 首次失败使用分区框架；DataTable 失败不再吞掉整张表格。正常、成功空记录与已有快照逻辑保持。
- 未知金额、余额、总数和配置统一为 —，不写入 0 或虚构默认配置；首次失败框架仅保留重试，筛选占位只读，不挂载创建、审核、充值或提交等业务写操作。会员积分字典区块继续按原字典查看/编辑权限显示。
- 重试调用原有读取方法，成功后恢复原页面及父页面保留的筛选草稿。接口、权限、查询参数、真实业务处理及数据库均未改动。
