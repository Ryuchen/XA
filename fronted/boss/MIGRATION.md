最终桥接交付项目为 `fronted/wechat-bridge`：只注册一页微信身份/手机号授权和短信确认，不打包旧小程序业务页，不存储业务JWT。原 `apps/boss-miniapp/native` 继续作为迁移参考；本文历史原生编译记录不代表要继续交付其完整业务包。

更新：2026-11-04。目录由根代理通过官方 `shadcn@4.23.0` CLI 的 React 脚手架创建，使用 Tailwind CSS 4.0.17。`package.json` 中的 `xaScaffold` 记录初始化来源。`apps/boss-miniapp/native` 保留为业务行为参考；此目录运行网页业务，不复用原微信页面或旧 UI 库。

## 原生交互补齐

此前明确未等价实现的两项旧交互现已补齐，均使用现有 React/shadcn 与局部 CSS，不引入新的视觉方向：

- 首页只选最新 HOT 列表第一项中的有图内容，以及首张有图 ORDER_RULES；可切换、下一张、打开原图、阅读详情及明确关闭。复用原端 `xa:entry-posters:{id}:{updated_at}|...` 组合规则，只有关闭时才写入持久记忆，展示/切换/阅读详情不提前记为关闭；不新增每日、每账号或其他频率规则。内容组合或更新时间变化后按原规则重新展示。18105 当前六项内容的 `image_url` 都为空，按真实数据不制造海报；双图分支仍待根代理提供真实图片内容后在浏览器验证。
- 转盘在同一个 `submitIntent` 返回真实单/十连结果且校验 count、draw/claim ID、奖品名称、rarity 与余额后，才开始 SVG 转盘与逐奖揭晓。指向由服务端实际奖品 ID 决定，前端没有随机抽奖。请求与整个揭晓阶段由同一 ref 锁阻止再次 draw；跳过、减少动态及定时揭晓只更新展示状态，不调用写接口，也不新建请求 ID。
- 转盘支持随时跳过并立即展示全部已确认奖品、持久“减少动态效果”选项，以及 `prefers-reduced-motion`。系统要求减少动态时直接展示结果；页面隐藏会结束展示，组件卸载清理计时器。已确认结果展示异常只提示去权益记录核对，不能用再次抽奖修复显示。
- 微信原生分享菜单、图片预览由浏览器 URL/原图入口承接；没有模拟微信授权、微信分享 SDK 或付款成功。登录与手机号授权使用已确定的最小真实微信桥接方案。

根代理另定位到 390×844 个人资料头像文件控件的原生固有宽度导致页面宽 412；已仅在头像 label/file input 补可收缩与最大宽度约束，未隐藏页面溢出。该修复待根代理复测。

以上仍是源码实现结论，不将 TypeScript/构建或只读 HTTP 作为交互验收通过。当前无已知尚未实现的旧 35 页业务动作或本轮明确要求的界面交互；未覆盖场景按上文保留。

## 最新认证约束

老板端只使用微信快捷登录/扫码登录，不提供密码登录、独立手机号注册登录或旧试音邀请换取 JWT 的入口。

1. 网页 `POST /users/web-login/start/` 获取真实微信授权桥接页的小程序码，凭私密 `ticket/poll_token` 轮询 `/users/web-login/status/`。
2. 只有后端返回 `CONFIRMED` 与实际会话，才调用共享会话存储。
3. 手机号由最小微信桥接页读取微信授权结果，再验证短信；网页不提供手填手机号冒充微信读取的路径。
4. 已登录账号验证手机号，起票携带当前鉴权与 `purpose=bind_phone`；回执账号不同则拒绝替换当前会话。
5. 微信入口/桥接页或短信服务未配置时展示实际失败信息，保留重试和客服入口，不制造二维码或假成功。
6. 试音邀请只读取公开信息；登录后通过 `/audition/enter` 核对当前微信账号与绑定账号。成功不签发新 JWT，不切换账号。

## 共享行为与待验证项

- 会话、401刷新、角色隔离、WebSocket重连由 `@xa/shared` 提供；账号切换会卸载当前业务页面。本人范围由后端权限再次约束。
- 金额展示复用 `@xa/money`：内部整数始终原样传给报价/写入，浪花/RMB只在展示边界换算。
- 所有资金操作先保存不可变请求凭证；网络和服务端不确定结果保留原请求，避免以新请求重复支付。首次明确业务拒绝才释放原凭证。
- 原型仅用于视觉结构参考，页面从真实 API 加载；没有为匹配原型而添加后端不存在的业务规则。
- 仍需批量浏览器与真实隔离数据库场景验证，特别是报价变化、双陪资格、跨页消息、优惠券退回、实销/售后、兑换库存与断线恢复。表中“待联调”不会因构建通过自动改为通过。
- 当前库中历史微信登录文案及后端邀请兼容实现的最终淘汰，由根代理统一处理；新老板网页源码只调用最终微信桥接入口。
