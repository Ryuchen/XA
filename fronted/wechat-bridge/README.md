# 最小微信授权桥接

在微信开发者工具中导入本目录，沿用项目现有公开AppID。唯一页面为 `pages/web-login/index`；没有首页、订单、钱包、支付或其他小程序业务页，没有业务JWT存储或旧端依赖。`apps/boss-miniapp` 仅保留迁移参考，不能用它的完整业务包冒充本桥接交付。

网页先在后端起票，微信小程序码的32位scene进入唯一页面。用户同意隐私指引后微信快捷登录；需要绑定号码时只用微信手机号授权，随后短信验证码验证并显式确认。网页登录JWT只返回持有私密poll_token的原网页。本小程序仅在内存保留当前票据的bridge_token，离页销毁。

`native/config.js` 区分开发、体验、正式环境。开发回环地址仅供本机开发者工具使用；手机真机需要可达的HTTPS地址及微信合法域名。正式和体验环境强制HTTPS，AppSecret和短信凭据仅放后端。发布前需在微信平台配置实际隐私指引、手机号能力和合法域名；当前没有把编译通过当作发布/真机授权或真实短信送达完成。

从仓库根目录执行 `node scripts/check-wechat-bridge.mjs --require-compiler` 检查单页包边界、依赖和微信官方模板/样式编译。
