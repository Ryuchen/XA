# 后台实时更新与挂页稳定性

2026-11-05：修复后台多标签页停留时反复卸载页面的问题。

- 同一次登录使用非秘密的持久化 `sessionId`。跨标签同步资料与Access令牌续期不改变当前身份版本；真正重新登录（包括同账号重登）、换号、退出和跨店仍使旧请求失效。资料没有变化时不重复写存储。
- 后台不再按60秒周期重读页面或健康状态下的待派队列。共享连接的25秒ping/pong是连接心跳，不触发页面数据请求；异常读取的退避重试继续保留。
- `useLiveReload`按当前业务页及运营tab筛选已有WebSocket事件，只重读相关数据区；350ms合并事件，同一区域读取期间最多保留一次后续核对。无关消息不刷新其他页面，重新连接/回到可见状态执行局部核对。
- 更新已有快照时不清空整页，不改变筛选、滚动、已打开的表单或输入草稿。通行证购买记录收到资金变更提示时只更新记录，规则编辑草稿保持不变。
- 页面仍从真实API读取授权数据；WebSocket消息作为失效提示，不将消息载荷直接当作账务结果。HTTP开发环境使用ws，HTTPS部署自动使用wss。没有为静态配置伪造后端推送；本次未新增其事件生产者。
