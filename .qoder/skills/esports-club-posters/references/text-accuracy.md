# 文字防错与生成时约束

只在生成含风格化文字的图（封面/广告页）或新底图时读取。改价、改文案走矢量层，不需要本文件。

## 生成时就锁定尺寸与比例

尺寸和比例是**生成指令的一部分**，不是生成后压缩或缩放补救。

| 目标比例 | 生成尺寸 |
| --- | --- |
| 16:9 横版封面 | 1792x1024 |
| 3:4 广告 / 小红书 | 1024x1536 |
| 1:1 朋友圈 | 1024x1024 |
| 9:16 故事 / 竖版 | 1024x1792 |

- 多比例输出必须**每个比例独立生成**，AI 直出无法靠裁切或缩放复用。
- 底图原生尺寸应不小于目标导出尺寸。导出宽超过原生宽时脚本会告警，此时应重新生成，而不是放大。
- 价目海报是竖版长图（示例约 1:2.4），超出上表标准比例，须在生成指令中显式写明画幅、行数与留空区域。

## 可读性下限：密集页不要靠降分辨率省体积

1080 宽的长图在手机上约缩到 390pt（约 2.8 倍）。画布正文需 ≥36px、标签 ≥28px，到手机上才有 13–14pt。

示例价目海报正文在 809 宽画布上为 13.4px，据此反推最小导出宽约 2200px。因此：

- 价目海报默认 `--size print`（3200 宽），正文约 53px，手机上约 19pt。
- 省体积靠 **WebP 格式**，不靠降分辨率：3200×7682 的 WebP 约 0.63 MB，同尺寸 PNG 约 13.66 MB。
- `web`/`hd` 只用于封面、广告等大字少内容的页面，或带宽确实受限且用户接受可读性下降时。

## 字数与数字风险

- 主标题 **≤8 字**最佳，>10 字出错率显著上升；副标题 ≤12 字，过长会被忽略或变形。超长时先建议缩短。
- **数字混排风险告知（必做）**：文案含数字（如"199元""5折""618"）时主动告知出错率高，建议纯中文核心文案交模型风格化渲染，数字利益点由矢量层叠加。用户坚持时才交模型，并在校验时重点核对数字。
- 价格、物资、门槛、补偿数额一律矢量层，不交模型。
- 只用用户提供或能核实的数字；示意数据必须在图上标「示意」。编造看起来像数据的数字比留空更糟。

## 提示词纪律

- 正文严禁出现风格/色彩/图型编号，避免模型把编号当文字画进画面。
- 风格与材质关键词从权威来源**原文复制**，不逐次改写，减少漂移。
- 用 `subject positioned in [位置]` 一类构图指令引导文字与主体分布。
- 同一 prompt 并行生成 2–3 个变体（变场景/构图/光影），让用户选，降低单次失败成本。

## 强制二次校验

用户选定后必须执行，不得跳过：

1. 用 Read 查看选定图片。
2. 与用户原始文案**逐字比对**标题与副标题。
3. 判定：
   - 全部正确 → 交付，状态记 `pass`。
   - 有错字/缺字/多字/笔画异常 → 用**相同 prompt** 重试，最多 **2 次**。
   - 重试 2 次仍有误 → 告知具体哪个字有问题，给三个选项：接受瑕疵 / 换风格或材质重试 / 缩短标题重试。状态记 `accepted-with-flaw` 并留依据。

常见错误类型（校验重点）：多一笔少一笔、整字替换（如"萃"→"翠"）、镜像或旋转、材质遮挡导致模糊不可辨。

AI 文字有随机性，同一 prompt 每次结果不同，通常重试即可修正。
