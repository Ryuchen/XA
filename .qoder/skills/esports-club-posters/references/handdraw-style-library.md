## 版式族与信息密度

三个目标的本质差异是**信息密度**，画幅只是结果。按密度选版式族：

| 目标 | 版式族 | 密度 | 可选图型举例 |
| --- | --- | --- | --- |
| 封面 `cover` | 社媒卡 `SC-*` | 极低 / 低 | SC-002 文案主导底部辅助图卡、SC-016 极简大字小图点缀卡、SC-023 代表性情景概括知识封面卡 |
| 广告页 `ad` | 社媒卡 `SC-*` | 中 | SC-010 上下双格标题列表卡、SC-014 留白驱动主视觉信息卡、SC-020 一大一组非对称信息卡 |
| 价目海报 `price` | 信息图 `IG-*` | 高 | IG-003 多行左文右图信息图、IG-004 双列多行对比信息图、IG-033 讲义式高密分析信息图 |

社媒卡是大留白、短文案、图文一体的结构；信息图是多层多行、表格容器、编号模块的高密度结构。图型只决定构图拓扑与密度，**不决定画风**——画风仍由风格编号决定。

按本轮实际信息量在全族内动态判断，不维护"目标 → 固定图型"的死映射。上表只是起点举例。

## 文字分工

| 文字类型 | 处理方式 |
| --- | --- |
| 标题、卖点、装饰性短语 | **风格化文字**：可由图像模型按图文一体绘制，也可用本技能矢量艺术字 |
| 价格、物资、单位、门槛、补偿数额、规则正文 | **数据文字**：一律由矢量层渲染，底图必须为这些区域留空 |

- **封面 / 广告页**：使用 `SC-*` 提示词时可追加上游图文一体后缀，让模型把风格化标题与短卖点画进画面。若还要叠加矢量数据或品牌名，仍须预留安全区。
- **价目海报**：使用 `IG-*` 提示词决定分层与密度，但**不追加图文一体后缀**，底图保持无字；六档数据、保障门槛与规则正文由矢量层填入。

上游图文一体后缀（仅封面/广告页使用，原样追加）：

```text
【如果主题直白包含画面元素那就按主题出图，文案由你来升华，但是不要直接描述画面。 如果主题比较概念化，那么文案和主题尽量保持一致，如果文案较长由你提炼，由你先设计画面隐喻（人类和非人类都行）再出图   。    文字参与构图，图文一体】
```

## 选款协议

1. 结合本轮玩法的语义、情绪、受众与投放渠道，在**全库范围内实时做审美推理**，选出 1 组风格 + 主题色。主题色数量按画面层次决定：单色统领、双色（主色 + 点缀色）或三色调和。
2. **严禁维护或套用"主题关键词 → 固定编号"的静态映射。** 同一玩法在不同切入点下应有不同美学可能；推荐理由须紧扣本轮画面的视觉隐喻与构图，不写套话。
3. 用户已指定风格或色彩时严格保留，只补齐缺失的另一项。
4. 先输出推荐卡片（风格编号与中英文名、激活决策、色彩编号与角色、1 句美学理由），再给提示词。用户可随时换编号。
5. 编号只出现在推荐卡片与项目状态记录中。**提示词正文严禁出现任何编号**（如 `#018`、`FA-018`、`C-01`、`SC-001`、`IG-003`），一律用自然语言名称，避免模型把编号当文字画进画面。

## 激活决策

按所选模型的能力决定提示词内容，默认基线模型 `gpt-image-2`；可用上游 `scripts/resolve_reference.py --model <model> --style <number>` 做确定性核对。

| 激活档位 | 提示词内容 |
| --- | --- |
| 强作者/强名称激活 | 只给参考作者名 + 风格名 + 主题；**不输出核心特征，也不垫参考图** |
| 强特征激活 | 风格名 + 过滤后的正向核心特征；不垫参考图 |
| 弱激活/需垫图 | 风格名 + 正向特征 + 参考图，并附参考图隔离声明 |
| 模型能力未知 | 按未知处理：给可得正向特征并要求参考图兜底 |

只保留正向可见特征，过滤含"避免/不要/不准/禁止"的子句，不机械复制整段 traits。参考图路径按安装根解析：`images/individual/{分类}/{编号}.webp`，同目录存在 `{编号}_grid.webp` 时优先。

需要垫图时，把下列隔离声明原样加入提示词：

```text
所附图片仅用于参考画风。只提取参考图的风格特征，例如线条、笔触、媒介、材质、色彩倾向和整体视觉语言；不要使用、复制或延续参考图中的任何主体、人物、动物、服装、道具、动作、姿态、场景、背景、构图、布局、文字或故事。最终画面内容完全以用户提供的主题为准。
```

参考图缺失或无法传入时，如实说明限制并给出纯文本提示词，不伪造或替换参考图。

## 海报提示词字段

沿用上游 8 字段结构，`内容密度` 按目标取默认值：封面 极低/低、广告页 中、价目海报 高。

```text
主题：[本轮玩法与核心卖点]
业务场景：[俱乐部价目海报 / 活动宣发 / 封面 / 社媒广告]
受众：[目标人群]
内容密度：[极低 / 低 / 中 / 高]
情感基调：[核心情绪关键词]
主题色：[自然语言色彩名与角色，如 主色 克莱因蓝 + 点缀色 象牙白]
editorial风格：[标准命名 Editorial 风格]
画风：风格名称：{generation_name}。参考作者/风格名称：{reference}。[按需追加 核心风格特征：{traits}。]
```

字段内不加多余修饰与套话。价目海报仍须保留无字约束与数据安全区（见 [art-direction.md](art-direction.md)）：表头整条深色、数字与单位列留空、左侧净文字区、角色与道具不跨进文字区。

## 记录与续作

把本轮选定结果写入项目 `campaign-state.json` 的 `visualStyle`：

```json
{
  "source": "handraw-style",
  "styleId": "FA-018",
  "styleName": "Minimal Deadpan Dialogue Cartoon",
  "colors": ["C-01", "C-30"],
  "editorial": "Clean Airy Flat Vector Illustration Editorial",
  "layoutFamily": "SC",
  "layoutId": "SC-016",
  "density": "低",
  "activation": "name+style",
  "referenceImage": null,
  "basis": "本轮用户确认或推荐理由"
}
```

沿用示例二次元手绘稿时 `source` 记为 `sample-anime`，`styleId` 留空。后续改价、换文案只复用已确认底图，不重新选款；确需换画风或换密度时更新该记录并重新走插画确认。
