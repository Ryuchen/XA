# 六级 VIP 卡片共同设计 Spec

## 目标

让会员在首页或会员页一眼识别当前等级与权益，同时获得接近银行卡不同等级的材质区分。卡片必须服务信息阅读，而不是成为收藏摆件。

## 共同内容

- 声浪电竞 Logo 与会员标识。
- `VIP 1` 至 `VIP 6` 六个等级视觉主题。
- 当前隔离账号 `隔离验收 VIP1` 与 `9.8 折`；其他等级显示“等级样式演示”和 `—`，不编造折扣。
- 银行卡比例约 1.586:1；桌面三列、平板两列、手机单列。
- 卡片选择、 hover 光感、减少动态效果和键盘焦点。

## 输出

- 六格缩略稿 `thumbs.html` / `thumbs.png`。
- 三个完整方向 `dir-1.html` / `dir-2.html` / `dir-3.html`。
- 桌面截图 1440×1000，手机截图 390×844；整页长图用于检查全部六级。
- 每版包含六个等级卡片与选择交互；不修改生产代码，直到用户选定。

## 设计约束

- 保留海洋蓝、MiSans、4pt 间距、真实业务字段和现有会员页其他模块。
- 正文 ≥14px、标签 ≥12px、可点目标 ≥44px。
- 三个方向必须拥有不同材质与信息骨架，不是简单换色。
- 动效只表达选择、材质与焦点，支持 `prefers-reduced-motion`。
