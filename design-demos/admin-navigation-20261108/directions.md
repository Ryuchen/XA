# 六个候选方向

所有候选共用真实品牌 SVG、MiSans 优先字体栈、45 个页面和权限边界。外观只用于辨认候选，核心差别是信息组织。

## 候选 1｜最佳设计师：Richard Saul Wurman 的分类思维 → 完整版 A

- **借什么**：按稳定的业务类别建立心智地图，再按处理/配置关系分层；不堆砌视觉隐喻。
- **主角素材**：真实业务对象名称和 45 个路由，主角是“归属清楚”本身。
- **骨架**：平台与工作台独立，七个业务域折叠；当前域展开二级中心，门店配置统一收束。
- **胆量花在哪**：将群派单和统一字典从日常处理移到门店配置，把订单与预约按实际时序排列。
- **form 来自内容**：域名直接来自电竞陪玩的订单、陪玩、老板、资金与履约对象。

## 候选 2｜最佳设计师：Cultured Code 的任务边界思维 → 完整版 C

- **借什么**：让连续任务靠近，减少在“对象柜”之间来回找；不照搬 Things 的外观。
- **主角素材**：客服、陪玩运营、会员活动、财务经营、门店治理五组任务。
- **骨架**：一级按岗位任务，二级按一段连续动作，三级仍是现有页面；规则靠近对应岗位。
- **胆量花在哪**：客服会话、订单预约、履约评价、消息触达形成一个连续工作区，打破原先对象分栏。
- **form 来自内容**：门店员工按职责完成一天的工作，而不是按数据库表逐张管理。

## 候选 3｜现实参照：Shopify Admin 公开导航模型 → 备选

- **出处**：官方导航说明与截图 `references/shopify-page.png`；只借公开分组，未看到登录后产品界面。
- **借什么**：核心业务对象与店铺设置分开，搜索补足跨域访问；多门店上下文保持可见。
- **主角素材**：订单、陪玩、老板、经营分析、设置五个对象组。
- **骨架**：对象型一级菜单 + 独立设置区；二级把记录、分析和规则分别排列。
- **胆量花在哪**：大量配置集中收束，让业务菜单明显短于配置目录。
- **form 来自内容**：一店一套商品、会员、资金与规则，门店切换仍是硬边界。

## 候选 4｜现实参照：Linear 官方界面层级 → 备选

- **出处**：官方界面更新说明与已查看图片 `references/linear-interface.png`。
- **借什么**：将定位、当前工作、视图配置与内容分层；导航退后，让工作对象优先。
- **主角素材**：面包屑、域内工作清单和上下文关系，不是深色玻璃效果。
- **骨架**：左侧域树 + 当前域的任务地图 + 原页面入口，设置作为该域末节。
- **胆量花在哪**：右侧不仅显示页面标题，还显示“这个域如何完成一段业务”。
- **form 来自内容**：陪玩服务涉及多角色协作，定位比装饰更重要。

## 候选 5｜秒数轮盘：Web 4「糖果色凸起立体按钮游戏化」→ 备选

- **出处**：轮盘秒数 43，43 % 20 + 1 = 4；已实际查看 `references/web-04-friendly-candy.jpg`。
- **借什么**：大步骤、明确的当前阶段、按压反馈；不借绿色配方、记账题材或虚构积分。
- **主角素材**：四个真实工作阶段组成的任务路径。
- **骨架**：工作区按开始、进行、结算形成大阶段卡，侧栏呈现其页面。
- **胆量花在哪**：用明显的阶段尺寸代替传统密集菜单。
- **form 来自内容**：预约、接单、报单、结算确实有先后；不足是低频配置会被弱化，因此保留为备选。

## 候选 6｜秒数轮盘：East 8「杉浦康平信息曼荼罗」→ 完整版 B

- **出处**：43 % 12 + 1 = 8；已实际查看 `references/east-08-sugiura-info-mandala.jpg`。
- **借什么**：只借“环层表达关系、引线连接解释”的信息组织思维，转译为克制的服务链路，不制作圆盘或日历。
- **主角素材**：招募供给 → 接单履约 → 会员增长 → 结算经营的真实业务链路。
- **骨架**：一级为服务阶段，二级为阶段中的处理中心，右侧显示前后阶段与当前域入口。
- **胆量花在哪**：会员活动与内容触达放在同一条增长链路，提现、薪资与经营复盘进入同一条结算链路。
- **form 来自内容**：它表达的是电竞陪玩从人员供给到履约结算的闭环，而不是泛用仪表盘。

## 选择进入完整版的三张

1. **A／业务域驱动**：迁移成本最低、权限裁剪稳定，作为可预测的方案。
2. **B／服务生命周期驱动**：完整呈现业务先后关系，组织方式与 A 有实质不同。
3. **C／岗位任务驱动**：围绕员工日常连续操作组织，与 A、B 的对象/流程逻辑不同。

候选 3、4、5 保留在六格总览；如用户更偏好其中之一，再补成完整可点击版。
