## 设计取舍

声音是老板选择陪玩的真实依据。首页借用唱片封套构图，把找陪玩、选玩法放在封面下缘。陪玩目录把试听、可读姓名和参考时价放在一起。订单用编号、服务状态、来源与实际支付组织票面，消息按时间阅读，账户把余额和账单放在本人身份下方。黑白玩家影像和套印纹理留给封面与人物，表单、金额、凭证和长文使用清晰的纸白底。

## 覆盖与边界

覆盖 [现行路由](../../fronted/boss/src/App.tsx) 的 35 条独立业务地址、通配兜底和关键分支。多地址跳转至同一业务视图的别名共用同一设计。功能来源为 [现行老板端](../../fronted/boss/src/business) 和 [老板端 PRD](../../docs/prd/02-老板端.md)。登录主稿遵循微信方向，普通浏览器扫码登录沿用当前待开放标记；代码中已有的账号密码和二次验证单列为现状分支。

「服务中」与「已支付」独立展示，试音报名在确认前保留报名状态，预约在转单前展示预估。本店可用余额、人民币和积分分别标注单位；支付结果未知时核对原请求。画册供视觉与流程评审，生产前端和后端部署未参与本次出稿。
