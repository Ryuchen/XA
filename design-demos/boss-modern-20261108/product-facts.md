# 产品与事实边界

- 当前产品：声浪电竞老板服务中心，React + Tailwind CSS 4 + shadcn，桌面与手机网页。
- 当前界面来源：`http://sl.esports.club/boss/#/home`，2026-11-08 通过本机隔离环境实际访问并截图。
- 当前真实 Logo：`fronted/boss/public/brand.svg`，蓝色声波线标；已保存至 `assets/shenglang-brand.svg`。
- 当前真实业务文案：先听听声音，再决定和谁组队；每日签到、领券中心、门店榜单、心意礼物；转盘单、体验单、陪玩单、趣味单、任务单等。
- 公开玩法来源：本机隔离接口 `/api/orders/gameplays/`，原始响应存于 `assets/gameplays.json`。设计稿不使用隔离验收商品、金额或客户信息。
- 真实参照 1：Discord - Talk, Play, Hang Out，Apple App Store 官方页面 `https://apps.apple.com/us/app/discord-talk-chat-hang-out/id985746746`。
