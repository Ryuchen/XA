## 色板

- 深夜：`#020617`
- 海军：`#0F172A`
- 深蓝：`#1E3A8A`
- 主蓝：`#2563EB`
- 天蓝：`#38BDF8`
- 浅蓝：`#7DD3FC`
- 奶白：现有中性背景，保持高可读性，不以大面积荧光替代。

## 字体与组件

- 字体：MiSans，400 / 500 / 600 / 700；原型回退 PingFang SC、Microsoft YaHei。
- 间距：4、8、12、16、24、32、48。
- 控件：按钮、输入与下拉 40–48px；圆角 6–8px。
- 内容卡片：8–12px；标签 4px；选中态不靠放大圆角表达。
- 阴影：现有 `0 1px 3px rgb(0 0 0 / 10%)`、`0 1px 2px -1px rgb(0 0 0 / 10%)`，悬浮 Dock 使用更大柔化阴影。
- 手机导航：五个入口，悬浮 Dock，保留足够触控范围。

## 签名细节

- 声波是唯一贯穿的动态母题，表示陪玩声音与“同频”。
- 动效服务于选人、试听、组队、订单状态和跨页连续性，不做无意义循环漂浮。
- 视觉原型中的图形波形均为程序化材质，不冒充真实音频频谱。

## 禁区

- 不变成通用霓虹电竞模板，不堆砌像素、武器、奖杯或游戏角色。
- 不使用虚假头像、评分、在线人数、资金或订单数据。
- 不牺牲正文对比度、44px 触控、手机布局与现有业务入口。
