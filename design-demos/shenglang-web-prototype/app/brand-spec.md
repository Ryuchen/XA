# 声浪电竞原型品牌规范

## 既有资产

- 品牌名称：声浪电竞。
- 本地标志：`public/brand.svg`，以六条圆角声波线构成，使用 `#2563eb` 描边。
- 已确认设计方向：“澄海：任务优先”。本次门店概念迭代不更改标志、产品命名或视觉方向。

## 色彩

沿用项目 Blue Planet 海洋蓝与奶白体系：

| 角色 | 色值／变量 | 用法 |
|---|---|---|
| 深海背景 | `#020617`／`--ocean-950` | 深色基底与阴影来源 |
| 次深背景 | `#0F172A`／`--ocean-900` | 深色层级 |
| 品牌深蓝 | `#1E3A8A`／`--ocean-800` | 重点渐变与品牌层 |
| 主品牌蓝 | `#2563EB`／`--ocean-600` | 标志、主要操作、当前门店和链接 |
| 浅海蓝 | `#38BDF8`／`--ocean-400` | 局部高亮 |
| 淡海蓝 | `#7DD3FC`／`--ocean-200` | 辅助层级 |
| 奶白 | `--milk: 0 0% 98.8%` | 浅色中性背景 |

状态色只表达成功、警告、失败等业务含义。门店区分依靠名称、稳定标识和账号数据，不为每店另造主题色，以免造成“换色即完成隔离”的误解。

## 界面与排版

- 沿用现有 MiSans／系统无衬线字体、shadcn/ui 组件和紧凑 4pt 间距节奏。
- 门店信息是业务上下文，不作为营销横幅：固定在切换器、范围条、详情归属和确认框中。
- 手机端保留足够触控范围，门店长名称允许截断但完整名称可在切换器与说明中读取。
- 管理后台维持桌面与 1366 × 1024 平板横屏布局，不做手机端重设计。

## 资产使用边界

本原型只使用项目已有的声浪电竞本地 SVG，没有引入外部品牌、虚构合作方或生成替代标志。示例门店名称是原型租户样例，不代表真实门店或经营主体。
