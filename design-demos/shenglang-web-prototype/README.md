# 声浪电竞设计原型

本目录只保留 `app/` 中的 React + TypeScript 最新设计原型，作为后续视觉核对与迁移的唯一标准。

旧的静态 `admin/`、`boss/`、`provider/`、三端静态展示板及其预览脚本已删除，不再作为设计参考。

## 页面范围

- 老板端 H5：沿既有 `/login`、`/home` 等路由预览。
- 管理后台：从 `/admin-login` 进入。
- 陪玩工作台：从 `/provider` 进入，包含接单工作台、报单、预约、消息、钱包、个人中心、资料档期、技能、评价、通行证、积分兑换、客服与试音报名，共 13 个页面。
- 三端共享左侧产品切换；老板端与陪玩端均支持移动端和 PC 端预览、主题切换及正常、加载、空、错误场景。

陪玩工作台不设置快捷入口，以订单状态、履约操作和服务安排为主。文件选择、状态变更、客服发送和资金试算均为本地演示，不上传文件、不发送消息、不发起真实交易。

## 本地预览

在本目录运行：

```bash
npm run dev
```

需要指定监听地址和端口时：

```bash
npm run dev -- --host 127.0.0.1 --port 7100
```

## 构建

```bash
npm run build
```

所有页面与操作均为设计演示，不连接真实业务接口，不构成业务功能验收。
