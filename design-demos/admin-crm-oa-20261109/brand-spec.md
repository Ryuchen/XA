# 品牌与组件基线

- 平台、声浪、兴安 SVG 均从 `fronted/admin/public` 复制并核验，最终 HTML 内嵌透明矢量，不重画品牌。
- 保留 Blue Planet `#2563EB`、Slate 中性色、奶白背景、MiSans 优先字体栈、shadcn 层级和 4pt 间距。
- 控件使用中等 40px 规格，导航点击区域至少 44px；表格默认每页 10 条，无首列 checkbox，表头与内容竖直居中，部分状态与操作列水平居中。
- 表格支持横向滚动，滚动条不预留视觉空间；操作列不使用特殊背景。
- 原型不增加营销式 hero、业务阶段卡、岗位任务卡、概念标语、插画或无意义动效。
- 真实业务页面才是主角。选择稿的主区域使用订单页真实字段，其他入口保留原路由和页面归属，不重写业务页面。
