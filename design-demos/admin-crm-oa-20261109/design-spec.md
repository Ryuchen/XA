# 标准后台修订规格

## 目标

让后台在视觉结构与操作方式上都符合常规 CRM／OA：功能模块可预测、当前页面明确、筛选和表格占主区域、配置与权限有固定入口。

## 统一形式

- 桌面 1366×1024；1920 桌面扩展；窄屏只验证导航可达，不改变生产后台桌面定位。
- 左侧：工作台和平台入口 + 一级功能模块 + 二级功能组 + 三级页面。
- 顶部：门店上下文、完整面包屑、功能搜索、当前门店切换。
- 右侧：真实页面标题、操作、查询队列、筛选表单、数据表格。
- 完整功能通过搜索查看，搜索结果展示一级模块／二级分组／原路由。

## 三个候选只比较模块颗粒度

1. A 标准功能模块：8 个业务模块，商品与营销相邻，财务包含薪资，经营分析独立。
2. B 业务归类模块：6 个业务模块，订单与客服、客户与营销分别归组，财务与经营统一。
3. C 细分业务模块：10 个业务模块，商品、营销、财务、薪资、经营分析各自独立。

## 验收

- 每版 45 个入口且只出现一次，含统一字典。
- 一级模块展开、二级分组、三级页面、面包屑和当前页高亮正确。
- 查询、更多筛选、清除、订单队列切换有真实前端状态；无业务网络请求。
- 搜索、侧栏收起、门店切换、窄屏导航、表格横向滚动可用。
- 不出现“方案宣传页”“生命周期”“岗位工作区”等上一版问题。
